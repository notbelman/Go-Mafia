# Промт для извлечения вопросов из аудио/текста собеседования

Из предоставленного текста (расшифровка аудио, заметки, скрин) извлеки все вопросы, которые задавал интервьюер.

## Правила
1. Раздели вопросы на основные и дополнительные (follow-up)
2. Дополнительный — это вопрос, который задали в продолжение предыдущего, углубляя тему
3. Группируй по темам как они шли на собесе
4. Не перефразируй сильно — сохраняй суть как было сказано
5. Не используй двоеточие `:` в тексте вопросов

## Формат вывода
```
### Тема (как она звучала на собесе)
- Основной вопрос
    - Дополнительный вопрос
    - Дополнительный вопрос
- Другой основной вопрос
    - Дополнительный вопрос

### Другая тема
- Основной вопрос
```

## Пример

Из текста:
> Спросили про горутины, чем отличаются от потоков. Потом уточнили про GMP модель. Спросили что будет если стек горутины вырастет. Дальше перешли к каналам — что будет если писать в небуферизированный и никто не читает. Как заблокировать через select навсегда.

Вывод:
```
### Горутины и потоки
- Чем горутины отличаются от потоков ОС?
    - Расскажи про GMP модель
    - Что будет если стек горутины сильно вырастет?

### Каналы
- Что будет если писать в небуферизированный канал, который никто не читает?
- Как заблокировать канал навсегда через select?
```
