Синхронные: Request-Response
Асинхронные: Fire-and-Forget, Point-to-Point, Pub/Sub
## Синхронные
Request-Response: клиент ждет ответа.
```
Client -> Server: GET /users/123
Client <- Server: 200 OK {id: 123}
```

Примеры: REST, gRPC, GraphQL, SOAP

---

## Асинхронные (Message-Based)

### Fire-and-Forget
Отправил сообщение и забыл (не ждет ACK/ответа).
```
Producer: send(msg)
Producer: продолжил работу (не ждет)
```

Примеры: логирование, метрики, UDP

---

### Point-to-Point (очередь задач)
Одно сообщение = один обработчик.
```
Producer -> [Queue] -> Worker 1 (взял задачу)
                    -> Worker 2 (ждет)
                    -> Worker 3 (ждет)
```

После того как Worker 1 взял задачу -> она УХОДИТ из очереди (или блокируется до ACK).

Примеры: обработка заказов, email, background jobs
Реализация: RabbitMQ Queue, Kafka Consumer Group

---

### Pub/Sub (широковещание)
Одно сообщение = все подписчики получают копию.
```
Producer -> [Topic] -> Consumer 1 (копия)
                    -> Consumer 2 (копия)
                    -> Consumer 3 (копия)
```

Примеры: Event-Driven архитектура, нотификации, кеш инвалидация
Реализация: RabbitMQ Fanout Exchange, Kafka (разные Consumer Groups)
