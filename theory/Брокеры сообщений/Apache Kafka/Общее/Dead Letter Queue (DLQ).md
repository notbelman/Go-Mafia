## Суть

Отдельный топик для сообщений которые не удалось обработать.

## Как работает

```
Main Topic → Consumer → ОК → commit offset
                      → ошибка (3 ретрая) → send в DLQ топик → commit offset → едем дальше
```

## Что делать с DLQ

- Алерт: попало в DLQ — разбираемся
- Пофиксили баг → переотправили в основной топик
- Или отдельный консьюмер читает DLQ с задержкой и пробует снова

## В Kafka нет DLQ из коробки

В отличие от RabbitMQ. Делаешь сам: ловишь ошибку → `producer.Send(dlqTopic, msg)`.
