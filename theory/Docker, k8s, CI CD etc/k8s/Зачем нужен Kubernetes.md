Kubernetes решает проблему сложности управления множеством микросервисов в динамической среде. Когда количество контейнеров растет, k8s берет на себя роль «дирижера», обеспечивая слаженную работу всей системы.
# Key Value Propositions of k8s
- **Auto-scaling**: Автоматическое наращивание мощностей при пиковых нагрузках, чтобы приложение «не повалилось».
- **Auto-healing**: Если сервис падает или нода выходит из строя, k8s сам перезапускает контейнеры на живых узлах (Self-healing).
- **Load Balancing**: Распределение входящего трафика между группами подов для стабильной работы под нагрузкой.
- **Desired State Management**: Контроллер постоянно сравнивает текущее состояние системы с «планом» (желаемым состоянием) и устраняет отклонения.
- **Zero Downtime**: Возможность обновлять приложение и менять конфигурации без остановки сервиса для пользователей.

⚠️ **insight**: Главное преимущество k8s — переход к **декларативному описанию инфраструктуры**. Вместо ручного запуска команд мы описываем в YAML-файлах, что хотим получить (например, 3 реплики сервиса), а Kubernetes берет на себя всю грязную работу по реализации и поддержанию этого состояния. Это превращает инфраструктуру в предсказуемый и восстанавливаемый код.
