1. Идентификация: "Я Ivan"
2. Аутентификация: "Вот мой пароль, проверь"
3. Авторизация: "Могу ли я удалить этого юзера?"

## Пример
POST /api/users/123
Authorization: Bearer eyJhbGc...

1. Идентификация: парсим токен -> user_id=456 из payload
2. Аутентификация: проверяем подпись токена + exp не истёк
3. Авторизация: проверяем user_id=456 может DELETE /users/123
   (либо role=admin, либо owner_id == 456)
