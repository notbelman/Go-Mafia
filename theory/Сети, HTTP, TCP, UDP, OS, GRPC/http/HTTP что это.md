Глагол в HTTP запросе, который указывает какое действие клиент хочет выполнить над ресурсом на сервере.

## Зачем

Стандартизация операций над ресурсами. Вместо /getUser, /createUser, /deleteUser используем один URL /users с разными методами.

## Примеры
```
GET    /users/123     - получить пользователя
POST   /users         - создать пользователя
PUT    /users/123     - заменить пользователя
PATCH  /users/123     - обновить поля пользователя
DELETE /users/123     - удалить пользователя
```
