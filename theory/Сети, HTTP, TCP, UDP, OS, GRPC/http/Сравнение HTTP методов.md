
| Метод   | CRUD   | Safe | Idempotent | Cacheable | Когда использовать                          | Важные нюансы                                                                 |
| ------- | ------ | ---- | ---------- | --------- | ------------------------------------------- | ----------------------------------------------------------------------------- |
| GET     | Read   | Да   | Да         | Да        | Получить ресурс/список                      | Не должен менять состояние. Параметры в URL                                   |
| POST    | Create | Нет  | Нет        | Да*       | Создать ресурс / RPC-операции / поиск       | Создаст дубли при retry. Нужен Idempotency-Key. *Cacheable если Cache-Control |
| PUT     | Update | Нет  | Да         | Нет       | Заменить ресурс целиком (upsert)            | Нужен ПОЛНЫЙ объект. Непереданные поля удалятся. Создаст если нет             |
| PATCH   | Update | Нет  | Нет*       | Нет       | Частично изменить ресурс                    | Только измененные поля. НЕ идемпотентен если increment/append операции        |
| DELETE  | Delete | Нет  | Да         | Нет       | Удалить ресурс                              | Повторный DELETE вернет 404, но состояние то же                               |
| HEAD    | Read   | Да   | Да         | Да        | Проверить существование без скачивания тела | Как GET, но только headers. Проверка Content-Length перед скачкой             |
| OPTIONS | -      | Да   | Да         | Нет       | Узнать доступные методы / CORS preflight    | Возвращает Allow: GET, POST + Access-Control-Allow-Methods для CORS           |
| TRACE   | -      | Да   | Да         | Нет       | Диагностика, эхо запроса                    | Отключен на большинстве серверов (XST атаки)                                  |
