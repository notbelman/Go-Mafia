- **Идентификация** = "кто ты?" (username, user_id в токене). **Аутентификация** = "докажи" (пароль, токен, биометрия). **Авторизация** = "что тебе можно?" (роли, permissions)
- Порядок: identification → authentication → authorization. Каждый запрос проходит все 3 этапа
- **Stateless** (JWT): сервер не хранит сессии, токен самодостаточен. **Stateful** (Session/Cookie): сервер хранит в Redis/БД
- **RBAC** (Role-Based): admin/moderator/user. **ABAC** (Attribute-Based): department=sales AND level>3

## Порядок: идентификация → аутентификация → авторизация

```
POST /api/users/123
Authorization: Bearer eyJhbG...

1. Идентификация: парсим JWT payload → user_id=456
2. Аутентификация: проверяем подпись токена + exp не истёк
3. Авторизация: user_id=456 может DELETE /users/123?
   (role=admin ИЛИ owner_id == 456)
```

## Идентификация — КТО ты

Просто заявляешь. Без проверки. Примеры идентификаторов:
- username / email
- user_id в JWT payload
- session_id в cookie
- API key (частично — это уже authentication)

**Идентификация без доказательств = уязвимость** (spoofing).

## Аутентификация — ДОКАЖИ

| Фактор | Что | Пример |
|:--|:--|:--|
| Знание | Что ты знаешь | Пароль, PIN |
| Владение | Что ты имеешь | Телефон (SMS/TOTP), hardware key |
| Биометрия | Кто ты есть | Отпечаток, Face ID |

**2FA/MFA** — комбинация факторов (пароль + SMS код).

## Авторизация — ЧТО тебе можно

| Модель | Как работает | Когда |
|:--|:--|:--|
| **RBAC** | Роли: admin, moderator, user | Простые системы |
| **ABAC** | Атрибуты: department=sales, level>3, time<18:00 | Сложные правила |
| **ACL** | Ресурс → список юзеров с правами | Файловые системы |

**Где проверяется:**
- **Gateway/middleware**: проверка роли до вызова сервиса (грубая)
- **Сервис**: проверка ownership (`user_id == resource.owner_id`) (тонкая)

## Stateless vs Stateful

| | Stateless (JWT) | Stateful (Session) |
|:--|:--|:--|
| Хранение | Токен у клиента | Сессия в Redis/БД |
| Масштабирование | Любой сервер проверит | Нужен shared Redis |
| Отзыв | Сложно (blacklist) | Просто (DELETE из Redis) |
| Размер запроса | Больше (JWT ~300-1000 байт) | Меньше (session_id ~32 байт) |
