- **Dirty Read** — читаем данные, которые другая транзакция ещё **НЕ закоммитила**. Если та сделает ROLLBACK — работали с данными, которых **никогда не существовало**
- Защита: **READ COMMITTED+**. В PostgreSQL **невозможен** даже на READ UNCOMMITTED (работает как READ COMMITTED)
- Ключевое отличие от Non-Repeatable Read: dirty = читаем **незакоммиченные**, non-repeatable = читаем **закоммиченные**, но изменившиеся

---

| Суть       | Читаем данные, которые другая транзакция ещё НЕ закоммитила                               |
| ---------- | ----------------------------------------------------------------------------------------- |
| Проблема   | Если та транзакция сделает ROLLBACK - работали с данными, которых никогда не существовало |
| Защита     | READ COMMITTED+                                                                           |
| PostgreSQL | Невозможен (READ UNCOMMITTED работает как READ COMMITTED)                                 |

## Пример
```
T1: BEGIN
T1: UPDATE SET balance = 100000
                                    T2: BEGIN
                                    T2: SELECT balance → 100000 (грязные данные!)
                                    T2: -- принимает решение на основе 100000
T1: ROLLBACK (отмена!)
                                    T2: -- решение принято на фейковых данных
```
