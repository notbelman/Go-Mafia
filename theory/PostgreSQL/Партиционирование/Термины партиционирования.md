
| Термин | Что это |
|--------|---------|
| Partition pruning | Отсечение ненужных партиций на этапе планирования по WHERE |
| Runtime pruning | Отсечение во время выполнения, когда значение из подзапроса/параметра (PG11+) |
| Planning time | Время построения плана запроса (растет с количеством партиций) |
| Execution time | Время выполнения самого запроса |
| Partition key | Столбец/выражение, по которому строки распределяются по партициям |
| Partition bounds | Границы партиции (FROM/TO для Range, IN для List, MODULUS/REMAINDER для Hash) |
| Default partition | Партиция для строк, не попавших ни в одну другую |
| Partition-wise join | JOIN выполняется между соответствующими партициями двух таблиц (OFF по умолчанию) |
| Partition-wise aggregate | GROUP BY выполняется внутри каждой партиции отдельно (OFF по умолчанию) |
| ATTACH/DETACH PARTITION | Присоединить/отсоединить существующую таблицу как партицию |
| pg_partman | Расширение для автоматизации создания партиций и retention policy |
