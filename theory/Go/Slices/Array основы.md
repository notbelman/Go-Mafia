- фиксированный размер, **не растёт**, элементы одного типа
- размер **вшит в тип**: `[3]int` ≠ `[4]int`, `len()` = константа на compile time
- под капотом: `addr = начало + idx * sizeof(elem)` — никаких указателей внутри
- bound check: константа → **ошибка компиляции**, переменная → **паника в runtime**
- нельзя: `make`, `append`, проверить на nil, отрицательная длина, переменная как размер
- можно: сравнивать == (поэлементно), в отличие от слайсов

## Создание

```go
a := [3]int{1, 2, 3}           // явно
b := [...]int{1, 2, 3}         // компилятор вычислит длину
c := [5]int{1, 2}              // остальные = 0
d := [5]int{2: 5, 4: 7}       // по индексам: [0 0 5 0 7]
e := [3][3]int{{1}, {2}, {3}}  // многомерный
```

## Размер — часть типа

Размер вшит в тип, не хранится в памяти. Поэтому `len()` — константа, компилятор подставляет число. ^array-size-in-type

```go
n := 5
var a [n]int  // ❌ compile error — нужна константа

const m = 5
var b [m]int  // ✅
```

`[3]int` и `[4]int` — **разные типы**. Нельзя присвоить один другому. ^array-different-types

## Доступ по индексу

```
addr = начало_массива + index * sizeof(элемент)
```

Никаких указателей внутри массива. Просто значения подряд в памяти. ^array-index-formula

## Bound checks

```go
a := [3]int{1, 2, 3}
_ = a[5]      // константа → ошибка компиляции
i := 5
_ = a[i]      // переменная → паника в рантайме
_ = a[-1]     // ❌ нельзя как в Python
```

Индекс-константа → ошибка компиляции. Индекс-переменная → паника в runtime. ^array-bound-check-rules

Отрицательный индекс через переменную тоже паника в runtime — Python-стиль `a[-1]` не поддерживается. ^array-no-negative-index

## Массив всегда инициализирован

```go
var a [10]int
fmt.Println(len(a))  // 10, не 0! Там уже 10 нулей.
// a != nil — массив нельзя проверить на nil
```

Массив при объявлении сразу инициализирован нулями. Проверить на nil нельзя — массив не является указателем. ^array-zero-init

## Сравнение массивов

Массивы можно сравнивать оператором == — сравнение поэлементное. Слайсы так сравнивать нельзя (только `reflect.DeepEqual` или ручной цикл). ^array-comparable

## Запрещённые операции

`make` и `append` для массивов недоступны — это инструменты слайсов. Размер массива задаётся один раз на этапе компиляции и не меняется. ^array-no-make-append
