- ошибка должна **рассказывать историю** — 4 правила текста ^errhandle-story
- обрабатывать ошибку ровно **один раз** (логирование = обработка) ^errhandle-once
- не хватает контекста/ответственности → **пробрасывай** наверх (с контекстом или без) ^errhandle-propagate
- есть контекст → **обрабатывай** прямо здесь (лог, retry, переподключение и т.д.) ^errhandle-handle-here
- не добавляй бессмысленный контекст — если нечего сказать, просто проксируй ^errhandle-no-empty-ctx

## 4 правила текста ошибки

1. **Максимально подробно** — не просто `"error"`, а что именно случилось ^errtext-detailed
2. **Весь контекст для расследования** — получая текст, можно понять причину ^errtext-context
3. **Однозначно характеризует место** — одна и та же ошибка не из двух мест кода ^errtext-unique
4. **Не слишком большой** — логи стоят дорого, не злоупотреблять длиной ^errtext-concise

## Обрабатывать один раз

```go
// ❌ двойная обработка — залогировали И пробросили
func GetRoute(lat, lon float64) error {
    err := validateCoords(lat, lon)
    if err != nil {
        log.Printf("validation failed: %v", err)       // обработка 1
        return fmt.Errorf("invalid coords: %w", err)    // обработка 2
    }
    return nil
}

// ✅ либо логируем здесь (если хватает контекста)
func GetRoute(lat, lon float64) error {
    err := validateCoords(lat, lon)
    if err != nil {
        log.Printf("GetRoute: validation failed: %v", err)
        return err  // не добавляем контекст, уже залогировали
    }
    return nil
}

// ✅ либо пробрасываем с контекстом (если не хватает)
func GetRoute(lat, lon float64) error {
    err := validateCoords(lat, lon)
    if err != nil {
        return fmt.Errorf("validate coords in GetRoute: %w", err)
    }
    return nil
}
```

^errhandle-once-example

## Проброс — не обработка

Проброс ошибки наверх (с контекстом или без) — это **не** обработка. Обработка — это когда вы что-то **делаете**: логируете, делаете retry, отвечаете клиенту, меняете поведение. ^errhandle-propagate-not-handle

## Не добавляй пустой контекст

```go
// ❌ контекст бессмысленный
return fmt.Errorf("error: %w", err)

// ✅ просто проксируй
return err

// ✅ или добавь полезный контекст
return fmt.Errorf("reading config file %s: %w", path, err)
```
