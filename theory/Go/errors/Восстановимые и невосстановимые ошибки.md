- деление на ноль (int) → **паника**, можно recover ^recover-table
- деление на ноль (float) → **+Inf**, нет паники (особенность IEEE 754) ^recover-table
- разыменование nil pointer → **паника**, можно recover ^recover-table
- stack overflow → **нельзя** recover ^recover-table
- out of memory (OOM) → **нельзя** recover ^recover-table
- os.Exit() → **нельзя** recover
- Go — «безопасный» язык: деление на ноль int = доп. проверка в рантайме → паника вместо UB ^go-safe-div

---

## Деление на ноль — int

```go
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered:", r)
        }
    }()
    x := 1 / 0  // ← паника: integer divide by zero
}
// recovered: runtime error: integer divide by zero
```

Go добавляет проверку при делении int — если ноль, паника (не UB как в C). ^int-div-zero

## Деление на ноль — float

```go
func main() {
    x := 1.0 / 0.0
    fmt.Println(x)  // +Inf — никакой паники!
}
```

IEEE 754: float имеет специальные битовые последовательности для +Inf, -Inf, NaN. Деление на ноль = корректная операция по стандарту. ^float-div-zero

## Nil pointer dereference

```go
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered:", r)
        }
    }()
    var p *int
    _ = *p  // паника: nil pointer dereference → recover ✅
}
```

Разыменование nil — recoverable паника. ^nil-deref

## Stack overflow — нельзя recover

```go
func infinite() { infinite() }

func main() {
    defer func() { recover() }()  // не поможет!
    infinite()
}
// fatal error: stack overflow (программа крашится)
```

Stack overflow — fatal error, runtime завершает процесс, recover не вызывается. ^stack-overflow

## OOM — нельзя recover

```go
func main() {
    defer func() { recover() }()  // не поможет!
    s := make([]byte, 1<<62)      // запрос огромной памяти
    _ = s
}
// fatal error: out of memory (программа крашится)
```

OOM — fatal error, defer/recover не успевают отработать. ^oom

## Сводка

| Ситуация | Паника? | Recover? |
|---|---|---|
| int / 0 | ✅ | ✅ |
| float / 0 | ❌ (+Inf) | — |
| nil deref | ✅ | ✅ |
| stack overflow | fatal | ❌ |
| OOM | fatal | ❌ |
