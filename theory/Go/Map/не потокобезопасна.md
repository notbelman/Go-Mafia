[[map Flashcards - concurrent]]
Одновременное чтение и запись — fatal error (не panic, не recover): ^mt-fatal-not-panic

```go
m := make(map[int]int)

go func() {
    for { m[1] = 1 }  // пишем
}()

go func() {
    for { _ = m[1] }  // читаем
}()

// fatal error: concurrent map read and map write
```

Runtime ловит это через флаг `hmap.flags` — при записи ставится бит, при чтении проверяется. ^mt-flags-detection

**Решения:**
```go
// 1. sync.Mutex — просто, но блокирует всех
var mu sync.Mutex
mu.Lock()
m[key] = value
mu.Unlock()

// 2. sync.RWMutex — много читателей, один писатель
var rw sync.RWMutex
rw.RLock()        // читатели не блокируют друг друга
_ = m[key]
rw.RUnlock()

// 3. sync.Map — встроенная concurrent map
var sm sync.Map
sm.Store(key, value)
val, ok := sm.Load(key)
```

sync.Map быстрее при read-heavy + ключи стабильны. Иначе обычная map + RWMutex. ^mt-syncmap-when
