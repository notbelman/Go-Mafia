- **полиморфизм** = многообразие форм: разные сущности выполняют одно действие, неважно как устроены внутри ^poly-def
- **утиная типизация**: если тип имеет нужные методы — он реализует интерфейс, без явного `implements` ^duck-def
- проблема утиной типизации: **идентичные контракты** у разных слоёв → можно перепутать реализацию, компилятор не поймает ^duck-problem
- для реализации интерфейса нужны **все** методы; методов может быть **больше**, но не меньше ^iface-all-methods

## Полиморфизм на примере

```go
type Shape interface { Area() float64 }

type Square struct{ Side float64 }
// утиная типизация: Square имеет функцию с той же сигнатурой, что и Shape
// Значит автоматически реализует интерфейс
func (s Square) Area() float64 { return s.Side * s.Side }

type Rect struct{ W, H float64 }
func (r Rect) Area() float64 { return r.W * r.H }

// Одна функция — разные реализации
func PrintArea(s Shape) { // функция принимает интерфейс
    fmt.Println(s.Area()) // вызывает тип этого интерфейса
}

PrintArea(Square{Side: 5})  // 25
PrintArea(Rect{W: 3, H: 4}) // 12
```

Неважно, что Square и Rect устроены по-разному — оба выполняют `Area()`. ^poly-example

## Утиная типизация

```go
type Duck interface {
    Quack()
    Walk()
}

type Dog struct{}
func (d Dog) Quack() { fmt.Println("woof") }
func (d Dog) Walk()  { fmt.Println("walk") }

func doStuff(d Duck) { d.Quack() }

doStuff(Dog{})  // ✅ компилируется! Dog "крякает" → значит утка
```

Dog нигде не говорит `implements Duck`. Но методы совпали → реализует. ^duck-example

## Проблема: идентичные контракты

```go
type UserService interface {
    GetUser(id int) (*User, error)
    UpdateUser(u *User) error
}

type UserRepository interface {
    GetUser(id int) (*User, error)
    UpdateUser(u *User) error
}

// Контракты идентичные! Перепутал repo и service:
func ProvideUserService() UserService {
    return NewUserRepository()  // ✅ компилируется, но БАГ!
    // должен был вернуть service, а вернул repository
    // логирование в service-слое не отработает
    // не просто логирование, а фул другая логика 
}
```

Компилятор не поможет — контракты совпадают. Баг проходит компиляцию, ловится только в тестах (или в проде). ^duck-identical-contracts
