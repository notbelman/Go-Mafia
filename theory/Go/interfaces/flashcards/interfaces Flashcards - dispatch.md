?
![[Диспетчеризация и девиртуализация#^itab-manual-impl]]

Что выведет этот код и почему?
```go
type Adder interface{ Add(int) int }
type Value struct{ N int }
func (v Value) Add(x int) int { return v.N + x }

var a Adder = Value{N: 10}
if v, ok := a.(*Value); ok {
    fmt.Println(v.Add(5))
} else {
    fmt.Println("не Value")
}
```
?
`не Value` — в интерфейс положен `Value` (не `*Value`), поэтому assertion на `*Value` возвращает `ok=false`. Нужно `a.(Value)` для неуказателя.
![[Диспетчеризация и девиртуализация#^devirt-def]]

Что выведет этот код?
```go
type Adder interface{ Add(int) int }
type A struct{ N int }
func (a A) Add(x int) int { return a.N + x }
type B struct{ N int }
func (b B) Add(x int) int { return b.N * x }

var iface Adder = B{N: 3}
fmt.Println(iface.Add(4))
```
?
`12` — в интерфейсе лежит `B`, вызов идёт через itab → `B.Add` (умножение). Динамическая диспетчеризация выбирает метод конкретного типа в рантайме.
