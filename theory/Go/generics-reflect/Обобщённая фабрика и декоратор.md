- **обобщённая фабрика**: type definition Creator[T] от функции → NewInstance[T] возвращает разные типы
- **обобщённый декоратор**: generic-функция + замыкание → декорируем поведение для любого типа
- паттерны из ООП и ФП **усиливаются** дженериками
- упрощение unsafe-обёрток: `atomic.Pointer[T]`, типизированный доступ к памяти

---

## Обобщённая фабрика

```go
type Creator[T any] func() T

func NewInstance[T any](c Creator[T]) T {
    return c()  // Creator = функция, вызываем
}

type Book struct{ Title string }
type Game struct{ Name string }

var bookCreator Creator[Book] = func() Book {
    return Book{Title: "Go in Action"}
}
var gameCreator Creator[Game] = func() Game {
    return Game{Name: "Tetris"}
}

book := NewInstance(bookCreator)  // Book
game := NewInstance(gameCreator)  // Game
```

`Creator[T]` — обобщённый type definition функционального типа. Один `NewInstance` возвращает разные типы в зависимости от переданного Creator. ^factory-creator-pattern

## Обобщённый декоратор

```go
func decorate[T any](fn func(T), decorator func(T) T) func(T) {
    return func(input T) {
        fn(decorator(input))  // сначала декоратор, потом функция
    }
}

func printInt(v int) { fmt.Println(v) }
func double(v int) int { return v * 2 }

decorated := decorate(printInt, double)
decorated(10)  // 20 — double(10) → printInt(20)
```

Декоратор обобщённый — работает с любым типом T. Порядок: сначала `decorator(input)`, потом `fn(результат)`. ^decorator-pattern-order

## Типизированные unsafe-обёртки

```go
// Без дженериков — громоздко
p := allocator.Alloc(8)
*(*int)(unsafe.Pointer(p)) = 200
val := *(*int)(unsafe.Pointer(p))

// С дженериками — чисто
func Write[T any](ptr unsafe.Pointer, val T) {
    *(*T)(ptr) = val
}
func Read[T any](ptr unsafe.Pointer) T {
    return *(*T)(ptr)
}

Write[int](p, 200)
val := Read[int](p)
```

Дженерики устраняют ручные касты `unsafe.Pointer` в каждом месте использования. Аналогично `atomic.Pointer[T]` из stdlib — обобщённая типизированная обёртка над unsafe. ^unsafe-wrapper-generics
