- сигнал: пишете **один и тот же код** несколько раз, отличаются только типы → дженерики ^cost-signal
- идеальные кейсы: **структуры данных** (Set, Tree, Graph), **функции контейнеров** (sort, merge, filter) ^cost-ideal
- цена: **рост бинарника** (каждая специализация = новый код в ассемблере) ^cost-binary
- цена: **увеличение времени компиляции** (генерация кода для каждого типа) ^cost-compile-time
- редкий случай: компилятор может подставить **интерфейс** вместо инстанцирования (когда много типов) ^cost-iface-fallback
- рантайм оверхед = **ноль** (код как если бы написали руками для конкретного типа) ^cost-zero-runtime

## Когда использовать

```go
// ❌ дублирование — сигнал
func containsInt(s []int, v int) bool { ... }
func containsString(s []string, v string) bool { ... }

// ✅ дженерик
func contains[T comparable](s []T, v T) bool {
    for _, item := range s {
        if item == v { return true }
    }
    return false
}
```

## Идеальные кейсы

Структуры данных: Set, Heap, BinaryTree, Graph — параметризованы типом элемента. ^cost-ds-examples

Функции контейнеров: Map, Filter, Reduce, Sort для срезов/каналов любых типов. ^cost-func-examples

Обобщённые обёртки: unsafe.Pointer → типизированный, atomic.Pointer[T]. ^cost-wrapper-examples

## Рост бинарника

```go
func sum[T int | float64](a, b T) T { return a + b }

sum[int](1, 2)
sum[float64](1.0, 2.0)
```

В ассемблере будут **две** функции: `sum[int]` и `sum[float64]` с разными инструкциями. Бинарник растёт линейно от количества инстанцирований. ^cost-binary-linear

## Интерфейсный fallback

В редких случаях (много типов) компилятор Go может не инстанцировать, а подставить пустой интерфейс — чтобы не раздувать бинарник. ^cost-iface-detail

Это прозрачно для пользователя, но добавляет рантайм-оверхед (boxing). ^cost-iface-boxing

## Не усложняй

Дженерики могут сделать код **сложнее**. Если нет дублирования — не нужны. Не ищите место, куда «воткнуть дженерик». ^cost-no-overuse

В C++ — известная проблема: изучил шаблоны → пишешь всё на шаблонах → через час не разберёшься. ^cost-cpp-antipattern
