Что выведет этот код (псевдо)?
```go
sm := NewShardedMap(4)
sm.Set("foo", "bar")
sm.Set("foo2", "baz")

// Оба ключа попали в один шард?
// Будет ли deadlock при конкурентном Get("foo") и Get("foo2")?
```
?
Deadlock невозможен. Если ключи попали в разные шарды — RLock независимые. Если в один — RLock/RLock совместимы (RWMutex). Это и есть смысл шардирования: горутины расходятся по разным мьютексам.
