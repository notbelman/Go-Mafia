Что выведет этот код и почему?
```go
func main() {
    var fib func(int) int
    fib = func(n int) int {
        if n <= 1 { return n }
        return fib(n-1) + fib(n-2)
    }
    fmt.Println(fib(6))
}
```
?
`8` — `fib(6)` это 8-е число Фибоначчи (0,1,1,2,3,5,8). Self-referencing через `var fib func(int) int` + последующее присвоение — единственный способ рекурсии для анонимной функции.
![[Рекурсия и мемоизация#^memo-self-ref]]

Что произойдёт если написать `fib := func(n int) int { ... fib(n-1) ... }` без предварительного `var`?
?
Ошибка компиляции: `fib` используется до объявления. При `:=` переменная доступна только после завершения объявления, поэтому рекурсия внутри тела невозможна — нужен паттерн `var fib func(...); fib = func(...) { ... fib(...) }`.
