## Паттерны синхронизации

#### [[Примитивный мьютекс]]
Мьютекс через atomic CAS без OS — как работает под капотом

#### [[Spin lock]]
Busy-wait через CAS, когда оправдан (критическая секция < 100 ns)

#### [[Семафор]]
Счётный семафор через channel (make(chan struct{}, N)) или atomic

#### [[Ticket lock]]
FIFO-честный лок: take ticket → wait until serving == ticket

#### [[Мьютекс Петерсона]]
Программный мьютекс без атомарных инструкций (2 потока)

#### [[CAS паттерны]]
Lock-free update: for { old = Load(); if CAS(old, new) { break } }

#### [[Recursive и Timed mutex]]
Рекурсивный мьютекс — антипаттерн в Go, timed lock через TryLock + timer

#### [[True sharing и False sharing]]
True sharing — реальная конкуренция за данные, false — артефакт cache line

#### [[Spurious wakeup]]
Ложные пробуждения в sync.Cond, всегда проверяй условие в цикле
