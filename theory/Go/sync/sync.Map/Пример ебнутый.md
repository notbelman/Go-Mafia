```
──────────────────────────────────────
НАЧАЛО
──────────────────────────────────────

read:  {}
dirty: nil
amended: false
misses: 0


──────────────────────────────────────
Store("a", 1)
──────────────────────────────────────

dirty == nil --> dirtyLocked() --> создаём пустой dirty
пишем a в dirty

read:  {}                          amended: true
dirty: { a: *1 }
misses: 0


──────────────────────────────────────
Store("b", 2)
──────────────────────────────────────

dirty есть --> просто пишем

read:  {}                          amended: true
dirty: { a: *1, b: *2 }
misses: 0


──────────────────────────────────────
Load("a")
──────────────────────────────────────

read: нет
amended: true --> лок --> dirty: нашли
misses++

read:  {}                          amended: true
dirty: { a: *1, b: *2 }
misses: 1


──────────────────────────────────────
Load("b")
──────────────────────────────────────

read: нет
amended: true --> лок --> dirty: нашли
misses++

read:  {}                          amended: true
dirty: { a: *1, b: *2 }
misses: 2


──────────────────────────────────────
Load("a")
──────────────────────────────────────

read: нет
amended: true --> лок --> dirty: нашли
misses++ --> misses (3) >= len(dirty) (2)

--> PROMOTION: dirty становится read

read:  { a: *1, b: *2 }            amended: false
dirty: nil
misses: 0
```
^example-first-promotion

```
──────────────────────────────────────
Store("c", 3)
──────────────────────────────────────

c нет в read --> лок
dirty == nil --> dirtyLocked():
  - копируем a: *1 (живой)
  - копируем b: *2 (живой)
dirty:  { a: *1, b: *2 }
пишем c в dirty

read:  { a: *1, b: *2 }            amended: true
dirty: { a: *1, b: *2, c: *3 }
misses: 0


──────────────────────────────────────
Delete("b")
──────────────────────────────────────

b есть в read --> entry.p = nil (atomic, без лока)
entry общий --> dirty тоже видит nil

read:  { a: *1, b: nil, c: *3 }    amended: true
dirty: { a: *1, b: nil, c: *3 }
misses: 0


──────────────────────────────────────
Load("x"), Load("y"), Load("z")
──────────────────────────────────────

3 промаха --> misses (3) >= len(dirty) (3)

--> PROMOTION

read:  { a: *1, b: nil, c: *3 }    amended: false
dirty: nil
misses: 0
```
^example-second-promotion

```
──────────────────────────────────────
Store("d", 4)
──────────────────────────────────────

d нет в read --> лок
dirty == nil --> dirtyLocked():
  - копируем a: *1 (живой)
  - b: nil --> НЕ копируем, ставим expunged
  - копируем c: *3 (живой)
пишем d в dirty

read:  { a: *1, b: expunged, c: *3 }    amended: true
dirty: { a: *1, c: *3, d: *4 }          <-- b нет!
misses: 0


──────────────────────────────────────
Store("b", 5)
──────────────────────────────────────

b есть в read, но entry.p == expunged
--> лок
--> unexpunge: entry.p = nil
--> добавляем b в dirty
--> entry.p = *5

read:  { a: *1, b: *5, c: *3 }          amended: true
dirty: { a: *1, b: *5, c: *3, d: *4 }
misses: 0


──────────────────────────────────────
Load промахи --> PROMOTION
──────────────────────────────────────

read:  { a: *1, b: *5, c: *3, d: *4 }   amended: false
dirty: nil
misses: 0

b снова живой, expunged исчез
```
^example-revival

**Последовательность операций в примере:**

1. Store("a", 1) — первый Store → dirty == nil → dirtyLocked() → amended = true ^example-step1
2. Store("b", 2) — dirty уже есть → просто пишем в dirty ^example-step2
3. Load("a"), Load("b"), Load("a") — 3 промаха → misses(3) >= len(dirty)(2) → **PROMOTION** ^example-step3
4. Store("c", 3) — dirty == nil → dirtyLocked() копирует a и b ^example-step4
5. Delete("b") — b в read → entry.p = nil, entry общий → nil виден и в dirty ^example-step5
6. Load("x"), Load("y"), Load("z") — 3 промаха → misses(3) >= len(dirty)(3) → **PROMOTION** с nil ^example-step6
7. Store("d", 4) — dirtyLocked() → b:nil → expunged, не копируется в dirty ^example-step7
8. Store("b", 5) — b expunged → unexpunge → добавить в dirty → записать ^example-step8
