32 бита упакованы в одно число: ^state-layout

```
+----------------------------------+---+---+---+
|            waiters               | S | W | L |
+----------------------------------+---+---+---+
  биты 3-31 (29 бит)                 2   1   0
```

| Бит  | Название | Значение | Описание                                 |
| :--- | :------- | :------- | :--------------------------------------- |
| 0    | Locked   | 1        | мьютекс захвачен                         |
| 1    | Woken    | 2        | кто-то разбужен и пытается захватить     |
| 2    | Starving | 4        | режим голодания                          |
| 3-31 | Waiters  | -        | количество спящих горутин (просто число) |

^state-bits

Биты 0-2 — флаги (Locked, Woken, Starving), биты 3-31 — счётчик ожидающих (29 бит, максимум ~537 миллионов горутин). ^state-bit-split

## Примеры
```
state = 0b00000000000000000000000000000000 = 0
            ^^^^^^^^^^^^^^^^^^^^^^^^^^^|||
             waiters = 0               SWL = 000
             --> свободен, никто не ждёт

state = 0b00000000000000000000000000000001 = 1
            ^^^^^^^^^^^^^^^^^^^^^^^^^^^|||
             waiters = 0               SWL = 001
             --> захвачен, никто не ждёт

state = 0b00000000000000000000000000001001 = 9
            ^^^^^^^^^^^^^^^^^^^^^^^^^^^|||
             waiters = 1               SWL = 001
             --> захвачен, 1 ждёт

state = 0b00000000000000000000000000010101 = 21
            ^^^^^^^^^^^^^^^^^^^^^^^^^^^|||
             waiters = 2               SWL = 101
             --> захвачен + starving, 2 ждут
```
^state-examples

## Как читать
```go
state & 1           // locked?
state & 2           // woken?
state & 4           // starving?
state >> 3          // сколько ждут
```
^state-read

## Как менять
```go
state + 8           // waiters++
state - 8           // waiters--
state | 1           // set locked
state &^ 1          // clear locked
```
^state-write
