GC Pacer — алгоритм выбора момента запуска GC.

**Задача:** завершить GC цикл ДО исчерпания heap target. Если запустить слишком поздно — heap вырастет больше цели. ^pacer-task

**Формула heap goal (Go 1.18+):**
```
Target = Live heap + (Live heap + stacks + globals) × GOGC/100
```
^pacer-formula

**Изменения в Go 1.18:** учитывает стеки и globals (раньше только heap).
^pacer-118-what

Лучше работает с маленькими heap — раньше маленький heap + большие стеки = GC запускался слишком редко. ^pacer-118-why

**Принудительный GC:** если не было GC > 2 минут — запускает sysmon (компонент runtime). ^pacer-forced

**runtime.GC():** если вызвать во время активного GC, по достижению фазы Sweep он запустится заново. ^pacer-runtime-gc
