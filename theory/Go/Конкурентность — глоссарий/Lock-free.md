- **Lock-free** — алгоритм без мьютексов. Гарантия: **хотя бы один** поток продвинется за конечное время. Основан на CAS ^lf-def
- Если мой CAS провалился — **чей-то CAS прошёл**. Система **всегда** движется вперёд ^lf-progress
- **Lock-free ≠ быстрее**. Высокий contention → много CAS-неудач. **Всегда бенчмаркай** ^lf-not-faster

---

```
Lock-based: горутина заснула с локом → ВСЕ стоят
Lock-free:  горутина заснула → остальные продолжают
```
^lf-vs-lockbased

## Паттерн "помоги другой горутине"

Если операция требует **2+ CAS** (как Push в очереди), другая горутина может **довернуть** чужой незавершённый CAS. Ключевой паттерн lock-free. ^lf-help-pattern

## Иерархия гарантий

```
Wait-free  ⊂  Lock-free  ⊂  Obstruction-free
   ↑              ↑              ↑
КАЖДЫЙ         хотя бы       один поток
за ≤N шагов    ОДИН           БЕЗ ПОМЕХ
               продвинется    продвинется
```
^lf-hierarchy
