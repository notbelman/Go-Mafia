## Конкурентность — глоссарий

#### [[Atomicity]]
Атомарность операции — выполняется целиком или никак

#### [[Happens-Before]]
Happens-before отношение — гарантия видимости изменений между горутинами

#### [[Data Race]]
Data race — конкурентный доступ без синхронизации, хотя бы одна запись

#### [[Race Condition]]
Race condition — результат зависит от порядка выполнения (логическая ошибка)

#### [[DR vs RC]]
Data Race vs Race Condition — разница: DR инструментируется, RC — нет

#### [[Critical Section]]
Критическая секция — код требующий эксклюзивного доступа

#### [[Mutex]]
Mutual exclusion — захват/освобождение, fairness, starvation

#### [[Semaphore]]
Счётный семафор, binary semaphore, acquire/release

#### [[Spinlock]]
Busy-wait лок через CAS, когда быстрее Mutex (очень короткие секции)

#### [[CAS]]
Compare-And-Swap — атомарное условное обновление, основа lock-free

#### [[Lock-free]]
Lock-free алгоритмы — прогресс гарантирован хотя бы для одного потока

#### [[Wait-free]]
Wait-free — прогресс гарантирован для ВСЕХ потоков за конечное число шагов

#### [[Deadlock]]
Взаимная блокировка, цикл ожидания, runtime детекция в Go

#### [[Livelock]]
Живая блокировка — потоки меняют состояние, но не продвигаются

#### [[Starvation]]
Starvation — поток не получает CPU/ресурс из-за других

#### [[Contention]]
Contention — конкуренция за один ресурс, снижает параллелизм

#### [[Race Detector]]
go race detector: -race флаг, ThreadSanitizer, false negatives
