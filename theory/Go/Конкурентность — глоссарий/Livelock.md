- **Livelock** — потоки НЕ заблокированы, **активно работают**, но не продвигаются. Бесконечно реагируют друг на друга ^ll-def
- Аналогия: два человека в коридоре уступают друг другу **в одну сторону** бесконечно ^ll-analogy
- Решение: **рандомизированный backoff** — ждать случайное время перед повтором ^ll-fix

---

```go
// Оба отпускают и пробуют заново ОДНОВРЕМЕННО → бесконечно
for {
    if mu1.TryLock() {
        if mu2.TryLock() { break }
        mu1.Unlock() // отпустил, попробую снова
    }
    // другая горутина делает зеркально
}
```
^ll-example

## Отличие от deadlock

| | Deadlock | Livelock |
|---|---|---|
| Потоки | **Спят** | **Работают** (CPU загружен) |
| Полезная работа | Нет | Нет |
| CPU | Свободен | Горит впустую |
| Обнаружение | Граф ожидания | Сложно (метрики) |
^ll-vs-deadlock

## Решение: random backoff

```go
time.Sleep(time.Duration(rand.Intn(100)) * time.Millisecond)
```
^ll-backoff

Потоки **десинхронизируются** → один захватит ресурс первым. Аналог: Ethernet CSMA/CD при коллизии. ^ll-desync
