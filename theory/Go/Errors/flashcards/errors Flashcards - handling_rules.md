Что не так с этим кодом?
```go
func GetRoute(lat, lon float64) error {
    err := validateCoords(lat, lon)
    if err != nil {
        log.Printf("validation failed: %v", err)
        return fmt.Errorf("invalid coords: %w", err)
    }
    return nil
}
```
?
Двойная обработка — ошибка залогирована И проброшена. Это нарушает правило «обрабатывать один раз». Нужно выбрать: либо логировать и вернуть `err`, либо пробросить с контекстом без лога.
