Что выведет этот код?
```go
m := make(map[int][128]byte)
for i := 0; i < 1_000_000; i++ {
    m[i] = [128]byte{}
}
for k := range m {
    delete(m, k)
}
runtime.GC()
var ms runtime.MemStats
runtime.ReadMemStats(&ms)
fmt.Println(ms.HeapAlloc > 200_000_000)
```
?
`true` — бакеты не освобождаются при delete, ~293MB висит в памяти. GC не трогает сами бакеты, только значения содержащие указатели.
