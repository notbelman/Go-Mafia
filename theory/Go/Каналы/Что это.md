Центральный объект синхронизации в Go, представляющий собой структуру, всегда аллоцируемую в **куче (heap)**. ^hchan-heap
Переменная канала в коде — это просто **указатель** на этот объект. ^hchan-pointer

## Под капотом

```go
type hchan struct {
    qcount   uint           // элементов сейчас
    dataqsiz uint           // размер буфера (cap)
    buf      unsafe.Pointer // кольцевой буфер
    elemsize uint16         // размер элемента
    elemtype *_type         // тип элемента (для типобезопасности)
    closed   uint32         // флаг закрытия
    sendx    uint           // индекс записи
    recvx    uint           // индекс чтения
    sendq    waitq          // очередь отправителей
    recvq    waitq          // очередь получателей
    lock     mutex          // мьютекс
}
```
^hchan-struct
