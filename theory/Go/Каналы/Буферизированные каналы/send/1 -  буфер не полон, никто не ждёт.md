### Send: буфер не полон, никто не ждёт

Обычная запись в буфер. Самый простой и частый путь для sender. ^send1-desc

```
ДО:
  буфер: [A, _, _]
  sendx: 1
  qcount: 1
  recvq: пусто

G1: ch <- B

  lock()
  buf[sendx] = v   → buf[1] = B
  sendx++          → sendx = 2
  qcount++         → qcount = 2
  unlock()

ПОСЛЕ:
  буфер: [A, B, _]
  sendx: 2
  qcount: 2
  
  G1: отправил ✓
```

^send1-steps

Операции под мьютексом: записываем `buf[sendx]`, инкрементируем `sendx`, инкрементируем `qcount`. ^send1-mutex-ops
