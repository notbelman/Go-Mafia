Что выведет этот код (время выполнения не важно — укажи результат сравнения)?
```go
type S struct {
    Data [1_000_000]byte
    ID   int
}
a := S{ID: 1}
b := S{ID: 2}
fmt.Println(a == b)
```
?
`false` — Go сравнивает поля слева направо: сначала 1 MB `Data` (равны), потом `ID` (1 ≠ 2) → ранний выход. Результат `false`, но было потрачено время на сравнение всего `Data`.
