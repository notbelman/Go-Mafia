- интерфейс = **контракт поведения**: набор сигнатур методов, которые тип должен реализовать ^iface-contract
- тип реализует интерфейс **неявно** (утиная типизация) — достаточно иметь нужные методы ^iface-implicit
- один тип может реализовать **несколько** интерфейсов; один интерфейс — **много** типов ^iface-many
- композиция интерфейсов: встраивание одного в другой (`ReadWriter = Reader + Writer`) ^iface-composition
- **Interface Guard** — compile-time проверка соответствия: `var _ Writer = (*MyWriter)(nil)` (приведение типа к nil без аллокации)^iface-guard-def
---

## Неявная реализация

```go
type Writer interface {
    Write(p []byte) (n int, err error)
}

type MyWriter struct{}

// MyWriter реализует Writer — ничего явно указывать не надо
func (w MyWriter) Write(p []byte) (n int, err error) {
    fmt.Println(string(p))
    return len(p), nil
}

var w Writer = MyWriter{}  // ок — есть метод Write
```

Нет `implements`, нет наследования. Есть метод → реализует. ^iface-no-implements

## Один тип — несколько интерфейсов

```go
type Reader interface { Read(p []byte) (int, error) }
type Writer interface { Write(p []byte) (int, error) }

type File struct{}
func (f File) Read(p []byte) (int, error)  { return 0, nil }
func (f File) Write(p []byte) (int, error) { return 0, nil }

var r Reader = File{}  // ✅
var w Writer = File{}  // ✅
```

## Композиция интерфейсов

```go
type ReadWriter interface {
    Reader
    Writer
}

var rw ReadWriter = File{}  // File реализует оба → реализует и ReadWriter
```

^iface-composition-example

## Interface Guard

```go
type Shape interface { Area() float64 }

type Circle struct{ Radius float64 }
func (c Circle) Area() int { return 0 }  // int, не float64!

// Compile-time проверка — не скомпилируется!
var _ Shape = (*Circle)(nil)
// error: Circle does not implement Shape (wrong type for Area)
```

Interface guard используется, чтобы явно выразить намерение, что тип реализует интерфейс, и защититься от случайных breaking changes. ^iface-guard-usecase

Особенно полезен когда реализуешь интерфейс из **сторонней библиотеки** — получаешь ошибку на этапе **компиляции**, а не в рантайме, если сигнатура метода перестанет совпадать. ^iface-guard-external
