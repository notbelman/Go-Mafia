- присваивание в интерфейс = **копирование** значения (адреса оригинала и копии разные)
- **pointer receiver** → нельзя присвоить значение (только указатель); **value receiver** → можно и то, и другое
- срез `[]int` **нельзя** присвоить в `[]any` — только поэлементно
- несравниваемый тип за интерфейсом (slice, map, func) в map-ключе или при == → **паника в рантайме**
- одинаковое имя метода, но **разная сигнатура** → type assertion не пройдёт (interface guard спасает)

---

## Копирование при присваивании

```go
value := 100
var i any = value    // копия value → в интерфейс
value = 200
fmt.Println(i)       // 100 — не изменился!

// Адреса разные:
fmt.Printf("%p\n", &value)                  // 0xc0000b2008
obj := (*int)((*[2]unsafe.Pointer)(unsafe.Pointer(&i))[1])
fmt.Printf("%p\n", obj)                      // 0xc0000b2048 — другой!
```

При присваивании значения в интерфейс происходит **копирование**: изменение оригинала не влияет на значение внутри интерфейса. Адреса оригинала и копии разные. ^copy-on-assign

## Pointer receiver — только указатель

```go
type Obj1 struct{}
func (o *Obj1) Do() {}  // pointer receiver

type Obj2 struct{}
func (o Obj2) Do() {}   // value receiver

type Doer interface { Do() }

var d Doer
d = &Obj1{}   // ✅ указатель
d = Obj1{}    // ❌ не скомпилируется! pointer receiver требует указатель

d = Obj2{}    // ✅ value receiver — можно значение
d = &Obj2{}   // ✅ value receiver — можно и указатель
```

Почему: pointer receiver подразумевает взятие адреса. У временного значения (rvalue) адрес взять нельзя. ^pointer-receiver-rule

Value receiver — можно передать и значение, и указатель. Pointer receiver — только указатель, иначе ошибка компиляции. ^value-vs-pointer-receiver

## Срез в срез интерфейсов — нельзя

```go
nums := []int{1, 2, 3}
// var ifaces []any = nums  // ❌ ошибка компиляции!

// Только поэлементно:
ifaces := make([]any, len(nums))
for i, v := range nums {
    ifaces[i] = v
}
```

`[]int` нельзя присвоить в `[]any` — это разные типы несмотря на то, что `int` реализует `any`. Конвертация только поэлементно. ^slice-to-any-slice

## Несравниваемый тип → паника

```go
// В map ключе:
m := map[any]struct{}{}
m[[]int{1, 2}] = struct{}{}  // panic: unhashable type []int

// При сравнении:
var a any = []int{1}
var b any = []int{1}
fmt.Println(a == b)  // panic: comparing uncomparable type []int
```

Компилятор не видит, что за `any` — проверка только в рантайме. ^uncomparable-panic

Несравниваемые типы: slice, map, func. За интерфейсом — паника при попытке сравнения или использования как ключа map. ^uncomparable-types

## Ловушка: одинаковое имя, разная сигнатура

```go
type Shape interface { Area() float64 }

type Circle struct{ R float64 }
func (c Circle) Area() int { return 0 }  // int, не float64!

var s any = Circle{R: 5}
_, ok := s.(Shape)  // ok = false! Area() int ≠ Area() float64
```

На первый взгляд метод `Area` есть. Но сигнатура отличается — **это разные методы**. ^sig-mismatch-trap

Interface guard ловит несовпадение сигнатур на этапе компиляции. ^interface-guard-benefit
