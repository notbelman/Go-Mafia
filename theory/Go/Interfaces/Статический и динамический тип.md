- **статический тип** = тип переменной (сам интерфейс), не меняется после объявления ^static-type-def
- **динамический тип** = что скрывается за интерфейсом (конкретная реализация), **может меняться** ^dynamic-type-def
- type assertion проверяет **динамический** тип, не статический ^assertion-dynamic
	- если T в assertion — интерфейс, проверяется что динамический тип **реализует** T (а не равен ему) ^assertion-interface-t
- сравнение интерфейсов(==) сравнивает **динамический тип + значение за интерфейсом** ^iface-eq
- концепция нужна для понимания рефлексии, type assertion, сравнения интерфейсов ^static-dynamic-usage

## Статический vs динамический

```go
type Stringer interface { String() string }

var s Stringer            // статический тип: Stringer
// динамический тип: nil (ничего не присвоено)

s = time.Now()            // статический: Stringer (не изменился!)
                          // динамический: time.Time

s = myDate{}              // статический: Stringer (всё тот же)
                          // динамический: myDate (изменился!)
```

Статический тип — навсегда. Динамический — меняется при каждом присваивании. ^static-forever-dynamic-changes

## Type assertion проверяет динамический тип

```go
type Fooer interface { Foo() }
type Barer interface { Bar() }

type Thing struct{}
func (t Thing) Foo() {}
func (t Thing) Bar() {}

var f Fooer = Thing{}  // статический: Fooer, динамический: Thing

// T (Thing) — конкретный тип: проверяет что динамический тип == Thing
v, ok := f.(Thing)     // ok = true

// T (Barer) — интерфейс: проверяет что динамический тип РЕАЛИЗУЕТ Barer
b, ok := f.(Barer)     // ok = true! Thing реализует Bar()
```

У `f` статический тип `Fooer` (нет метода `Bar`). Но type assertion смотрит на **динамический тип** `Thing`, у которого `Bar()` есть. ^assertion-static-vs-dynamic

## Сравнение интерфейсов

```go
var x any = 3
var y any = 3
fmt.Println(x == y)  // true — одинаковый динамический тип (int) и значение (3)

var z any = 3.0
fmt.Println(x == z)  // false — разные динамические типы: int vs float64
```

Сравниваются **оба**: динамический тип + значение за интерфейсом. ^iface-eq-example
