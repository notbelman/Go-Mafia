Компилятор генерирует **отдельную копию функции для каждого конкретного типа**. ^mono-definition

```go
func Sum[T int | float64](a, b T) T { return a + b }
```

Компилятор создаст `Sum_int` и `Sum_float64` — два отдельных прямых вызова. ^mono-example

Никакого itab, никакого indirect call. ^mono-no-itab

Поэтому дженерики по скорости ≈ статическая диспетчеризация. ^mono-perf-equiv
