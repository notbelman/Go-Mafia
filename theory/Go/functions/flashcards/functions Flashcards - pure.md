Что выведет этот код и является ли функция `add` чистой?
```go
var callCount int

func add(a, b int) int {
    callCount++
    return a + b
}

func main() {
    fmt.Println(add(2, 3))
    fmt.Println(add(2, 3))
    fmt.Println(callCount)
}
```
?
`5`, `5`, `2` — функция детерминированная (один вход → один выход), но **нечистая**: она модифицирует глобальную переменную `callCount`, что является побочным эффектом.
