Что произойдёт с переменной `number` после завершения функции `generator`, если замыкание ещё живо?
?
![[Замыкание#^closure-why-heap]]

Что выведет этот код?
```go
gen1 := generator(0)
gen2 := generator(100)
fmt.Println(gen1(), gen2(), gen1(), gen2())
```
(где generator — стандартный счётчик из примера)
?
`0 100 1 101` — каждый вызов `generator()` создаёт свой `number` в heap. gen1 и gen2 независимы.

Как правильно написать самовызывающуюся анонимную функцию (например, рекурсивный fib)?
?
![[Замыкание#^closure-self-ref-pattern]]

Что выведет этот код?
```go
funcs := make([]func(), 5)
for i := 0; i < 5; i++ {
    funcs[i] = func() { fmt.Println(i) }
}
for _, f := range funcs {
    f()
}
```
?
`5 5 5 5 5` — все замыкания захватили одну переменную `i`. К моменту вызова цикл уже завершился, `i == 5`.
![[Замыкание#^closure-loop-trap]]

Что выведет исправленная версия с передачей i как аргумента?
```go
for i := 0; i < 5; i++ {
    go func(n int) { fmt.Println(n) }(i)
}
// (предположим, есть time.Sleep для ожидания)
```
?
`0 1 2 3 4` (порядок может отличаться) — `i` передаётся по значению в момент вызова goroutine, создаётся копия `n`.
