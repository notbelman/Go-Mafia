[[memory Flashcards - size_classes]]

**Проблема без классов:**
Выделяешь 5, 20, 3 байта вперемешку. Удалил 20 — дыра. Кто-то просит 25 — не влезает. **Фрагментация.** ^sc-problem

**Решение:**
67 фиксированных размеров блоков: 8B, 16B, 24B, 32B, 48B... до 32KB. ^sc-count

Объект попадает в **ближайший подходящий** класс — просишь 5B, получаешь блок 8B. ^sc-rounding

Блоки одного размера лежат вместе. Удалил блок 8B → на его место встанет любой другой 8B. Нет фрагментации. ^sc-no-fragmentation

**Потери памяти:**
Минус — тратишь лишнее. Просил 5B, получил 8B → 3B пустуют. ^sc-waste-intro

Чем меньше объект относительно класса, тем больше потеря: 1B в классе 8B = 87%, 9B в классе 16B = 43%. ^sc-waste-small

Чем крупнее класс — тем меньше потеря: 32KB = всего 6%. ^sc-waste-large

**Объекты > 32KB:**
Не помещаются ни в один класс. Аллоцируются напрямую из mheap страницами по 8KB. ^sc-large-heap

Даже +1 байт сверх 32KB = дополнительная страница 8KB. ^sc-large-extra-page

```
Класс  Размер    Max waste     Пример
  1      8B        87%         1B объект → 7B пустует
  2     16B        43%         9B объект → 7B пустует
  3     24B        29%
  5     48B        31%         33B объект → 15B пустует
  7     80B        19%         66B объект → 14B пустует
 67    32KB         6%
```
