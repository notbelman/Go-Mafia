Три compile-time функции для получения информации о layout типов в памяти.

## Функции

**`unsafe.Sizeof(x)`** — размер типа в байтах. Не учитывает данные за указателем: для слайса вернёт 24 (размер заголовка), а не размер underlying array. ^sizeof-def

**`unsafe.Alignof(x)`** — выравнивание типа в байтах. CPU читает память блоками, адрес поля должен быть кратен этому числу. ^alignof-def

**`unsafe.Offsetof(s.field)`** — смещение поля от начала структуры в байтах. Работает только для полей структур. ^offsetof-def

Все три функции вычисляются в **compile-time** — это не runtime-вызовы. ^compile-time
