
1.  **Решардинг без простоя:** При добавлении нового узла хеш-слоты просто перемещаются с одного узла на другой. При этом соответствие «ключ -> слот» не меняется, что позволяет расширять систему с минимальным влиянием на производительность.
2.  **Протокол Gossip:** Узлы кластера постоянно обмениваются информацией о состоянии друг друга (кто доступен, кто упал), используя протокол Gossip.
3.  **Автоматический Failover:** Если большинство узлов фиксируют падение мастера, один из его подчинённых узлов (Slave) автоматически повышается до мастера.
