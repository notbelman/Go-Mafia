
| Проблема          | Суть                                    | Последствие                    | Решение                       |
| :---------------- | :-------------------------------------- | :----------------------------- | :---------------------------- |
| Cache Stampede    | Много запросов на один протухший ключ   | БД перегружена одним ключом    | Mutex lock, раннее обновление |
| Cache Penetration | Запросы несуществующих ключей           | Каждый запрос идёт в БД        | Кэшировать null, Bloom filter |
| Cache Avalanche   | Массовое истечение TTL одновременно     | БД перегружена всеми запросами | Jitter к TTL, прогрев         |
| Stale Data        | Кэш устарел, отдаём неактуальные данные | Пользователь видит старое      | Event-based + TTL             |
| Cold Start        | Кэш пустой после рестарта               | Все запросы идут в БД          | Прогрев, постепенная загрузка |
