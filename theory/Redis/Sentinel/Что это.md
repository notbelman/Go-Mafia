Для обеспечения высокой доступности (HA) Redis использует конфигурацию из ведущего узла (Main) и одного или нескольких подчинённых узлов (Secondary).

**заметка по топологии:**
Рекомендуется использовать нечётное количество узлов Sentinel (минимум 3 с кворумом 2). Это необходимо для предотвращения ситуаций, когда система не может принять решение из-за равного количества голосов «за» и «против».

⚠️ **Важно:** Репликация в Redis является **асинхронной**, поэтому при падении мастера существует риск потери данных, которые еще не успели скопироваться на подчинённый узел.
