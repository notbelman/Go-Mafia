title: Что такое ownership

Система владения — это альтернатива GC и ручному управлению (malloc/free). Она гарантирует безопасность памяти во время компиляции.

**Три золотых правила:**

1. У каждого значения есть переменная-владелец.
2. В один момент времени у значения может быть **только один** владелец.
3. Когда владелец выходит из области видимости (scope), значение удаляется (`drop`).

```
{
    let s1 = String::from("hello"); // s1 владеет строкой
    let s2 = s1; // MOVE: владение перешло к s2. s1 больше не валидна.

    // println!("{}", s1); // ОШИБКА КОМПИЛЯЦИИ: borrow of moved value
} // Здесь вызывается drop для s2. Память s1 уже не трогается.
```

**Senior-уровень: что происходит «под капотом»?**

- **Move Semantics:** В отличие от C++, где по умолчанию работает copy-конструктор, в Rust происходит побитовое копирование (shallow copy) указателя, длины и емкости из стека, при этом старая переменная помечается как «неинициализированная». Это предотвращает **double free error**.
- **Copy Trait:** Если тип реализует `Copy` (например, `i32`), значение не перемещается, а копируется в стеке. Оригинал остается валидным.
- **Drop Order:** В структурах данных поля удаляются в порядке их объявления. В Edition 2024 правила владения остаются фундаментально теми же, что и в прошлых редакциях, обеспечивая стабильность системы.

⚠️ **Нюанс** Владение напрямую связано с временем жизни (lifetimes). Rust должен гарантировать, что владелец живет дольше, чем любая ссылка на этот ресурс.
