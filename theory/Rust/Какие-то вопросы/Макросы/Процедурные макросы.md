Работают с **абстрактным синтаксическим деревом (AST)** - получают поток токенов на вход и возвращают новый поток токенов.

### Три вида

| Вид               | Синтаксис            | Применение                                          |
| ----------------- | -------------------- | --------------------------------------------------- |
| **Derive**        | `#[derive(MyMacro)]` | Автогенерация trait impl для структур/енамов        |
| **Attribute**     | `#[my_attr]`         | Модификация любого item (функции, структуры и т.д.) |
| **Function-like** | `my_macro!(...)`     | Похожи на декларативные, но с полной мощью Rust     |

### Особенности

- Живут в **отдельном крейте** с `proc-macro = true` в Cargo.toml
- Используют крейты `syn` (парсинг) и `quote` (генерация кода)
- Выполняются на этапе компиляции

### Когда использовать

- Сложная кодогенерация на основе структуры типа
- Автоимплементация трейтов (`Serialize`, `Debug` и т.д.)
- Кастомные атрибуты для фреймворков (как `#[tokio::main]`)

### Пример derive-макроса (сигнатура)
```rust
use proc_macro::TokenStream;

#[proc_macro_derive(MyTrait)]
pub fn my_trait_derive(input: TokenStream) -> TokenStream {
    // парсим input через syn
    // генерируем код через quote
    // возвращаем TokenStream
}
```
