Работают по принципу **паттерн-матчинга**: сопоставляют входные токены с шаблонами и подставляют соответствующий код.

### Когда использовать

- Простая кодогенерация
- Variadic функции (переменное число аргументов)
- Небольшие DSL
### Синтаксис
```rust
macro_rules! имя_макроса {
    (шаблон) => { код };
    (другой_шаблон) => { другой_код };
}
```

### Пример - создание вектора
```rust
macro_rules! my_vec {
    ( $( $x:expr ),* ) => {
        {
            let mut temp = Vec::new();
            $( temp.push($x); )*
            temp
        }
    };
}

let v = my_vec![1, 2, 3]; // раскроется в push(1), push(2), push(3)
```

### Фрагменты (fragment specifiers)

| Фрагмент | Что матчит |
|----------|------------|
| `$x:expr` | Выражение |
| `$x:ident` | Идентификатор |
| `$x:ty` | Тип |
| `$x:tt` | Один токен (token tree) |
| `$x:stmt` | Statement |
