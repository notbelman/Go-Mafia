title: iter() vs into_iter() vs iter_mut()
---
## iter()
- Возвращает &T
- Коллекция остаётся владельцем
- Только чтение
## iter_mut()
- Возвращает &mut T
- Коллекция остаётся владельцем
- Можно изменять элементы
## into_iter()
- Возвращает T (owned)
- Потребляет коллекцию
- После вызова коллекция недоступна
## Пример
```rust
let v = vec![1, 2, 3];
for x in v.iter() {}      // v доступен после
for x in v.iter_mut() {}  // v доступен после
for x in v.into_iter() {} // v moved, недоступен
```
## for loop
```rust
for x in &v {}      // iter()
for x in &mut v {}  // iter_mut()
for x in v {}       // into_iter()
```
