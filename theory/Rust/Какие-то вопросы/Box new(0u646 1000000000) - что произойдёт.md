## Stack overflow

Массив сначала создаётся на стеке, потом копируется в кучу.

1 млрд u64 = 8 GB на стеке → краш.

## Почему
```rust
Box::new(value)
//       ^^^^^ вычисляется на стеке
//             потом перемещается в кучу
```

## Решение
```rust
// vec! аллоцирует сразу в куче
let v: Box<[u64]> = vec![0u64; 1_000_000_000].into_boxed_slice();
```
