## Синхронно

Ждём завершения, поток заблокирован:
```rust
let data = file.read(); // поток спит пока диск читает
let resp = http.get();  // поток спит пока ждём сеть
```

## Асинхронно

Не ждём, делаем другое:
```rust
let data = file.read().await; // отдали управление, делаем другие задачи
let resp = http.get().await;  // поток не спит, выполняет другое
```

## Аналогия

Синхронно: стоишь у плиты, ждёшь пока вода закипит.

Асинхронно: поставил воду, пошёл резать овощи, вернёшься когда закипит.

## Зачем

Один поток может обрабатывать тысячи соединений. Не тратим ресурсы на ожидание I/O.

## Важно

Асинхронность ≠ параллельность. Async - про эффективное ожидание, не про одновременное выполнение.
