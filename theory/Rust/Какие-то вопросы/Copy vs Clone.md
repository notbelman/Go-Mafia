## Copy
- Побитовое копирование на стеке
- Неявное, автоматическое
- Только для простых типов: i32, bool, f64, &T
- После копирования оригинал остаётся валидным
## Clone
- Явное глубокое копирование
- Вызывается вручную: `.clone()`
- Может быть дорогим (выделение памяти)
- String, Vec, HashMap - только Clone
## Правило
Copy - маркерный трейт, требует Clone
```rust
#[derive(Copy, Clone)]
struct Point { x: i32, y: i32 }
```
## Почему String не Copy
Владеет данными в куче - побитовое копирование создаст два владельца одной памяти
