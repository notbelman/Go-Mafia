Задача может переехать на другой worker thread на любом .await:

1. Task выполняется на Worker A
2. Task делает .await, засыпает
3. Worker A берёт другую задачу
4. Task просыпается - попадает в очередь
5. Worker B (у которого очередь пуста) ворует задачу
6. Task продолжает выполнение на Worker B

Поэтому всё что живёт через .await должно быть Send.
