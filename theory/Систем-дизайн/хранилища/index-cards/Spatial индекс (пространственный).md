**Суть:** Индексация объектов в пространстве (координаты). Позволяет быстро искать "что находится рядом с точкой X,Y".

**Quad-tree (простейший вариант):**
1. Пространство делится на 4 квадранта
2. Если в квадранте слишком много объектов — делим ещё на 4
3. Если в соседних квадрантах мало объектов — сливаем обратно
4. Есть максимальная глубина (конфигурируется)

**Как поиск работает:**
Ищем точку (0.1, 0.7). По X = 0.1 → левая половина. По Y = 0.7 → верхняя половина. Сразу попадаем в нужный квадрант.

**Другие структуры:** R-деревья, KD-деревья, октодеревья (для 3D).

**Где применяется:**
- геолокация (найти ближайшие такси, рестораны)
- игры (game dev — поиск объектов в пространстве)
- карты (точки на карте)

**Связь:**
- [[GeoDNS]] — роутинг по координатам использует похожую идею пространственного поиска
