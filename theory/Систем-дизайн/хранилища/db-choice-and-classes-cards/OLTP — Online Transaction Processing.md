Обработка транзакций: создать заказ, обновить юзера, списать деньги. Много мелких быстрых запросов.

## Характеристики

- Тысячи одновременных пользователей, каждый трогает 1-10 строк
- Операции: INSERT, UPDATE, DELETE, SELECT по ключу
- Латентность: миллисекунды
- Данные актуальные (current state)
- ACID обязателен

## Хранение: строковое (row-based)

Строка целиком лежит рядом на диске. Читаешь юзера по id — одно чтение, все поля сразу.
```
| id | name  | email       | age |   ← вся строка в одном блоке
| 1  | Alice | a@mail.com  | 30  |
| 2  | Bob   | b@mail.com  | 25  |
```

Быстро: получить/обновить одну строку.
Медленно: `SELECT AVG(age) FROM users` — нужно прочитать ВСЕ строки, хотя нужна только одна колонка.
