**Суть:** Каждой записи сопоставляется битовая карта — набор бит (0/1), где каждый бит = дискретный признак.

**Пример:** Кафе с признаками: кальян, собаки, живая музыка, вегетарианская кухня. Каждый признак — один бит.
```
Кафе А: 1101 (кальян ✓, собаки ✓, музыка ✗, веган ✓)
Кафе Б: 0110 (кальян ✗, собаки ✓, музыка ✓, веган ✗)
```

**Как поиск работает:**
Пользователь выбирает "кальян + собаки". Маска: 1100. Побитовое AND по всем записям → мгновенно находим подходящие кафе.

**Почему быстро:**
- bitmap занимает копейки памяти, целиком помещается в RAM
- процессоры имеют AVX инструкции для векторных побитовых операций
- хоть 128, хоть 256 бит — пролетает мгновенно

**Когда использовать:** много дискретных признаков (да/нет). Фильтрация по комбинации булевых полей. Политики доступа (есть доступ / нет доступа).
