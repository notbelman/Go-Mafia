**Суть:** Полное время от отправки запроса клиентом до получения ответа. Сумма всех промежутков на всём пути.

**Из чего складывается:**
- T1: клиент → сервер (по сети)
- T2: сервер обрабатывает запрос
- T3: сервер → база данных (по сети)
- T4: база данных читает с диска
- T5: база данных → сервер (ответ)
- T6: сервер десериализует, собирает ответ
- T7: сервер → клиент (по сети)

Response time = T1 + T2 + T3 + T4 + T5 + T6 + T7

**Связь с latency:** response time включает в себя все [[Latency (задержка)]] на пути. Latency — это кусочек, response time — вся сумма.

| | Latency | Response time |
|--|---------|---------------|
| Что меряет | Задержка до начала обработки | Полный путь туда-обратно |
| Масштаб | Между двумя точками | Весь маршрут запроса |

**На практике:** чаще всего метрики строят по response time, а не по latency. Это то, что чувствует пользователь.
