**Зачем знать:** когда бизнес задаёт требование "запрос за 5 мс", сразу понимаем, какое железо подходит, а какое нет.

## [[Latency (задержка)]] (чтение 1 МБ) 

| Железо | Latency |
|--------|---------|
| RAM    | 250 000 нс (~0.25 мс) |
| SSD    | 1 мс |
| HDD    | 20 мс |

## [[Throughput (пропускная способность)]]

| Железо | Пропускная способность |
|--------|----------------------|
| HDD    | ~200 МБ/с |
| SSD (SATA) | ~500 МБ/с |
| SSD (NVMe) | ~1000 МБ/с |
| DDR3 RAM | ~20 000 МБ/с |

**Как применять:**
- Требование "ответ за 5 мс" → HDD (20 мс) не подходит → смотрим SSD или RAM
- Требование "пропускать 5 ГБ/с" → считаем, сколько дисков/плашек нужно
- Сеть тоже добавляет latency — если по сети не успеваем, остаётся только RAM

**Связь:**
- latency железа напрямую влияет на response time системы
- выбор железа зависит от требований: low latency → RAM, high throughput → можно SSD/HDD с параллелизмом
- [[Вертикальное масштабирование]] = покупаем железо получше
