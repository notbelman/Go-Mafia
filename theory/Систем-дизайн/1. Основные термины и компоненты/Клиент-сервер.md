**Суть:** Клиент запрашивает данные → сервер сам идёт в хранилище (БД, файл, что угодно), фильтрует, ищет, сортирует → отдаёт клиенту только то, что тот попросил. Лишних данных клиент не получает.

**Пример:** Клиент просит пользователя с ID 5 → сервер идёт в базу, находит именно пятого → отдаёт только его.

**Почему доминирует (~95% систем):** — клиент не нагружается логикой — безопасно: клиент может делать только то, что сервер позволяет ("двери" — аутентификация, авторизация, rate limiting) — сервер контролирует объём отдаваемых данных

**Связь с файл-сервером:** Отличие в одном — кто обрабатывает данные. Файл-сервер отдаёт сырьё, клиент-сервер отдаёт результат.

**На интервью:** Когда проектируете систему — по умолчанию это клиент-сервер, если задача явно не требует P2P или файл-сервер.
