**Суть:** Протокол API, где всё — и метод, и данные — передаётся в теле запроса в формате XML.

**Отличие от REST:**

| | REST | SOAP |
|--|------|------|
| Формат | JSON (легковесный) | XML (многословный) |
| Метод | HTTP глагол (GET, POST) | Всё в теле запроса |
| Читаемость | Высокая | Низкая |

**Пример SOAP запроса:**
```xml
<soap:Envelope>
  <soap:Body>
    <GetUser>
      <UserId>5</UserId>
    </GetUser>
  </soap:Body>
</soap:Envelope>
```

**Почему устарел:**
- многословный — XML тяжелее JSON
- трудночитаемый
- сложнее в отладке

**Где встречается:** legacy-проекты, банки, госсистемы — то, что писали 15–20 лет назад и не переписали.

**На собеседовании:** знать, что существует, уметь объяснить отличие от REST. Проектировать на SOAP не будут просить.
