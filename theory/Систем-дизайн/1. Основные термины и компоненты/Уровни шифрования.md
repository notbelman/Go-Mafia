**Открытая передача:** Без шифрования. Данные летят как есть. Любой на пути может прочитать.

**Транспортное шифрование:** Данные шифруются при передаче, расшифровываются на сервере. Сервер видит содержимое. Пример: HTTPS (TLS).

**Сквозное (E2E):** Шифрование на устройстве отправителя, расшифровка только на устройстве получателя. Сервер не видит содержимое — просто передаёт зашифрованный блоб. Пример: WhatsApp.

| | Кто видит данные | Пример |
|--|-----------------|--------|
| Открытое | Все | HTTP |
| Транспортное | Сервер + получатель | HTTPS |
| E2E | Только получатель | WhatsApp, Signal |
