**Суть:** FIFO + бит "used". Даём элементу второй шанс перед вытеснением.

**Как работает:**
1. Очередь FIFO. При каждом обращении к элементу ставим бит used = 1
2. Пора вытеснять → смотрим голову очереди:
   - бит = 0 → вытесняем
   - бит = 1 → сбрасываем в 0, перемещаем в конец очереди (второй шанс)
3. Повторяем, пока не найдём элемент с битом 0

**Пример:**
```
Очередь: [A(1), B(0), C(1), D(1)]
Вытеснение:
  A(1) → сброс в 0, в конец → [B(0), C(1), D(1), A(0)]
  B(0) → вытесняем B
```

**Плюс:** дешёвое улучшение FIFO — один бит на элемент.

**Минус:** если у всех бит = 1 → пройдём всю очередь, сбросим всем в 0, и только потом вытесним первого. В худшем случае — полный проход.

**Связь:**
- улучшение [[Random, FIFO, LIFO (базовые алгоритмы вытеснения)|FIFO]]
- [[Clock]] — оптимизация Second Chance (без перемещения элементов)
