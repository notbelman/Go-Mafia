**Суть:** Когда кэш только поднялся — он пустой. Прогрев — процесс наполнения кэша данными.

**Как прогревать:**
- наполнить тестовыми/реальными данными заранее
- постепенно пускать трафик, чтобы кэш заполнялся естественно
- blue-green деплой: новый инстанс прогревается, пока старый держит нагрузку

**Когда кэш вымывается:**
- сервис рестартнулся
- передеплоился
- упал / заООМился

**Опасность непрогретого кэша:** все запросы идут мимо кэша прямо в БД → БД может не выдержать нагрузку, если кэш до этого её прикрывал.

**Связь:**
- внутреннее кэширование → прогрев нужен после каждого рестарта
- внешнее кэширование → прогрев нужен только при падении самого кэша
- blue-green деплой помогает с постепенным прогревом
