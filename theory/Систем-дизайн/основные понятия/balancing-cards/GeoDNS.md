**Суть:** DNS, который знает географию. Направляет пользователя на ближайший датацентр по его IP-адресу.

**Как работает:**
1. Пользователь из США делает запрос
2. GeoDNS смотрит его IP
3. Идёт в GeoIP базу (например, MaxMind) — определяет регион
4. Отдаёт IP ближайшего датацентра (в США)

**Зачем:** latency зависит от расстояния. Москва → Нью-Йорк по сети ≈ 200 мс. Если есть датацентр в США — лучше направить туда.

**Пример:**
- пользователь из США → датацентр в США
- пользователь из Индии → датацентр в Индии

**Нужны ли несколько датацентров?** Зависит от требований. Если latency не критичен — можно один датацентр и не заморачиваться.

**Связь:**
- расширение DNS-балансировки
- решает проблему [[Latency (задержка)]] для географически распределённых пользователей
- связан с latency железа — сеть тоже добавляет задержку
