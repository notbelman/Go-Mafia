## Data intensive (IO bound)

**Суть:** Приложение перемалывает много данных. Основная нагрузка — ввод/вывод: диск, сеть, БД.

**Признаки:**
- нужно сохранять большие объёмы данных
- ресурсоёмкие операции с данными
- пользователям нужно искать, фильтровать во множестве данных
- приложение часто ждёт (сеть, диск), а не считает

**Пример:** поход в сторонние сервисы, сбор данных — приложение ждёт ответа по сети, CPU простаивает. Это IO bound.

## Compute intensive (CPU bound)

**Суть:** Приложение грузит процессор вычислениями.

**Признаки:**
- математические/физические уравнения
- алгоритмы на графах
- ML-инференс
- CPU загружен на максимум

**Зачем различать:** от типа нагрузки зависит, что масштабировать. IO bound — больше дисков, быстрее сеть, больше RAM. CPU bound — больше ядер, выше тактовая частота.

**Связь:**
- data intensive → выбор железа по [[Латенси и throughput железа]]
- compute intensive → выбор железа по CPU
- data intensive -> [[Горизонтальное масштабирование]]
- data intensive -> [[High throughput приложения]]
