**Суть:** Переменные внутри приложения, которые инкрементируются при событиях. Периодически отправляются в систему мониторинга → дашборды → алерты.

**Как работает:**
1. В коде заводим счётчик (например, requests_total)
2. При каждом запросе инкрементируем
3. Раз в N секунд метрика уходит в систему мониторинга (Prometheus, Graphite)
4. На дашборде видим графики
5. Настраиваем алерт: если error_rate > 5% → звонок дежурному

**Базовые метрики:**
- RPS / TPS / QPS — запросов в секунду
- Response time / Latency
- Success rate / Error rate
- CPU, RAM, Disk, Network, I/O
- Uptime / Downtime
- Размеры очередей, буферов
- Количество процессов, потоков

**Зачем:** без метрик не знаешь, что происходит с системой. Узнаёшь о проблемах от пользователей, а не от алертов.

**Overhead:** метрики — это дополнительная нагрузка (отправка, хранение), но без них в продакшне нельзя.
