
*   **Шардинг:** Данные распределяются между несколькими узлами (шардами).
*   **Хеш-слоты:** В кластере всегда фиксированное количество слотов — **16 384**.
*   **Алгоритм распределения:** Чтобы найти нужный узел для ключа, Redis вычисляет хеш ключа и делит его по модулю на количество слотов: `CRC16(key) % 16384`.
*   **Узлы:** Каждый ведущий узел (Master) в кластере отвечает за определенный диапазон этих слотов (например, Узел 1: 0–5460, Узел 2: 5461–10922 и т.д.).
