Запросы к данным, которых нет ни в кэше, ни в БД. Каждый запрос проходит насквозь в БД.
```
GET /user/999999999 → cache miss → SELECT ... → пусто → ничего не кэшируем
GET /user/999999999 → cache miss → SELECT ... → пусто → опять в БД
...бесконечно
```

Часто это атака — перебор несуществующих ID.

**Решение 1: кэшировать пустой результат.**
```go
item, err := db.GetItem(id)
if err == ErrNotFound {
    redis.Set(ctx, "item:"+id, "null", 1*time.Minute) // кэшируем отсутствие
    return nil, nil
}
```

**Решение 2: Bloom Filter** — быстрая проверка "точно нет в БД" перед запросом.
```
Запрос → Bloom filter → "точно нет" → сразу 404, в БД не идём
                       → "возможно есть" → проверяем кэш → БД
```
