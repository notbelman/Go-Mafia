
Это лог, в который записывается каждая полученная сервером операция записи.
*   **Как работает:** Команды буферизуются и сбрасываются на диск с помощью системного вызова `fsync()`.
*   **Плюсы:** Высокая надежность; данные можно восстановить почти в полном объеме.
*   **Минусы:** Файлы AOF гораздо больше по размеру, чем RDB; загрузка данных в память при старте происходит медленнее.
