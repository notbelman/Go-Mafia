Строка — это 16-байтный header: указатель на данные + длина. Без capacity (в отличие от slice). ^str-header-def

```go
// runtime/string.go
type stringStruct struct {
    str unsafe.Pointer  // указатель на []byte
    len int             // длина в байтах
}
```

```
s := "hello"

переменная s (16 байт)
┌─────────────────────────┐
│ str ──────────────┐     │
│ len = 5           │     │
└───────────────────│─────┘
                    ▼
	              ['h','e','l','l','o']  (readonly)
```

При присваивании `s2 := s` копируется только header (16 байт), данные шарятся: ^str-assign-share

```
s  ──► str ──┐
             ├──► ['h','e','l','l','o']
s2 ──► str ──┘
```

Substring тоже без копирования — новый header указывает на ту же память: ^str-substring-no-copy

```go
s := "hello"
s2 := s[1:4]  // "ell" — новый header, те же байты
```

Gotcha: большая строка держит память, даже если нужен маленький кусок. ^str-gotcha-memory

Почему нет поля capacity: строка иммутабельна, она не может расти. Capacity нужен только для мутабельных структур (slice), чтобы знать сколько места есть для append без реаллокации. ^str-no-cap
