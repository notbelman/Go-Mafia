- Go **разрешает** добавление/удаление во время range, но результат **непредсказуем** ^mutate-allowed
- добавление: элемент может попасть "до" текущей позиции (пропущен) или "после" (будет обработан → может добавить ещё) ^mutate-add-behavior
- удаление: зависит от порядка обхода. Код `if k == "foo" { delete(m, "bar") }` — потенциальный баг ^mutate-del-behavior
- `fmt.Println(map)` **сортирует ключи** — обманчивая стабильность (range — нет) ^mutate-println-sort
- **float как ключ:** потеря точности → `0.3 + 0.6 ≠ 0.9` → элемент не найдётся ^mutate-float-key

## Добавление во время range

```go
m := map[int]struct{}{0: {}, 1: {}, 2: {}}
for k := range m {
    m[k+10] = struct{}{}  // добавляем новый ключ
}
fmt.Println(len(m))  // 3? 6? 7? 10? — каждый запуск разный!
```
^mutate-add-example

Новый элемент может попасть в бакет **до** текущей позиции обхода (не увидим) или **после** (увидим → для него добавим ещё один → и так далее). ^mutate-add-reason

## Удаление во время range

```go
m := map[string]int{"foo": 1, "bar": 2, "baz": 3}
for k := range m {
    if k == "foo" { delete(m, "bar") }
    if k == "bar" { delete(m, "foo") }
    fmt.Println(k)
}
// Результат зависит от порядка обхода:
// если foo первый: foo, baz (bar удалён)
// если bar первый: bar, baz (foo удалён)
```
^mutate-del-example

## range копирует указатель

```go
for _, v := range m {
    v = 1000  // v — копия значения, map не изменится
}
```

Map — указатель, range копирует указатель → тот же hmap. Но `v` — копия value, как и со slice. ^mutate-range-copy

## Float как ключ

```go
v1, v2 := float32(0.3), float32(0.6)
m := map[float32]string{v1 + v2: "found"}

result := float32(0.9)
fmt.Println(m[result])  // "" — не найдено! 0.3+0.6 ≠ 0.9 из-за потери точности
```
^mutate-float-example

**Решения:** хранить цену в копейках (int), строка, структура `{рубли, копейки}`, массив байт. ^mutate-float-solutions

## fmt.Println — обманчивая стабильность

```go
m := map[int]int{1: 1, 2: 2, 3: 3}
fmt.Println(m)  // всегда map[1:1 2:2 3:3] — Println сортирует ключи!

for k := range m { fmt.Print(k) }  // 312, 231, 123 — каждый раз разный
```
^mutate-println-example
