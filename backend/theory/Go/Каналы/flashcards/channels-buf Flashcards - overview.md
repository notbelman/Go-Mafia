Что выведет этот код?
```go
ch := make(chan int, 3)
ch <- 1
ch <- 2
ch <- 3
fmt.Println(len(ch), cap(ch))
go func() { ch <- 4 }()
time.Sleep(10 * time.Millisecond)
fmt.Println(len(ch))
```
?
`3 3` затем `3` — после третьей записи буфер полон. Горутина с четвёртой записью блокируется. `len(ch)` остаётся 3, потому что никто не читает.
