Что выведет этот код?
```go
for {
    select {
    case v := <-ch:
        if v == 3 {
            break
        }
        fmt.Println(v)
    }
}
```
Канал отправляет: 1, 2, 3, 4.
?
`1`, `2`, `4` — при v==3 `break` выходит из `select`, но цикл `for` продолжается. Значение 3 не печатается, 4 печатается. Программа не завершается.
![[Нюансы каналов#^nuance-break-continue]]

Что выведет этот код?
```go
src := make(chan int, 1)
clone := src
src <- 42
fmt.Println(<-clone)
```
?
`42` — `clone` и `src` указывают на один и тот же `hchan`. Запись в `src` читается из `clone`.
