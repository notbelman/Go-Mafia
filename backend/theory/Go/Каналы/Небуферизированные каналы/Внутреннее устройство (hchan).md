При создании рантайм инициализирует `hchan` со следующими особенностями:

| Поле              | Значение             | Пояснение                               |
| :---------------- | :------------------- | :-------------------------------------- |
| `dataqsiz`        | `0`                  | Определяет канал как небуферизированный |
| `buf`             | `nil`*               | Память под данные не выделяется         |
| `qcount`          | всегда `0`           | Элементы не хранятся в буфере           |
| `sendq` / `recvq` | активно используются | Вся работа через очереди ожидания       |

^hchan-fields

`dataqsiz = 0` — именно это поле определяет канал как небуферизированный на уровне рантайма. ^hchan-dataqsiz

`buf = nil` — память под данные не выделяется, данные никогда не хранятся в канале, только копируются напрямую между стеками горутин. ^hchan-buf-nil

`qcount` всегда равен `0` — элементы не накапливаются в буфере канала. ^hchan-qcount

`sendq` и `recvq` — основные структуры небуферизированного канала: вся синхронизация происходит через очереди ожидающих горутин. ^hchan-queues

> *В режиме race detector `buf` указывает на собственный адрес для целей синхронизации. ^hchan-race-detector
