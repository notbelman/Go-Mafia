## Паттерны с каналами

#### [[Pipeline]]
Цепочка стадий: каждая читает из входного канала, пишет в выходной

#### [[Fan-Out и Tee]]
Fan-out: один канал → N горутин. Tee: дублировать поток в два канала

#### [[Fan-In]]
Слияние N каналов в один через горутину на каждый источник

#### [[Generator]]
Функция возвращает <-chan T, горутина пишет и закрывает канал

#### [[Worker pool]]
N горутин читают из jobs channel, пишут в results channel

#### [[Done channel]]
done <-chan struct{} для отмены — select { case <-done: return }

#### [[Or-done channel]]
Обёртка: читать из канала пока не done, без утечек

#### [[Rate Limiter]]
Ограничение RPS через time.Tick или token bucket на каналах

#### [[Single Flight]]
Дедупликация: если запрос уже в полёте — подождать его результат

#### [[Error Group]]
errgroup.Group — горутины + первая ошибка + отмена контекста

#### [[Barrier]]
Барьер: N горутин достигают точки, все ждут друг друга

#### [[Bridge]]
chan chan T → плоский <-chan T, объединяет поток каналов

#### [[Promise и Future]]
Async результат: горутина пишет в канал, caller читает когда нужно

#### [[Moving Letter]]
Передача ownership объекта через канал, один владелец в каждый момент

#### [[Transform и Filter]]
map/filter поверх канала — функциональные паттерны в Go

#### [[Graceful shutdown]]
Сигнал → drain в полёте → close → exit, порядок важен

#### [[Динамический select]]
reflect.Select для динамического числа каналов (unknown at compile time)
