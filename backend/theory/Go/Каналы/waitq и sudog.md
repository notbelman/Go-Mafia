**waitq** — очередь горутин, ждущих на канале. ^waitq-def
```go
type waitq struct {
    first *sudog  // голова (самый старый)
    last  *sudog  // хвост (самый новый)
}
```
^waitq-struct

Когда горутина попадает в очередь:

|                    | sendq                   | recvq                    |
| ------------------ | ----------------------- | ------------------------ |
| Небуферизированный | нет готового получателя | нет готового отправителя |
| Буферизированный   | буфер полон             | буфер пуст               |
^waitq-conditions

**sudog** — "билетик" горутины в этой очереди. ^sudog-def
Почему `sudog`, а не просто `*g`? 
Одна горутина может ждать на нескольких каналах в `select` — нужен отдельный "билетик" для каждого канала. ^sudog-why-not-g
```go
type sudog struct {
    g        *g              // кто ждёт
    elem     unsafe.Pointer  // данные (откуда/куда)
    c        *hchan          // какой канал
    isSelect bool            // в select?
    next     *sudog          // → следующий
    prev     *sudog          // ← предыдущий
}
```
^sudog-struct
