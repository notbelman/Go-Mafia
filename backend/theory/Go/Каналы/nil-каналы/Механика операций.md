
| Операция    | Поведение               | Причина                                          |
| :---------- | :---------------------- | :----------------------------------------------- |
| `<-ch`      | Блокировка **навсегда** | Нет `hchan` → `gopark` без возможности `goready` |
| `ch <- v`   | Блокировка **навсегда** | Нет `hchan` → `gopark` без возможности `goready` |
| `close(ch)` | **panic**               | `panic: close of nil channel`                    | ^nil-ops-table

Чтение из nil-канала (`<-ch`) вызывает `gopark`, но так как нет `hchan` и нет очереди — горутину никто не разбудит (`goready`). Горутина блокируется навсегда. ^nil-recv-mechanism

Запись в nil-канал (`ch <- v`) аналогична: `gopark` без `goready` — блокировка навсегда. ^nil-send-mechanism

Закрытие nil-канала (`close(ch)`) приводит к немедленному `panic: close of nil channel`. ^nil-close-panic
