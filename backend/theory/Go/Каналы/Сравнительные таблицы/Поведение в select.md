
| Состояние канала       | Поведение case                                        |
| :--------------------- | :---------------------------------------------------- |
| **Nil**                | Case **игнорируется**                                 |
| **Открытый, готов**    | Case может быть выбран                                |
| **Открытый, не готов** | Case участвует в ожидании                             |
| **Закрытый**           | Case **всегда готов** (receive возвращает zero value) |

### Крайние случаи select

| Ситуация | Результат |
|:---------|:----------|
| Все каналы nil, нет default | Deadlock |
| Все каналы nil, есть default | Выполняется default |
| Пустой `select {}` | Deadlock (блок навсегда) |
