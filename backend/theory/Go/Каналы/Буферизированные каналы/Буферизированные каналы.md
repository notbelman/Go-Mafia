Каналы с внутренним хранилищем (`make(chan T, n)` где `n > 0`), реализующие модель **асинхронной передачи данных**. ^bufchan-def

Отправитель может продолжить работу сразу после записи, если в буфере есть место — синхронизация с получателем не требуется. ^bufchan-async

---
### Области применения

| Сценарий | Зачем буфер |
|:---------|:------------|
| **Развязка (Decoupling)** | Producer и Consumer работают с разной скоростью |
| **Сглаживание пиков** | Буфер поглощает кратковременные всплески нагрузки |
| **Worker Pool** | Буферизированный канал как очередь задач |
| **Batch processing** | Накопление элементов перед обработкой |
| **Rate limiting** | Размер буфера = количество допустимых concurrent операций |
