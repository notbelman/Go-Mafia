При создании рантайм инициализирует `hchan` с активным буфером:

| Поле       | Значение         | Пояснение                          |
| :--------- | :--------------- | :--------------------------------- |
| `dataqsiz` | `n` (capacity)   | Размер буфера из `make(chan T, n)` |
| `buf`      | `unsafe.Pointer` | Указатель на кольцевой буфер       |
| `qcount`   | `0..dataqsiz`    | Текущее количество элементов       |
| `sendx`    | индекс записи    | Куда писать следующий элемент      |
| `recvx`    | индекс чтения    | Откуда читать следующий элемент    |

^hchan-fields

`dataqsiz` задаётся один раз при создании и не меняется — размер буфера иммутабелен. ^hchan-dataqsiz-immutable

`buf` — это указатель типа `unsafe.Pointer` на кольцевой буфер в памяти; при аллокации `hchan` и `buf` могут быть выделены одним непрерывным блоком. ^hchan-buf-ptr

`qcount` — единственное поле, которое читается атомарно при lock-free fast path в `select`. ^hchan-qcount-atomic
