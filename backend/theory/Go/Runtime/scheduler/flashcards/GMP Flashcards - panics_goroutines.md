Что выведет этот код и почему?
```go
func main() {
    defer func() { recover() }()
    go func() {
        panic("boom")
    }()
    time.Sleep(time.Second)
}
```
?
Процесс упадёт с `panic: boom`. `recover()` в `main` горутине ловит паники только своего стека. Паника в дочерней горутине раскручивает её собственный стек — `defer` в `main` бесполезен.

Что выведет этот код — строки перемешаются или нет?
```go
for i := 0; i < 5; i++ {
    go func(n int) {
        log.Println("goroutine", n)
    }(i)
}
time.Sleep(time.Second)
```
?
Строки не перемешаются — `log.Println` использует внутренний мьютекс, каждая запись атомарна. Если заменить на `fmt.Println` — строки могут перемешаться.
