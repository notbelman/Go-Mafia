Что выведет этот код? Статическая или динамическая диспетчеризация здесь?
```go
func Sum[T int | float64](a, b T) T { return a + b }
fmt.Println(Sum(3, 4))
fmt.Println(Sum(1.5, 2.5))
```
?
`7` и `4` — мономорфизация генерирует отдельные функции `Sum[int]` и `Sum[float64]` на этапе компиляции. Статическая диспетчеризация, нет boxing.
