- **Критическая секция** (КС) — участок кода, обращающийся к разделяемому ресурсу. Одновременно — **только один** поток ^cs-def
- КС должна быть **минимальной**: чем дольше держишь лок → тем больше contention ^cs-minimize
- **Нельзя** внутри КС: сетевые вызовы, I/O, тяжёлые вычисления — "самоубийство" (Балун) ^cs-no-io

---

```go
mu.Lock()
// ─── критическая секция ───
balance += amount
// ───────────────────────────
mu.Unlock()
```
^cs-example

## Гранулярность

**Грубая** (один мьютекс на всё): просто, но максимальный contention. ^cs-coarse

**Мелкогранулярная** (мьютекс на каждый ресурс): сложнее, меньше contention, риск deadlock. ^cs-fine

```
1 mutex на таблицу   → грубая (просто, медленно)
1 mutex на строку    → мелкая (сложно, быстро)
```
^cs-granularity

## Связь
- [[Mutex]] — защищает КС
- [[Contention]] — длинная КС = высокий contention
- [[Deadlock]] — мелкогранулярные локи → риск deadlock
