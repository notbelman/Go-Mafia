- структура — агрегирующий тип данных, объединяет логически связанные поля
- копирование объекта структуры = **побитовое копирование** всех полей (как присвоить каждое поле отдельно)
- два способа инициализации: позиционный `Point{1, 2}` и именованный `Point{X: 1, Y: 2}`
- именованный предпочтительнее: явнее, не ломается при добавлении полей
- теги полей — пары ключ-значение, по умолчанию пустая строка; подробнее — на занятии про рефлексию

---

## Два способа инициализации

```go
type Point struct {
    X int
    Y int
}

// Способ 1: позиционный
p1 := Point{1, 2}

// Способ 2: именованный (рекомендуемый)
p2 := Point{X: 1, Y: 2}
```

Если добавить поле `Z int` → способ 1 **сломается** (нужно менять все вызовы). Способ 2 — без изменений. ^struct-init-positional-breaks

## Побитовое копирование

```go
p1 := Point{X: 10, Y: 20}
p2 := p1  // побитовая копия всех полей

// Эквивалентно:
// p2.X = p1.X
// p2.Y = p1.Y
```

Для указателей, slice, map — копируется **заголовок** (указатель/хедер), не данные за ним. ^struct-copy-shallow

## Теги полей

```go
type User struct {
    Name  string `json:"name" validate:"required"`
    Email string `json:"email,omitempty"`
}
// теги — набор пар ключ:"значение"
// используются в сериализации, валидации, рефлексии
// по умолчанию тег = "" (пустая строка)
```

Теги полей — строки в формате `ключ:"значение"`, доступны через рефлексию. По умолчанию тег = `""` (пустая строка). ^struct-tags-format

## Локальные и анонимные структуры

```go
func handle() {
    // Локальная структура — видна только внутри функции
    type request struct { URL string }

    // Анонимная структура — нет имени
    resp := struct {
        Code int
        Body string
    }{Code: 200, Body: "ok"}
}
```

Анонимные структуры идентичны, если совпадают **порядок полей + типы + теги**. ^struct-anon-identity

Локальная структура — объявлена внутри функции, видна только в её scope. ^struct-local-scope
