- размер пустой структуры (сумма размеров типов её полей) = **0 байт** (в отличие от C++, где минимум 1 байт)
- адрес можно взять → указывает на **фиктивное место** в памяти (зависит от горутины/стека)
- все пустые структуры в одном контексте → **один и тот же адрес**
- пустая структура **последним полем** → Go добавляет padding (защита GC от утечек)
- `struct{}` и `[0]T` — оба занимают 0 байт

---

## Размер = 0, но адрес есть

```go
var e struct{}
fmt.Println(unsafe.Sizeof(e))  // 0
fmt.Println(&e)                // 0xc000... — адрес есть!
```

Размер пустой структуры в Go — 0 байт. В C++ минимум 1 байт (правило уникальности адреса). В Go адрес есть, но фиктивный. ^empty-size-zero

## Все пустые структуры → один адрес

```go
var a struct{}
var b struct{}
var c [0]int

fmt.Printf("%p\n", &a)  // 0x5a4e30
fmt.Printf("%p\n", &b)  // 0x5a4e30 — тот же!
fmt.Printf("%p\n", &c)  // 0x5a4e30 — тот же!
```

Все `struct{}` и `[0]T` в одном контексте (горутина/стек) указывают на один адрес. ^empty-same-addr

В другой горутине (другой стек) — адрес будет **другой**. Нет гарантии глобального единого адреса. ^empty-addr-goroutine

## Пустая структура последним полем → padding!

```go
type A struct {
    X int64       // 8 байт
    _ struct{}    // 0 байт — первое поле
}
// Размер: 8 байт ✅ (пустая структура в начале/середине — бесплатно)

type B struct {
    _ struct{}    // 0 байт — последнее поле
    X int64       // 8 байт
}
// Размер: 8 байт ✅

type C struct {
    X int64       // 8 байт
    _ struct{}    // последнее поле!
}
// Размер: 16 байт ⚠️ (+8 байт padding)
```

Пустая структура в начале/середине — бесплатна (0 байт padding). Пустая структура **последним полем** — Go добавляет padding до следующего выравнивания. ^empty-last-field-padding

## Почему padding в конце?

```
Память: [...X X X X X X X X][????????]
                              ↑
              struct{} указывает СЮДА — за пределы объекта!
```

Если взять `&obj._` → указатель на память **за объектом**. GC может посчитать, что эта чужая память ещё используется → утечка. Go добавляет padding, чтобы указатель оставался **внутри** объекта. ^empty-padding-gc-reason

## Практическое применение

```go
// Множество (set) — значения не нужны, только ключи
set := make(map[string]struct{})
set["key"] = struct{}{}
// struct{} занимает 0 байт → экономия памяти vs map[string]bool
```

`map[string]struct{}` используют как set: значения не нужны, `struct{}` занимает 0 байт vs `bool` (1 байт). ^empty-set-pattern
