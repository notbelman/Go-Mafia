- **флаги** (true/false) — простейший способ, но хранит только 2 состояния ^sig-flags
- **статусы** (константы) — расширение флагов, зарезервированные значения для разных ошибок ^sig-statuses
- **optional** — структура-обёртка с has_value/get_value (есть в Rust, C++ и др.) ^sig-optional
- **errno** — глобальная переменная, не засоряет сигнатуру, но нужна синхронизация ^sig-errno
- **структура с контекстом** — отдельный тип с полями, описывающими что именно пошло не так ^sig-struct
- в Go используется интерфейс `error` — структура с методом `Error() string` ^sig-go-error

## Флаги

```go
func divide(a, b int) (int, bool) {
    if b == 0 {
        return 0, false  // false = что-то пошло не так
    }
    return a / b, true
}
```

Просто, но не информативно: false — это «деление на ноль» или «число чётное»? Непонятно. ^sig-flags-drawback

## Статусы

```go
const (
    StatusOK = iota
    StatusZero
    StatusEven
)

func divide(a, b int) (int, int) {
    if b == 0 { return 0, StatusZero }
    if b%2 == 0 { return 0, StatusEven }
    return a / b, StatusOK
}
```

Расширение флагов — теперь можно различать причины. Используется в C++ (boost), HTTP-коды и т.д. ^sig-statuses-example

## Optional

```go
type Optional[T any] struct {
    value   T
    present bool
}

func (o Optional[T]) HasValue() bool { return o.present }
func (o Optional[T]) Get() T         { return o.value }
```

Обёртка: есть значение → present=true, нет → present=false. Есть в Rust (`Option`), C++ (`std::optional`). ^sig-optional-example

## Errno (глобальная переменная)

```go
var errno int

func divide(a, b int) int {
    if b == 0 {
        errno = StatusZero
        return 0
    }
    errno = StatusOK
    return a / b
}
// Сигнатура чистая, но нужно не забыть проверить errno
// + синхронизация при нескольких горутинах
```

Подход из C — не засоряет сигнатуру, но костыльно. Главная проблема — нужна синхронизация при конкурентном доступе. ^sig-errno-problem

## Структура с контекстом (подход Go)

```go
type DivisionError struct {
    Msg  string
    A, B int
}

func (e *DivisionError) Error() string {
    if e.Msg != "" { return e.Msg }
    return fmt.Sprintf("cannot divide %d by %d", e.A, e.B)
}
```

Когда нужен дополнительный контекст — отдельный тип с полями. В Go это интерфейс `error`. ^sig-struct-example
