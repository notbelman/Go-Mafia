Потокобезопасная map, оптимизированная для специфических сценариев. ^syncmap-def

## Когда использовать

| Сценарий                                                 | sync.Map лучше?          |
| :------------------------------------------------------- | :----------------------- |
| Read-heavy (много чтений, мало записей)                  | Да                       |
| Disjoint keys (горутины работают с разными ключами)      | Да                       |
| Write-heavy                                              | Нет, лучше map + RWMutex |
| Нужен Len(), итерация                                    | Нет                      |
^syncmap-when-table
