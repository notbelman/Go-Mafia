Эксклюзивная блокировка — только одна горутина может владеть мьютексом. ^struct-exclusive

```go
type Mutex struct {
    state int32   // состояние: флаги + счётчик ожидающих
    sema  uint32  // семафор для сна/пробуждения
}
// Пример Zero Value
var mu sync.Mutex  // сразу готов, state=0, sema=0
```
^struct-fields

Mutex готов к использованию сразу — Zero Value (state=0, sema=0) означает «свободен». Копирование Mutex после использования — undefined behavior, поэтому передавать нужно только указатель. ^struct-zero-value

Mutex **не reentrant**: одна горутина не может захватить лок дважды — это deadlock. ^struct-not-reentrant

###### Ошибки

| Ситуация                        | Результат               |
| :------------------------------ | :---------------------- |
| Unlock() без Lock()             | panic                   |
| Lock() дважды в одной горутине  | deadlock (не reentrant) |
| Копирование после использования | undefined behavior      |

^struct-errors
