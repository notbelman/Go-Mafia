- **функция высшего порядка** (ФВП) — принимает функцию как аргумент и/или возвращает функцию ^hof-def
- **предикат** — функция, возвращающая `bool` ^predicate-def
- предикаты удобны для обобщения: одна сортировка + предикат → asc/desc ^predicate-generalize
- ФВП — основа для forEach, map, filter, reduce в Go ^hof-patterns

## Предикат — обобщение поведения

```go
// Сортировка вставками — один код, разное поведение через предикат
func insertionSort(arr []int, less func(a, b int) bool) {
    for i := 1; i < len(arr); i++ {
        key := arr[i]
        j := i - 1
        for j >= 0 && less(key, arr[j]) {
            arr[j+1] = arr[j]
            j--
        }
        arr[j+1] = key
    }
}

// По возрастанию
insertionSort(data, func(a, b int) bool { return a < b })

// По убыванию — тот же код!
insertionSort(data, func(a, b int) bool { return a > b })
```

Без предиката пришлось бы писать две функции сортировки. ^predicate-without

## Функция высшего порядка — forEach

```go
func forEach(arr []int, fn func(int) int) []int {
    result := make([]int, len(arr))  // копия — чистая функция
    for i, v := range arr {
        result[i] = fn(v)
    }
    return result
}

squares := forEach([]int{1, 2, 3, 4}, func(x int) int {
    return x * x
})
// [1, 4, 9, 16]
```

`forEach` — ФВП: принимает `fn` как аргумент. `fn` применяется к каждому элементу. ^foreach-hof

## ФВП: принимает + возвращает

```go
func multiplier(n int) func(int) int {
    return func(x int) int { return x * n }
}

double := multiplier(2)  // возвращает функцию
triple := multiplier(3)

double(5)  // 10
triple(5)  // 15
```

`multiplier` — ФВП: возвращает функцию. Используется в каррировании и partial application. ^hof-return-func
