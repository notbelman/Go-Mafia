Что выведет этот код?
```go
func bump(x int) { x++ }

func main() {
    n := 5
    bump(n)
    fmt.Println(n)
}
```
?
`5` — аргумент копируется, `x++` изменяет локальную копию, оригинал `n` не затронут.
![[Функции основы#^copy-on-pass]]

Что выведет этот код?
```go
func modify(s []int) { s[0] = 99 }

func main() {
    s := []int{1, 2, 3}
    modify(s)
    fmt.Println(s[0])
}
```
?
`99` — передаётся копия заголовка slice, но заголовок указывает на тот же backing array. Запись через копию заголовка меняет оригинальный массив.
