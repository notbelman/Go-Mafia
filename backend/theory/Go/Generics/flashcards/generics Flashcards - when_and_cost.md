Что выведет этот код, сколько функций сгенерирует компилятор?
```go
func sum[T int | float64](a, b T) T { return a + b }

fmt.Println(sum(1, 2))
fmt.Println(sum(1.5, 2.5))
```
?
`3` и `4` — компилятор генерирует две отдельные функции в ассемблере: `sum[int]` и `sum[float64]`. Бинарник содержит обе. Рантайм оверхед нулевой — каждая работает как написанная вручную.
