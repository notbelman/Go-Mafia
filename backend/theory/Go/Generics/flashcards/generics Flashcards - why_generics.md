Что выведет этот код и как компилятор это обеспечивает?
```go
func max[T int | uint](a, b T) T {
    if a > b { return a }
    return b
}
fmt.Println(max(uint(3), uint(1)))
```
?
`3` — компилятор выводит `T=uint` из аргументов и генерирует специализацию `max[uint]`. Вы пишете одну функцию, компилятор создаёт реализацию для конкретного типа.
