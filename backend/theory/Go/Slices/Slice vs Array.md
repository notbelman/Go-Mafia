- массив — **value type**, фиксированный, `[3]int` и `[4]int` — **разные типы**
- размер массива **вшит в тип**, не хранится в памяти → `len()` = константа на этапе компиляции
- массив **НЕ указатель** — просто значения подряд, доступ: `ptr + idx * sizeof(elem)`
- передача: массив копирует **ВСЕ данные**, slice — **только header (24 байта)**
- массивы **comparable** (==), слайсы — нет
- `make`, `append` — только для слайсов, не для массивов

## Размер — часть типа array

`[3]int` и `[4]int` — **разные типы**. Размер и тип элемента вшиты в тип, не хранятся в памяти рядом с данными. ^array-size-in-type

Поэтому `len()` для массива подставляется компилятором как константа на этапе компиляции. ^array-len-compile-time

```go
var a [3]int
var b [4]int
a = b  // ❌ compile error: разные типы
```

## Массив — НЕ указатель

Массив — просто множество значений подряд в памяти. Никаких указателей внутри. ^array-not-pointer

Доступ по индексу: `addr = начало_массива + index * sizeof(элемент)` — прямая адресная арифметика. ^array-index-access

## Сравнимость

Массивы **comparable**: == сравнивает все элементы поэлементно. ^array-comparable

Слайсы **не comparable**: == работает только с `nil`. Для сравнения слайсов нужен `slices.Equal` или ручной цикл. ^slice-not-comparable

## Передача в функцию

Передача массива в функцию копирует **все данные** — функция получает независимую копию. ^array-pass-copy

Передача слайса копирует только **header (24 байта)**: ptr + len + cap. Данные shared. ^slice-pass-header

```go
// Array — копируется полностью
func modify(arr [3]int) { arr[0] = 999 }
a := [3]int{1, 2, 3}
modify(a)           // a не изменился — работали с копией

// Slice — копируется header, данные общие
func modify(s []int) { s[0] = 999 }
s := []int{1, 2, 3}
modify(s)           // s[0] = 999 — изменился!
```

## Zero value

Zero value массива — `[N]T{}`: все элементы равны нулевому значению типа T. ^array-zero-value

Zero value слайса — `nil`: ptr=nil, len=0, cap=0. ^slice-zero-value

## make и append

`make` и `append` работают только для слайсов, не для массивов. ^slice-make-append-only

## Когда что использовать

| Используй Array | Используй Slice |
|:----------------|:----------------|
| Размер известен в compile time | Размер динамический |
| Криптография, хэши `[32]byte` | Почти везде |
| Нужна comparable семантика | Нужна эффективная передача |
