| Поле | Что значит                              | Получить |
| :--- | :-------------------------------------- | :------- |
| len  | Сколько элементов доступно через индекс | `len(s)` |
| cap  | Сколько можно вырастить без реаллокации | `cap(s)` |

`len` — количество элементов, доступных через индекс. ^lencap-len-def
`cap` — сколько элементов вмещает underlying array, начиная от `ptr`. Пока `len < cap`, `append` не делает реаллокацию. ^lencap-cap-def

```go
s := make([]int, 2, 5)
s[0] = 1      // ✅ OK, индекс < len
s[3] = 4      // ❌ panic: index out of range (3 >= len)
s = s[:4]     // ✅ OK, можно расширить до cap
s = s[:6]     // ❌ panic: 6 > cap
```

[[slice Flashcards - len_cap]]

Индексирование (`s[i]`) работает только в пределах `len` — иначе паника. Расширение через reslice (`s[:n]`) работает до `cap`, но не выше. ^lencap-index-bounds
