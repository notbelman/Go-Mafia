|                 | Array             | Slice                     | Map                           |                |
| :-------------- | :---------------- | :------------------------ | :---------------------------- | -------------- |
| Тип             | Value type        | Reference-like (header)   | Reference type (указатель)    |                |
| Размер          | Фиксированный     | Динамический              | Динамический                  |                |
| Zero value      | `[N]T{}` (нули)   | `nil`                     | `nil`                         |                |
| Comparable      | ✅ == по элементам | ❌ только с `nil`          | ❌ только с `nil`              |                |
| Ключ в мапе     | ✅ да              | ❌ нет                     | ❌ нет                         |                |
| Передача в ф-ю  | Копия ВСЕХ данных | Копия header (24 байта)   | Копия указателя (8 байт)      |                |
| Мутация в ф-и   | Не видна снаружи  | Элементы — да, len — нет  | Видна снаружи                 |                |
| Упорядоченность | По индексу        | По индексу                | Нет (рандомный порядок)       |                |
| Под капотом     | Непрерывный блок  | Header → underlying array | Header → buckets (hash table) | ^compare-table |
[[slice Flashcards - array_vs_slice_vs_map]]
**Типы передачи в функцию:** Array передаёт копию ВСЕХ данных (дорого для больших массивов), Slice передаёт копию header (24 байта: ptr + len + cap), Map передаёт копию указателя (8 байт). ^pass-to-func

**Мутация в функции:** Array — мутации не видны снаружи (передана копия). Slice — мутации элементов видны снаружи (шарят underlying array), но изменение len не видно. Map — все мутации видны снаружи (передан указатель). ^mutation-in-func

**Comparable:** Array можно сравнивать оператором `==` (поэлементно) и использовать как ключ в map. Slice и Map — нельзя сравнивать (только с `nil`), нельзя использовать как ключ в map. ^comparable

**Zero value:** Array — `[N]T{}` (все элементы в zero value). Slice — `nil` (len=0, cap=0, ptr=nil). Map — `nil` (нельзя писать в nil map, можно только читать — вернёт zero value). ^zero-value
