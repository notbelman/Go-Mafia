Что выведет этот код? Изменится ли `a` после вызова функции?
```go
func modify(arr [3]int) {
    arr[0] = 999
}
a := [3]int{1, 2, 3}
modify(a)
fmt.Println(a[0])
```
?
`1` — массив передаётся по значению, функция получает копию. Оригинал `a` не изменён.

Что произойдёт с адресом массива на стеке если стек горутины вырастет? Как это отличается от C/C++?
?
![[Array аллокация и копирование#^array-stack-relocation]]

Что выведет этот код (адреса будут разными, важно — одинаковые или нет)?
```go
a := [3]int{1, 2, 3}
p1 := &a
_ = make([]byte, 1<<20)
p2 := &a
fmt.Println(p1 == p2)
```
?
`false` — после роста стека горутины массив переезжает на новое место. Адрес изменится. В C/C++ стековые адреса стабильны.
