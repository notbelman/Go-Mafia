**Dockerfile** — это текстовый файл, содержащий последовательный набор инструкций (команд), по которым Docker автоматически собирает готовый образ (Image). Вместо того чтобы вручную собирать архив с приложением, разработчик описывает шаги сборки в этом файле.

**Основные инструкции:**

- **`FROM`**: Задает базовый образ (фундамент). Обычно это готовый образ из Docker Hub с ОС или средой исполнения (например, `FROM openjdk:17`).
- **`WORKDIR`**: Устанавливает рабочую директорию внутри образа. Все последующие команды будут выполняться в ней.
- **`COPY`**: Копирует файлы или папки с вашего компьютера внутрь образа.
- **`ENTRYPOINT`**: Определяет основную команду, которая будет выполнена при запуске контейнера.

**Пример Dockerfile для Java-приложения:**

```
# 1. Берем базу, где уже есть Linux и Java
FROM openjdk:17-alpine

# 2. Создаем папку приложения внутри образа
WORKDIR /app

# 3. Копируем наш скомпилированный файл внутрь
COPY build/libs/my-app.jar app.jar

# 4. Команда для старта приложения при запуске контейнера
ENTRYPOINT ["java", "-jar", "app.jar"]
```

**Процесс сборки:** Чтобы превратить Dockerfile в Image, используется команда `docker build`. Точка в конце указывает, что Dockerfile нужно искать в текущей директории.

```
docker build -t my-app-name:v1 .
```
