**Docker Compose** — это инструментарий для определения и запуска многоконтейнерных (multi-container) приложений. Если Dockerfile описывает, как собрать один конкретный образ, то Docker Compose описывает, как целая группа контейнеров (например, backend, база данных и кэш) должна работать вместе как единая система.

**Для чего он нужен (решаемые проблемы):**

- **Сложность архитектуры**: Реальное приложение редко состоит из одного процесса. Обычно это связка из кода (Java/Python), базы данных (PostgreSQL) и хранилища (Redis). Запускать каждый из них вручную через `docker run` долго и неудобно.
- **Оркестрация на одной машине**: Compose позволяет одной командой поднять всю «экосистему» проекта со всеми правильными настройками, версиями и связями между компонентами.
- **Управление зависимостями**: Можно указать порядок запуска (например, приложение не должно стартовать раньше, чем поднимется база данных).

**Пример конфигурации (`docker-compose.yaml`):** _(Примечание: структура YAML-файла является общепринятым стандартом индустрии)_.

```
version: '3.8'
services:
  # Наше приложение из Dockerfile
  backend-app:
    build: .
    ports:
      - "8088:8088"
    depends_on:
      - postgres-db

  # Готовый образ базы данных из Docker Hub
  postgres-db:
    image: postgres:15-alpine
    environment:
      POSTGRES_PASSWORD: password
```

**Основные команды:**

- `docker-compose up`: Сборка (если нужно), создание и запуск всех контейнеров, описанных в файле.
- `docker-compose stop`: Остановка всех сервисов приложения.
- `docker-compose down`: Полная остановка и удаление контейнеров и созданных для них виртуальных сетей.
