Платформа контейнеризации. Упаковывает приложение + все зависимости в изолированный контейнер.

**Зачем:** "У меня работает" → работает везде одинаково (dev/staging/prod)

**Контейнер vs VM:**
- VM - виртуализация железа, свой kernel, тяжёлые (гигабайты)
- Container - виртуализация на уровне ОС, общий kernel, лёгкие (мегабайты)

**Под капотом (Linux):**
- namespaces - изоляция (pid, net, mnt, user)
- cgroups - лимиты ресурсов (cpu, memory)
- overlay fs - слоистая файловая система
