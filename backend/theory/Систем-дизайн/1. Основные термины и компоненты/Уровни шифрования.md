- **Открытая передача** — без шифрования, данные летят как есть. Любой на пути может прочитать (HTTP)
- **Транспортное** — шифруются при передаче, расшифровываются на сервере. Сервер видит содержимое (HTTPS/TLS)
- **Сквозное (E2E)** — шифрование на устройстве отправителя, расшифровка только на устройстве получателя. Сервер **не видит** содержимое (WhatsApp, Signal)

---

| | Кто видит данные | Пример |
|---|---|---|
| Открытое | Все | HTTP |
| Транспортное | Сервер + получатель | HTTPS (TLS) |
| E2E | Только получатель | WhatsApp, Signal |

### Открытая передача
Без шифрования. Данные летят как есть. Любой на пути может прочитать.

### Транспортное шифрование
Данные шифруются при передаче, расшифровываются на сервере. Сервер видит содержимое. Пример: HTTPS (TLS). [[Проксирование|Reverse proxy]] часто делает SSL termination — расшифровывает трафик на входе.

### Сквозное (E2E)
Шифрование на устройстве отправителя, расшифровка только на устройстве получателя. Сервер не видит содержимое — просто передаёт зашифрованный блоб. Пример: WhatsApp, Signal.
