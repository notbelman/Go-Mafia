Дополнительные инструменты внутри БД. Маленькие кубики, которые иногда проще использовать вместо кода в приложении.

## Хранимые процедуры
Код, написанный на уровне БД. Работает быстрее (нет сетевого запроса). Минусы: сложно тестировать, версионировать, искать специалистов.

## Триггеры
Автоматические действия при INSERT / UPDATE / DELETE. Пример: при вставке ставки — автоматически обновить статистику. Не нужно писать логику в приложении.

## Materialized View
Кэширование результата тяжёлого запроса внутри БД. Один раз посчитал SELECT с JOIN и GROUP BY — результат сохранён. При повторном запросе — отдаётся мгновенно.

**Проблема:** как обновлять? Варианты: при каждом изменении (refresh), по расписанию, вручную. Зависит от БД.

## Watch API
Некоторые key-value БД (etcd) позволяют подписаться на изменение ключа. Изменился IP кластера → в приложение приходит event. Полезно для service discovery и конфигурации.

## Cron / Scheduler
Периодическое выполнение задач. Пример: раз в час удалять старые данные. Либо средствами БД, либо внешний процесс, который ходит и чистит по таймстемпу.
