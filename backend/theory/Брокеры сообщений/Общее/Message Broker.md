## Что это

Посредник между сервисами для асинхронного обмена. Берёт на себя хранение и маршрутизацию сообщений.
```
Producer → [Broker] → Consumer
              ↓
         хранит на диск
         маршрутизирует
         буферизирует
```

## Ключевые характеристики

| Характеристика | Что даёт |
|----------------|----------|
| Декаплинг | Продюсер не знает адрес/API/состояние консьюмера. Можно добавлять подписчиков без изменения отправителя |
| Асинхронность | Продюсер свободен сразу после записи в брокер |
| Load Leveling | Буфер для сглаживания пиков. Консьюмеры работают в своём темпе |
| Надёжность | Сохранение на диск, получатель может быть offline |
| Изоляция | Нет "эффекта домино" при тормозах консьюмера |

## Цена

- Усложнение инфраструктуры
- Увеличение latency
- Eventual consistency (не немедленный результат)
- Нужна идемпотентность (дубли при сбоях сети)
- Сложнее отладка, нужен мониторинг
