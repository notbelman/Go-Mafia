- **Heap** — файл таблицы на диске, разбит на **страницы по 8 КБ**. Строки лежат в порядке вставки, DELETE оставляет дыру
- **TID (ctid)** — адрес строки: `(номер страницы, номер указателя)`. Индекс хранит `ключ → TID`
- Страница: header → указатели (растут вниз) → свободное место → данные строк (растут вверх)
- Индекс — **отдельный файл** рядом с heap. Аналогия: оглавление книги — "глава 5 → стр. 42"

## Структура страницы (8 КБ)

```
Page 0 (8 КБ):
┌──────────────────────────────────────────────────────────────┐
│ Header                                                       │
├──────────────────────────────────────────────────────────────┤
│ Указатель 1: 8100                                            │
│ Указатель 2: 7950                                            │  ← растут вниз
│ Указатель 3: 7800                                            │
├──────────────────────────────────────────────────────────────┤
│                      свободное место                         │
├──────────────────────────────────────────────────────────────┤
│ [байт 7800] {id:12, email:'bob@ya.ru'}                       │
│ [байт 7950] {id:3,  email:'alice@gmail.com'}                 │  ← растут вверх
│ [байт 8100] {id:7,  email:'zack@mail.ru'}                    │
└──────────────────────────────────────────────────────────────┘
```

## TID (CTID) — адрес строки

Адрес строки в heap: `(номер страницы, номер указателя)`.

```sql
SELECT ctid, id, email FROM users;

 ctid  | id |  email
-------+----+-----------------
 (0,1) | 7  | zack@mail.ru
 (0,2) | 3  | alice@gmail.com
 (0,3) | 12 | bob@ya.ru
```

Как читается `(0, 2)`: страница 0 → указатель 2 → смещение 7950 → `{id:3, email:'alice@gmail.com'}`.

## Индекс — отдельная структура

```
base/16384/
├── 18204        ← heap (страницы данных)
├── 18204_fsm    ← free space map
└── 18210        ← индекс (страницы индекса)
```

Индекс по email хранит: значение → адрес в heap.

```
Индекс (B-tree по email):
alice@gmail.com → (0,2)
bob@ya.ru       → (0,3)
zack@mail.ru    → (0,1)
```

## Запрос с индексом

```sql
SELECT * FROM users WHERE email = 'alice@gmail.com';
```

1. Индекс: ищем `'alice@gmail.com'` → адрес `(0, 2)`
2. Heap: страница 0, указатель 2 → смещение 7950
3. Читаем: `{id:3, email:'alice@gmail.com'}`
