## Условие
Дан массив `meetings`, в котором каждый элемент `meeting[i]` — это пара `[startTime, endTime]`.
Необходимо объединить все накладывающиеся друг на друга встречи и вернуть массив с объединёнными встречами.

**Пример:**
- Input: `[[1,3], [2,6], [8,10], [15,18]]`
- Output: `[[1,6], [8,10], [15,18]]`
- Explanation: Интервалы `[1,3]` и `[2,6]` пересекаются → объединяем в `[1,6]`

## Решение

```go
func mergeIntervals(meetings [][]int) [][]int {
	// сортируем по началу интервала, чтобы пересекающиеся шли подряд
	// пример: [[3,5],[1,4],[6,8]] → [[1,4],[3,5],[6,8]]
	sort.Slice(meetings, func(i, j int) bool {
		return meetings[i][0] < meetings[j][0]
	})

	var merged [][]int

	for _, meeting := range meetings {
		// два случая, когда добавляем интервал как новый:
		// 1. merged пуст — первый интервал, не с чем сравнивать
		// 2. конец последнего merged < начало текущего — нет пересечения
		//    пример: последний [1,4], текущий [6,8] → 4 < 6 → не пересекаются
		if len(merged) == 0 || merged[len(merged)-1][1] < meeting[0] {
			merged = append(merged, meeting)
		} else {
			// интервалы пересекаются — сливаем
			// берём максимум из концов, начало уже правильное (отсортировано)
			// пример: последний [1,4], текущий [3,7] → 4 >= 3 → сливаем в [1,7]
			merged[len(merged)-1][1] = max(
				merged[len(merged)-1][1],
				meeting[1],
			)
		}
	}

	return merged
}
```

**Сложность:**
- Временная: O(n log n) — сортировка
- Пространственная: O(n)
