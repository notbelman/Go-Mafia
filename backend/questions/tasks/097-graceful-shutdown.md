## Условие

Есть некий сервис, который принимает запросы (TCP, HTTP — не имеет значения). Клиент передаёт на вход некоторый объект с описанием задачи.

Мы должны, получив эту задачу, поставить её в очередь на обработку. Задача запускается в обработку (имитируем полезную работу через time.Sleep(5*time.Second)), если у нас есть свободные обработчики. Как только очередная задача выполнилась — берём следующую задачу из очереди. Если в очереди пусто, ожидаем новых задач от клиентов.

Сервис одновременно может обрабатывать не более N задач. Остальные задачи должны помещаться в очередь.
