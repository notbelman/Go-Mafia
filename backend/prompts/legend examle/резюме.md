### Ланит

**Старший Golang разработчик** (Go, gRPC, REST API, SOAP, PostgreSQL, Redis, Docker, Kubernetes, GitLab CI)

**О проекте:** Система управления логистикой для трекинга грузоперевозок в реальном времени с интеграцией внешних систем маршрутизации и телематики. Микросервисная архитектура с обработкой потоковых данных от транспортных средств, поддержка REST и gRPC API для внутренних сервисов и внешних интеграций.

**Команда:** Команда из 8 разработчиков (4 backend, 2 frontend, 2 DevOps), работа по Scrum методологии, участие в архитектурных решениях и code review

**Достижения и результаты:**

1. Спроектировал микросервисную архитектуру системы трекинга с нуля, разделив функционал на 6 независимых сервисов (трекинг, маршрутизация, телематика, нотификации, аналитика, интеграции), что обеспечило горизонтальную масштабируемость под растущую нагрузку

2. Разработал REST API для внешних клиентов и внутренний gRPC API для межсервисного взаимодействия, реализовав 40+ эндпоинтов с поддержкой до 5000 RPS

3. Реализовал интеграцию с 5 внешними системами маршрутизации и телематики через REST и SOAP протоколы, обеспечив единый адаптер-слой для унификации данных от разных провайдеров

4. Оптимизировал обработку потоковых данных от 10000+ транспортных средств в реальном времени, внедрив Redis Pub/Sub для распределения нагрузки и PostgreSQL для персистентного хранения с партиционированием по времени

5. Построил CI/CD pipeline в GitLab CI с автоматическими тестами, линтерами и деплоем в Kubernetes, сократив время релиза с 2 часов до 15 минут

6. Контейнеризировал все микросервисы с Docker, создав multi-stage Dockerfile для оптимизации размера образов (с 800MB до 25MB)

7. Настроил оркестрацию микросервисов в Kubernetes-кластере с автоскейлингом на базе HPA, обеспечив автоматическое масштабирование при росте нагрузки на 200%

8. Внедрил distributed tracing с Jaeger для отладки межсервисного взаимодействия, сократив время поиска проблем в production на 70%

**Стек:** Go, gRPC, REST API, SOAP, PostgreSQL, Redis, Docker, Kubernetes, GitLab CI, Jaeger, HPA
