# private

Эта папка предназначена для личных материалов, которые удобно держать рядом с основной базой, но не нужно пушить в общий репозиторий.

Что можно хранить здесь:

- резюме и его версии
- рассказ о себе и разбор опыта
- заметки по конкретным вакансиям и компаниям
- личные планы подготовки

Все файлы в `private/`, кроме этого `README.md`, игнорируются git.

Не храните здесь токены, ключи, пароли и другие секреты.
