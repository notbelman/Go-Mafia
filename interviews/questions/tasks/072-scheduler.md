## Условие

Нужно реализовать backend часть приложения планировщика, в котором будет 3 метода:

1. Создать команду с ID и временем запуска
2. Получить список активных команд
3. Отменить команду по ID

Команда должна выполниться точно в переданное в первом методе время. Методы будут вызываться через HTTP-сервер, количество одновременных запросов не определено.

Само выполнение команды пускай будет Print(ID) в stdout, чтобы эмулировать выполнение.

Необходимо реализовать HTTP-сервер и эти 3 метода.

// POST /command — создать команду {id, run_at}
// GET /commands — получить список активных команд
// DELETE /command/{id} — отменить команду по ID
