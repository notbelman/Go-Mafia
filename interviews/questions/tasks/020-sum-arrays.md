## Условие
Складывать очень большие числа, которые превышают ёмкость базовых типов. Числа хранятся в виде массивов неотрицательных чисел.

Написать функцию, которая примет на вход два таких массива, вычислит сумму и вернёт результат в виде такого же массива.

**Пример:**
```
arr1 = [1, 2, 3]  # число 123
arr2 = [4, 5, 6]  # число 456

res = [5, 7, 9]   # число 579
```

Допустим ответ с первым незначащим нулем `[0, 5, 7, 9]`
