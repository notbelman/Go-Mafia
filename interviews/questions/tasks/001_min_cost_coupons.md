## Условие

В массиве A хранятся цены на N предметов. Есть K купонов, которые уменьшают цену предмета на X.

Если применить t купонов на предмет с ценой a, то его итоговая стоимость будет `max(a - t*X, 0)` (то есть купоны не могут сделать цену предмета отрицательной).

Необходимо вернуть минимальное количество денег, которое придётся потратить, чтобы купить все предметы.

## Пример

```
A = [8, 3, 10, 5, 13]
K = 4
X = 7
result = 12
```

**Объяснение:** Применяем 2 купона на 13 (13 - 14 = 0, но min 0), 1 купон на 10 (10 - 7 = 3), 1 купон на 8 (8 - 7 = 1). Итого: 0 + 3 + 3 + 5 + 1 = 12.

## Решение

```rust
use std::collections::BinaryHeap;

fn min_cost(prices: Vec<i64>, k: i64, x: i64) -> i64 {
    // Max-heap: всегда применяем купон к самому дорогому предмету
    let mut heap: BinaryHeap<i64> = prices.into_iter().collect();
    
    for _ in 0..k {
        if let Some(max_price) = heap.pop() {
            if max_price <= 0 {
                // Все предметы уже бесплатны
                heap.push(max_price);
                break;
            }
            let new_price = (max_price - x).max(0);
            heap.push(new_price);
        }
    }
    
    heap.iter().sum()
}
```

## Сложность

- Время: O(K log N) - K операций с кучей размера N
- Память: O(N) - хранение кучи

### Код
```go
package main

import (
	"fmt"
	"sort"
)

func minCost(A []int, K int, X int) int {
	n := len(A)
	if n == 0 {
		return 0
	}

	// 1) Первый проход: применяем купоны пропорционально цене
	for i := 0; i < n && K > 0; i++ {
		couponsNeeded := A[i] / X
		if couponsNeeded > K {
			couponsNeeded = K
		}
		A[i] -= couponsNeeded * X
		K -= couponsNeeded
	}

	// 2) Сортируем массив
	sort.Ints(A)

	// 3) С конца: есть купон — выкупаем (бесплатно), нет — плюсуем к result
	result := 0
	for i := n - 1; i >= 0; i-- {
		if K > 0 {
			K--
			// предмет бесплатный
		} else {
			result += A[i]
		}
	}

	return result
}

func main() {
	A := []int{10, 25, 30}
	K := 5
	X := 7
	fmt.Println(minCost(A, K, X))
}
```

Цель задачи - минимизировать сколько мы потратим денег, использовав все купоны, когда используешь купон, то он либо выкупает фул товар, если ```A[i] > X```, либо снижает цену товара, если изначальная цена больше купона, важно, что купон ФУЛ удаляется если мы его потратили, то есть нельзя на один товар потратить с одного купона 3 часть купона, и с этого же купона, на другой товар потратить 4 части купона, пару примеров
```
A = [8, 3, 10, 5, 13]
A[0] = 8
X = 7

После применения купона у нас будет A[0] = A[0] - X = 8 - 7 = 1
Получаем как бы такой массив
A = [1, 3, 10, 5, 13]

Если возьмем A[2] и применим купом, то будет A[2] = A[2] - X = 10 - 8 = 2
Получаем
A = [1, 3, 3, 5, 13]

А вот если применим к A[1] например, то у нас фул выкупится товар, так как купон фул стоимость товара покрывает, и получится, что как бы купом дает скидку 7, но мы тратим его чтобы выкупить товар за 3, получается 4 части купона просто сгорают - какая-то хуйня
```

И вот из последней строчки, у нас и получается ситуация, когда нам нужно максималь "жадно"(greedy algorithms вроде так называется) потратить все купоны, максимально оптимально

Как это сделать? Тратить купоны ТОЛЬКО на самые крупные товары
```
A = [8, 3, 10, 5, 13]
K = 4
X = 7

То есть сначала ТОЛЬКО на A[0], A[2], A[4], мы получаем максимальную выгоду тут
```

А что если у нас пример вот такой вот?
```

K = 3
X = 10
```

И вот тут мы понимаешь, что можно не просто по одному купону тратить на один товар, а тратить сразу максимальное количество купонов, пока цена товара, больше чем скидка по купону

```go 
		}
	}
```
