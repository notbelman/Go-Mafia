## Условие

Что выведет программа? Объяснить разницу поведения слайса при передаче по значению и по указателю, а также влияние append на исходный массив.

## Пример
```go
func f1(s []int) {
    s[1] = 20 // меняем элемент массива по индексу
    s = append(s, 80) // аллоцируется новый массив
}

func f2(s *[]int) {
    (*s)[1] = 10 // меняем элемент напрямую в общем массиве
    *s = append(*s, 40) // изменили срез, на который ссылается указатель
}

s := []int{1, 2, 3}
f2(&s)
fmt.Println(s) // ?
f1(s)
fmt.Println(s) // ?
```
