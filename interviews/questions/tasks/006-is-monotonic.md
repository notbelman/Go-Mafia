## Условие
Является ли слайс монотонным?

Монотонная функция — функция одной переменной, которая либо везде не убывает, либо везде не возрастает.

**Примеры:**
- `{1,7}` – true
- `{1,1}` – true
- `{3,3,1}` – true
- `{9,5,1}` – true
- `{23,5,23}` – false

## Решение

```go
package main

import "fmt"

func isMonotonic(arr []int) bool {
	// возможны три варианта:
	// 1. пустой массив — считаем монотонным 
	// (нет пары элементов, нарушающих порядок)
	// 2. один элемент — тоже монотонный (не убывает и не возрастает)
	// 3. два и более элементов — нужно проверять пары соседей
	if len(arr) < 2 {
		return true
	}

	// предполагаем, что массив одновременно
		// и неубывающий, и невозрастающий
	// будем «выбивать» флаги по мере нахождения контрпримеров
	increasing, decreasing := true, true

	for i := 1; i < len(arr); i++ {
		// если текущий элемент БОЛЬШЕ предыдущего — это точно 
		// не невозрастающая последовательность
		// пример: [5, 3, 7] — пара (3,7) убивает decreasing
		if arr[i] > arr[i-1] {
			decreasing = false
		}
		// если текущий элемент МЕНЬШЕ предыдущего — это точно 
		// не неубывающая последовательность
		// пример: [1, 5, 3] — пара (5,3) убивает increasing
		if arr[i] < arr[i-1] {
			increasing = false
		}
		// если arr[i] == arr[i-1] — оба флага остаются, 
		// равенство допустимо в обоих случаях
	}

	// монотонный = хотя бы одно из двух выполняется на всём массиве
	// если оба false — значит были и подъёмы, и спуски → не монотонный
	return increasing || decreasing
}

func main() {
    tests := [][]int{
        {1, 7},
        {1, 1},
        {3, 3, 1},
        {9, 5, 1},
        {23, 5, 23},
    }
    for _, test := range tests {
        fmt.Println(test, isMonotonic(test))
    }
}
```

**Сложность:**
- Временная: O(n)
- Пространственная: O(1)
