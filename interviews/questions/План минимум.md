## 🛠️ GO

### 📌 Map
- Внутренняя структура: buckets, overflow, хеширование
- Почему не потокобезопасна
- Когда resize, влияние на производительность

### 🔄 sync.Map
- Когда использовать вместо обычной map
- Под капотом: read-only path, dirty map, mutex

### 🧷 Примитивы синхронизации
- `Mutex`, `RWMutex`, `WaitGroup`, `Cond`, `Once`

### ⚔️ Atomics vs Mutex
- Когда что использовать
- Ключевая разница

### 📦 Интерфейсы
- Что такое interface
- Реализация в Go

### 🧩 Slice
- Устройство: `ptr`, `len`, `cap`
- Поведение append и copy

### 🔗 Каналы
- Буферизированные vs небуферизированные
- `select`, `close`, `nil`-каналы
- Deadlock и race conditions
- Worker pool
### 🧹 GC
- Mark & sweep, concurrent collection
- STW-паузы, write barrier, GOGC

### 🧠 GMP модель
- G (goroutine), M (thread), P (processor)
- Планирование, work stealing, syscalls
- Preemption, netpoller

## 🗄️ PostgreSQL

### 🔍 Индексы
- Виды: B-tree, GIN, GiST, BRIN, Hash
- Когда какой использовать
- Покрывающие, частичные, составные

### ✅ ACID
- Atomicity, Consistency, Isolation, Durability
- Почему важно для транзакций

### 🔄 MVCC
- Многоверсионность в PostgreSQL
- Почему нужен VACUUM

### 🔐 Транзакции
- Уровни изоляции: Read Committed, Repeatable Read, Serializable
- Аномалии: phantom reads, non-repeatable reads
- Дефолт в PostgreSQL

### 📊 EXPLAIN ANALYZE
- Разница EXPLAIN и EXPLAIN ANALYZE
- Функция ANALYZE

### 🧼 VACUUM
- Авто-очистка и ручной запуск
- VACUUM FULL, VACUUM ANALYZE

### 🔁 Репликация
- Физическая (streaming) vs логическая
- Sync vs async

### 🧩 Шардирование и партиционирование
- В чём разница
- Range, list, hash партиции
- Когда партиции, когда шарды

### 📝 WAL
- Журнал предзаписи
- Роль в durability и репликации
