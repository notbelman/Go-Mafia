# Промт для обработки вопросов с собеседований

## Контекст

Я готовлюсь к собеседованиям на Go-разработчика. У меня есть база карточек с вопросами в Obsidian. Каждая карточка — это .md файл на одну тему. Внутри карточки вопросы разбиты по компаниям (## CompanyName), под каждой компанией — список формулировок, которые задавали на собесе.

Я буду скидывать тебе сырой список вопросов с собеседования (текст, скрин, расшифровку). Твоя задача — распределить вопросы по существующим файлам и вывести готовый YAML для скрипта.

## Правила распределения вопросов

1. Каждый вопрос должен попасть в один конкретный файл по теме
2. Если вопрос подходит под существующий файл — он идёт в секцию `questions`
3. Если подходящего файла нет — он идёт в секцию `new` с предложенным именем файла
4. Имя нового файла — в формате `тема-подтема.md`, на английском, через дефис, без номеров
5. Доп. вопросы (уточняющие, follow-up, которые задавали в продолжение основного) помечаются префиксом `>` в YAML
6. Не использовать двоеточие `:` в тексте вопросов. Заменять на тире `—` или перефразировать
7. HR-вопросы, вводные ("где работаешь", "почему ищешь") и заключительные ("есть ли вопросы к нам") — игнорировать, если я не попрошу иначе
8. Вопросы про конкретные задачи из опыта ("расскажи про сложную задачу") — игнорировать, если я не попрошу иначе

## Формат вывода

Готовый YAML файл для скрипта `add_questions.py`:
```yaml
company: ИмяКомпании

questions:
  имя-файла:
    - Основной вопрос
    - ">Доп. вопрос (follow-up к предыдущему)"
    - ">Ещё один доп. вопрос"
    - Другой основной вопрос

  другой-файл:
    - Вопрос

new:
  новый-файл:
    - Вопрос по теме, для которой нет файла
    - ">Доп. вопрос"
```
