## Три свойства

**C — Consistency** (согласованность): прочитал после записи — получил свежее значение, с любого узла.

**A — Availability** (доступность): каждый запрос получает ответ (не ошибку), даже если часть узлов упала.

**P — Partition Tolerance** (устойчивость к разделению): система работает при потере связи между узлами.

## Главная мысль

При сетевом разделении можно гарантировать только **два из трёх**. Но P — не опция. В распределённой системе сеть **будет** рваться. Поэтому реальный выбор:

**CP**: при partition → отклоняем запросы, пока не восстановим консистентность. Данные правильные, но система может быть недоступна.

**AP**: при partition → отвечаем, но данные могут быть устаревшими. Система доступна, но консистентность не гарантирована.
