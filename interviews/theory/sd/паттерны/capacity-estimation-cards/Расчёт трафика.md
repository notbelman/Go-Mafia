Сколько данных льётся в систему в секунду, в день, в год.

## Формула

```
Traffic per second = RPS write × размер_одного_запроса
```

## Пример: WhatsApp (запись)

- RPS write ≈ 2.315
- Максимальный размер сообщения: 1000 символов × 2 байта (UTF-8 кириллица) = 2000 байт

```
Per second = 2.315 × 2.000 = 4.630.000 байт ≈ 4.6 МБ/с
Per day    = 4.6 МБ × 86.400 ≈ 397 ГБ/день (≈ 400 ГБ)
Per year   = 400 ГБ × 365 ≈ 146 ТБ/год (≈ 150 ТБ)
```

## Быстрый перевод единиц

Убираем три нуля — переходим на следующий уровень:

```
4.630.000 байт
    → убрали 1000 → 4.630 КБ
    → убрали 1000 → 4.6 МБ
```

Грубая оценка (в реальности 1024, но для коленочных расчётов — 1000).

## Трафик на чтение

Если read/write = 5:1, то трафик на чтение ≈ 4.6 МБ × 5 = 23 МБ/с. Суммарный трафик ≈ 27 МБ/с. Это копейки — даже HDD справится (100+ МБ/с throughput).

## Зачем считать

Из трафика → считаем storage. Из трафика → понимаем, хватит ли пропускной способности дисков (HDD vs SSD). Из трафика → понимаем нагрузку на сеть.
