**Суть:** Вместо одного мощного сервера — ставим несколько недорогих. Задачу выполняет не один сервер, а N серверов.

**Плюсы:** — нет потолка: нужно больше — добавляй ещё машины — дешевле: N недорогих серверов обычно выгоднее, чем один дорогой — отказоустойчивость: упал один — остальные работают

**Минусы:** — сложнее архитектура: нужно думать о балансировке, синхронизации данных, миграциях — дороже в разработке: больше усилий на проектирование — особенно больно с stateful сервисами (об этом отдельная карточка)

**Когда использовать:** — по умолчанию, если играем вдолгую — система, которая будет расти и держать нагрузку — сразу закладываемся + берём минимально необходимые ресурсы на каждый узел

**Когда НЕ заморачиваться:** — стартап, проверка гипотезы — просто пишем код, не думаем о масштабировании, если нужно — вертикалим

**Золотая середина вертикального + горизонтального:** не нужно искать. По умолчанию — горизонтальное с минимальными ресурсами на узел.
