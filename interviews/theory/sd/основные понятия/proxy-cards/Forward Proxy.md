**Суть:** Прокси, о которой **клиент знает**. Клиент осознанно отправляет запрос через прокси.

**Пример:** VPN. Instagram заблокирован в России → ставим VPN → идём через прокси. Я как пользователь понимаю, что использую прокси.

**Зачем:**
- обход ограничений доступа (блокировки)
- анонимность — сервер видит IP прокси, а не клиента
- клиент явно настраивает адрес прокси в своём приложении

**Важно:** клиент использует API прокси. Прокси может переложить протокол — клиент шлёт REST, прокси конвертирует в gRPC для целевого сервиса.

**Связь:**
- клиент знает о прокси (в отличие от reverse proxy)
- VPN — типичный пример forward proxy
