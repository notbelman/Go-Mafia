**Суть:** Remote Procedure Call от Google. Вместо JSON — бинарный формат Protobuf. Вместо HTTP-глаголов — вызов функций.

**Как работает:**
1. Описываем контракт в `.proto` файле (типы, методы)
2. Кодогенерация — из `.proto` получаем клиент и сервер на любом языке
3. Вызываем удалённую функцию как локальную

**Плюсы:**
- компактнее JSON — бинарный формат, меньше трафика
- типизация из коробки — ошибки на этапе компиляции, а не в рантайме
- кодогенерация — не нужно писать клиент руками
- быстрее сериализация/десериализация

**Минусы:**
- нечитаемый формат (бинарный) — сложнее дебажить
- нужна кодогенерация — дополнительный шаг в сборке

**Когда использовать:**
- внутри микросервисов (сервис → сервис) — основной кейс
- можно и для клиентов (пример: Яндекс.Облако отдаёт gRPC SDK)
