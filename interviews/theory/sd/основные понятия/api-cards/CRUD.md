**Суть:** Четыре базовые операции, которые покрывают большинство API:

| Операция | Что делает | HTTP метод |
|----------|-----------|------------|
| Create   | Создать   | POST       |
| Read     | Прочитать | GET        |
| Update   | Обновить  | PUT / PATCH|
| Delete   | Удалить   | DELETE     |

**Зачем знать:** При проектировании API первым делом определяем, какие CRUD-операции нужны для каждой сущности. Это отправная точка.

**Пример:** Сущность "пользователь":
- Create → POST /users
- Read → GET /users/{id}
- Update → PUT /users/{id}
- Delete → DELETE /users/{id}

**Нюанс PUT vs PATCH:**
- PUT — полная замена ресурса (отправляем все поля)
- PATCH — частичное обновление (отправляем только изменённые поля)
