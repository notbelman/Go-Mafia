Привязка тегов к группам записей в кэше. Инвалидация по тегу — все связанные записи обновляются разом.

## Проблема

Mail.ru: на главной странице новости, погода и курс валют. Всё закэшировано в разных таблицах/спейсах. Приходит новость «курс доллара рухнул до 30₽», а в виджете справа доллар = 75₽. Пользователь видит противоречие. Нужно согласованно инвалидировать связанные данные.

## Решение

Каждой группе данных в кэше назначается тег: новости → тег `news`, погода → тег `weather`, валюта → тег `currency`.

Приходит новость про погоду → инвалидируем тег `weather` → все записи с этим тегом обновляются.

Приходит новость «в Москве из-за глобального потепления рухнул курс доллара» → на ней два тега: `weather` + `currency` → инвалидируем обе группы одновременно.

## Как работает

1. При записи в кэш указываем теги: `set("weather:moscow", data, tags=["weather"])`
2. При инвалидации: `invalidate_tag("weather")` → все записи с этим тегом удаляются или помечаются устаревшими
3. Следующий запрос за `weather:moscow` → cache miss → поход в БД → свежие данные

## Когда использовать

- Несколько групп данных на одной странице, которые должны быть согласованы
- Событие затрагивает несколько категорий данных одновременно
- Нужна точечная инвалидация: не весь кэш, а конкретные группы
