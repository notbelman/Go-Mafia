**Проблема:** В распределённой системе логи лежат на каждой машине отдельно. 200 инстансов = 200 мест, куда нужно зайти по SSH и грепать.

**Решение:** Централизованная система логирования.

**Как работает:**
1. На каждой машине стоит демон (агент), который собирает логи
2. Демон отправляет логи в центральную систему (ELK Stack, Graylog, Loki)
3. В UI — поиск, фильтрация, агрегация по всем сервисам сразу

**ELK Stack:**
- **E**lasticsearch — хранит и индексирует логи
- **L**ogstash — собирает и обрабатывает логи
- **K**ibana — UI для поиска и визуализации

**Отличие от трейсинга:**
- Трейсинг — путь одного запроса через сервисы (граф)
- Логирование — текстовые записи о событиях (поток)
- Дополняют друг друга: в логе можно искать по trace ID

**Зачем:** дебаг, аудит, расследование инцидентов, понимание поведения системы.
