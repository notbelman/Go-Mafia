Уровни — из модели OSI. L3 = сетевой (IP), L4 = транспортный (TCP/порты), L7 = прикладной (HTTP).

## L4 (Network Load Balancer)

**Суть:** Работает на уровне соединений (connections). Не заглядывает внутрь — просто пробрасывает connection на бэкенд.

- Клиент открыл соединение, отправляет 10 000 запросов → L4 видит одно соединение, пробросил его на один сервер
- Другой клиент, 100 запросов → пробросил на другой сервер
- Не понимает, сколько запросов внутри соединения

**Плюс:** быстрее — не нужно разбирать пакет до 7 уровня и запаковывать обратно.

## L7 (Application Load Balancer)

**Суть:** Работает на уровне запросов. Видит HTTP, понимает содержимое — может раскидывать отдельные запросы по разным серверам.

- Открывает соединения, смотрит сколько запросов по каждому
- Умно распределяет на разные бэкенды

**Плюс:** умнее, точнее распределение.
[[Reverse Proxy]] — L7 = application level, часто тот же Nginx
**Минус:** медленнее — полный разбор до 7 уровня.

## Комбинация (как в Яндексе)

На входе — несколько L4 (раскидывают по датацентрам по соединениям). За ними — L7 (умно распределяют запросы внутри датацентра).

| | L4 | L7 |
|--|----|----|
| Видит | Соединения | Запросы |
| Скорость | Быстрее | Медленнее |
| Умность | Тупее | Умнее |
| Другое название | Network LB | Application LB |
