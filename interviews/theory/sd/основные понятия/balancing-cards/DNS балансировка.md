**Проблема:** балансировщик — единая точка отказа. Кто будет балансировать на балансировщик? Ещё один балансировщик? А на него?

**Решение:** DNS. За одним доменным именем прячем несколько IP-адресов. DNS отдаёт их в разном порядке каждый раз.

**Как работает:**
```
$ nslookup mail.ru
→ 94.100.180.70
→ 94.100.180.71
→ 217.69.139.70
→ 217.69.139.71
```
Следующий запрос — те же IP, но в другом порядке. Клиент идёт на первый в списке → нагрузка размазывается.

**Зачем переупорядочивание:** чтобы все клиенты не долбились в один и тот же хост. Если первый недоступен — клиент пробует следующий (retry).

**Связь:**
- решает проблему единой точки отказа балансировщика
- по сути round robin на уровне DNS
- [[GeoDNS]] — умная версия DNS-балансировки
