**Суть:** Second Chance, но без перемещения элементов. Кольцевой буфер + указатель (стрелка часов).

**Как работает:**
1. Элементы расположены по кругу (кольцевой буфер)
2. Указатель ("стрелка") движется по кругу
3. Пора вытеснять → смотрим элемент под стрелкой:
   - бит = 0 → вытесняем, стрелка остаётся
   - бит = 1 → сбрасываем в 0, двигаем стрелку дальше
4. Повторяем, пока не нашли элемент с битом 0

**Отличие от Second Chance:** не перемещаем элементы в конец очереди. Просто двигаем указатель. Это дешевле.

**Где используется:** Linux — управление виртуальной памятью. Ядро решает, какие страницы выгрузить из RAM на диск, именно алгоритмом Clock.

**Связь:**
- оптимизация [[Second Chance]]
- используется в реальных ОС (Linux)
- [[Second Chance]] и Clock — практичные улучшения FIFO
