**Суть:** Кэш живёт внутри сервиса — в памяти (map, дерево, любая структура данных) или в файле под ногами (BoltDB и т.д.).

**Плюсы:**
- максимальная скорость — данные в оперативке, без сетевых запросов
- нет расходов на сериализацию/десериализацию
- нет маршалинга — просто обращение к структуре данных

**Минусы:**
- сервис становится stateful → проблемы с горизонтальным масштабированием
- рестарт / деплой / OOM → кэш вымывается, нужен прогрев
- инвалидация в N инстансах — сложно

**Связь:**
- внутреннее → сервис становится [[Stateless vs Stateful сервисы|statefull]] → нужны [[Sticky Sessions (привязка к инстансу)]]
-  [[Low latency приложения]] → внутреннее
