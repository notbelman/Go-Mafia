**Суть:** Кэш — отдельный сервис (Redis, Memcached, Tarantool). Приложение ходит в него по сети.

**Плюсы:**
- можно хранить больший объём данных
- горизонтальное масштабирование сервиса просто — добавил инстанс, он ходит в тот же кэш
- рестарт сервиса → данные в кэше на месте
- прогрев и инвалидация в одном месте

**Минусы:**
- дополнительный latency — сетевой поход
- расходы на сериализацию/десериализацию

**Связь:**
- внешнее → сервис остаётся [[Stateless vs Stateful сервисы|stateless]] → балансировка проще
-  простота эксплуатации → внешнее
- [[Горизонтальное масштабирование]]
