**Суть:** Клиент запрашивает данные → сервер отдаёт файл целиком, в сыром виде. Никакой фильтрации, сортировки, поиска на сервере не происходит. Вся обработка ложится на клиента.

**Пример:** Клиент просит пользователя с ID 5 → сервер отдаёт файл со **всеми** пользователями → клиент сам ищет нужного.

**Почему устарела:** — небезопасно отдавать клиенту все данные — клиент нагружается логикой обработки — не у всех клиентов хватает ресурсов (CPU, RAM)

**Где живёт сейчас:** Google Drive, Dropbox — загрузка/скачивание файлов целиком, без обработки на сервере.

**Граница с клиент-сервером:** тонкая. Если сервер делает хоть какую-то выборку (фильтрация по ключу, offset внутри файла) — это уже ближе к клиент-серверу.
