**Суть:** Для каждого слова хранится список документов, в которых оно встречается. "Слово → где встречается" вместо "документ → какие слова".

**Пример:**
```
Тексты:
  0: "it is what it is"
  1: "what is it"
  2: "it is a banana"

Обратный индекс:
  a      → [2]
  banana → [2]
  is     → [0, 1, 2]
  it     → [0, 1, 2]
  what   → [0, 1]
```

Запрос "banana" → смотрим в индекс → документ 2. Мгновенно.

**Поиск по нескольким словам:** "is" + "banana" → пересечение множеств [0,1,2] ∩ [2] = [2]. Используются алгоритмы merge/intersect.

**Алгоритм построения:** проходим по всем словам всех документов, строим маппинг слово → список документов.

**Где используется:** Elasticsearch, Sphinx — основная структура данных полнотекстового поиска.
