**Суть:** Надстройка над документными БД. Позволяют делать полнотекстовый поиск — искать по словам, однокоренным формам, опечаткам.

**Как работает:**
- слова разбираются на корни (отбрасываются суффиксы, приставки)
- поиск по однокоренным: "мама" → находит "маму", "мамы", "мамины"
- поиск по похожим: "ИП" → находит "индивидуальный предприниматель"
- используется редакционное расстояние и словари

**Антипаттерн:** хранить все данные только в Elasticsearch. Правильно — основные данные в реляционке/документной БД, а рядом Elasticsearch для поиска.

**Исключение:** логи и трейсы можно хранить прямо в Elasticsearch — там не нужна основная БД.

**Примеры:** Elasticsearch, Sphinx (Авито).

**Связь:**
- [[Inverted Index (обратный индекс)]] — основная структура данных внутри поисковых движков
- [[Логирование]] — ELK Stack использует Elasticsearch для хранения логов
