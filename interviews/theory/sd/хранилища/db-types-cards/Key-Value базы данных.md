**Суть:** Хэш-таблица, вынесенная за пределы процесса. Ключ → значение. Самая простая модель данных.

**Примеры данных:**
- video_id → количество просмотров
- author_id → количество подписчиков
- session_token → user_id

**Основное применение:** кэширование. Внешний кэш = key-value БД.

**Примеры:** Redis, Memcached, Tarantool.

**Особые key-value:** etcd, ZooKeeper — используются для хранения конфигурации кластера, service discovery, метаинформации серверов, механизмов репликации. Не для пользовательских данных, а для инфраструктуры.
