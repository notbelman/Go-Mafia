**Суть:** Хранилище для сырых файлов — картинки, видео, MP3, исходный код, бэкапы. Данные, которые нельзя "распотрошить" на поля.

**Модель использования:** положил → получил → удалил. Модификация не предусмотрена. Положил файл и забыл, потом кто-то скачает или удалит.

**Антипаттерн:** сохранять файлы, а потом постоянно их модифицировать. Blob storage не заточен под это.

**Примеры:** Amazon S3, Google Cloud Storage, MinIO.

**Синонимы:** Blob Storage, Object Storage, GlоbStorage — одно и то же.
