## Embedded (встраиваемые)
Код БД встраивается прямо в приложение как библиотека. Нет сетевых запросов — приложение пишет "под ноги" на диск.

**Зачем:** хочу структурированно писать на диск, строить индексы, обеспечивать конкурентный доступ — но не хочу поднимать отдельный сервер БД.

**Как работает:** подключаешь библиотеку → она размечает файлы на диске → приложение работает с ними как с БД.

**Примеры:** BoltDB (Go), RocksDB, LevelDB.

**Нюанс:** embedded БД может использовать несколько файлов и каталогов — это не обязательно один файл.

## Single File Database
Вся БД = один файл. Можно скопировать, передать другу, он поднимет.

**Пример:** SQLite — самая известная. Файл .db — это вся база.

**Где используется:** мобильные приложения, локальные конфигурации, прототипы.

**Отличие от embedded:** single file — это про формат хранения (один файл). Embedded — про архитектуру (библиотека в коде). SQLite — и то, и другое.
