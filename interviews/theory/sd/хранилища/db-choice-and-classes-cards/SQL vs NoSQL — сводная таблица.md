
||**SQL**|**NoSQL**|
|:--|:--|:--|
|**Модель данных**|Таблицы, строки, колонки|Документы, key-value, графы, column-family|
|**Схема**|Строгая, определена заранее|Гибкая, можно менять на лету|
|**Язык запросов**|SQL (стандарт)|У каждой БД свой (MQL, CQL, API)|
|**JOIN**|Нативный, быстрый|Нет или дорогой ($lookup в MongoDB)|
|**Транзакции**|ACID из коробки|BASE по умолчанию, ACID частично (MongoDB с 4.0)|
|**Масштабирование**|Вертикальное (горизонтальное сложно)|Горизонтальное из коробки|
|**Консистентность**|Strong по умолчанию|Eventual по умолчанию (tunable)|
|**Связи между данными**|FK, нормализация|Embedded documents, денормализация|
