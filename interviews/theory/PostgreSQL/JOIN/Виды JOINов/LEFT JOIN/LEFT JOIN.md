
INNER JOIN + строки из левой таблицы без пары (с NULL)
```sql
SELECT * FROM t1
LEFT JOIN t2 ON t1.id = t2.id;
```

**Пример:**
t1: (1), (1), (3)
t2: (1), (1), (4), (5)

**Результат: 5 строк, не 3!**

| t1.id | t2.id |
| ----- | ----- |
| 1     | 1     |
| 1     | 1     |
| 1     | 1     |
| 1     | 1     |
| 3     | NULL  |

Каждая 1 слева × каждая 1 справа = 2×2 = 4
Плюс 3 без пары → NULL

⚠️ Строк может быть БОЛЬШЕ чем в левой таблице!
