 

Зеркало LEFT JOIN - всё наоборот

Все из правой + совпадения из левой (NULL где нет пары)
```sql
SELECT * FROM t1
RIGHT JOIN t2 ON t1.id = t2.id;
```

**Пример:**
t1: (1), (1), (3)
t2: (1), (1), (4), (5)

**Результат:**

| t1.id | t2.id |
| ----- | ----- |
| 1     | 1     |
| 1     | 1     |
| 1     | 1     |
| 1     | 1     |
| NULL  | 4     |
| NULL  | 5     |

⚠️ Редко используется - всегда можно переписать как LEFT JOIN, поменяв таблицы местами
