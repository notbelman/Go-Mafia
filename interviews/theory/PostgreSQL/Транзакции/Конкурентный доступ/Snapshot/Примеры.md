**READ COMMITTED — новый snapshot на каждый запрос:**
```
T1 (READ COMMITTED):           T2:
BEGIN;
                               BEGIN;
SELECT * FROM accounts;        
-- snapshot #1: xmin=100       
                               UPDATE accounts SET balance=2000 WHERE id=1;
                               COMMIT;
SELECT * FROM accounts;        
-- snapshot #2: xmin=101 (новый!)
-- видит изменения T2
```

**REPEATABLE READ — один snapshot:**
```
T1 (REPEATABLE READ):          T2:
BEGIN;
SELECT * FROM accounts;        
-- snapshot зафиксирован
                               BEGIN;
                               UPDATE accounts SET balance=2000 WHERE id=1;
                               COMMIT;
SELECT * FROM accounts;        
-- тот же snapshot
-- НЕ видит изменения T2
```

**Посмотреть активные транзакции:**
```sql
SELECT pid, xact_start, state, backend_xid, backend_xmin
FROM pg_stat_activity
WHERE state != 'idle';

-- backend_xid: XID этого backend (NULL если read-only)
-- backend_xmin: xmin snapshot этого backend
```
