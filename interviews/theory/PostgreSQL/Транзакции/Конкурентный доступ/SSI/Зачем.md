## SSI — Serializable Snapshot Isolation

Механизм уровня SERIALIZABLE. Ловит аномалии которые Snapshot Isolation пропускает.

Snapshot Isolation (REPEATABLE READ) не ловит **write skew**:
```
Правило: минимум 1 врач на смене

T1: SELECT count(*) → 2, UPDATE Alice off
T2: SELECT count(*) → 2, UPDATE Bob off
Оба коммитят → 0 врачей. Нарушение.
```

Snapshot это пропускает: T1 и T2 меняют разные строки.
