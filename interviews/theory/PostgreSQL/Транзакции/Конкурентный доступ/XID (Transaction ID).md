## Что это

32-битный идентификатор транзакции. Хранится в каждой версии строки (xmin/xmax).

| XID | Значение |
|-----|----------|
| 0 | Невалидный |
| 1 | Системная инициализация |
| 2 | FrozenXID - видим всем всегда |
| 3+ | Обычные транзакции |

## Virtual XID

Read-only транзакции не тратят настоящий XID - получают лёгкий vxid (существует только в памяти).

XID выдаётся только при первом INSERT/UPDATE/DELETE.

## Wraparound - проблема

32 бита = ~4 млрд транзакций. При переполнении старые данные станут "невидимыми".

**Решение:** VACUUM делает freezing - заменяет старые xmin на FrozenXID (2).

**Если VACUUM не успевает** → база уходит в read-only mode (защита от потери данных).
