## Что такое транзакция

Группа операций, которые выполняются как единое целое: либо все успешно, либо ни одна.

## ACID - свойства транзакции

| **A - Atomicity**   | Всё или ничего. Либо все операции выполнены, либо ни одной                                      |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| **C - Consistency** | БД переходит из одного корректного состояния в другое. Бизнес-правила не нарушаются             |
| **I - Isolation**   | Параллельные транзакции не влияют друг на друга. На практике - компромисс через уровни изоляции |
| **D - Durability**  | После COMMIT данные сохранены навсегда, даже если сервер упадёт                                 |

**Главный компромисс:** полная изоляция дорогая → существуют уровни изоляции, которые жертвуют частью изоляции ради производительности.
