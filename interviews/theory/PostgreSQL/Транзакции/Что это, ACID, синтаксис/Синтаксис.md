### BEGIN / COMMIT / ROLLBACK

**BEGIN** - начать транзакцию
**COMMIT** - зафиксировать изменения
**ROLLBACK** - откатить все изменения
```sql
BEGIN;
  UPDATE account SET balance = balance - 100 WHERE id = 1;
  UPDATE account SET balance = balance + 100 WHERE id = 2;
COMMIT;
```

**При ошибке внутри транзакции:**
```sql
BEGIN;
  UPDATE account SET balance = balance - 100 WHERE id = 1;
  -- тут ошибка, например нарушение FK
  INSERT INTO transfers(from_id, to_id) VALUES (1, 999);
ROLLBACK;  -- обязательно вызвать после ошибки!
```

**Важно для PostgreSQL:**
После ошибки транзакция в состоянии "aborted".
Любые команды кроме ROLLBACK будут игнорироваться.

**SAVEPOINT - точки сохранения:**
```sql
BEGIN;
  UPDATE account SET balance = 500 WHERE id = 1;
  SAVEPOINT my_point;
  UPDATE account SET balance = -100 WHERE id = 2;  -- ошибка
  ROLLBACK TO my_point;  -- откат до savepoint, а не всей транзакции
COMMIT;
```
