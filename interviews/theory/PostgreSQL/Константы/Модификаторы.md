
| Модификатор                    | Что делает                                           |
| ------------------------------ | ---------------------------------------------------- |
| DEFERRABLE INITIALLY IMMEDIATE | Проверка сразу, можно отложить через SET CONSTRAINTS |
| DEFERRABLE INITIALLY DEFERRED  | Проверка при COMMIT                                  |
| NOT VALID                      | Не проверять старые данные, только новые             |

**NOT VALID подробнее** - когда и зачем:
```sql
-- Добавить FK на большую таблицу без проверки старых данных
ALTER TABLE orders ADD CONSTRAINT fk_user 
FOREIGN KEY (user_id) REFERENCES users(id) NOT VALID;

-- Потом валидировать в фоне
ALTER TABLE orders VALIDATE CONSTRAINT fk_user;
```
