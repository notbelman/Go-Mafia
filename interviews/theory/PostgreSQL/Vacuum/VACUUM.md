Очистка мёртвых версий строк после UPDATE/DELETE.

### Зачем MVCC 

создаёт новую версию при UPDATE/DELETE. Старые копятся → bloat. Без VACUUM: - Таблица растёт бесконечно - XID wraparound → потеря данных
### Что делает

- Помечает место как свободное для переиспользования (FSM)
- Удаляет мёртвые указатели в индексах
- Замораживает старые xmin (защита от XID wraparound)

**НЕ возвращает место на диск.**

### Запуск

**Автоматически:** autovacuum срабатывает когда `dead_tuples > 50 + 0.2 * reltuples`

**Вручную:**

```sql
VACUUM accounts;          -- только очистка
VACUUM ANALYZE accounts;  -- + обновить статистику
```
