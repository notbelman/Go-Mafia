Последовательное чтение всех страниц таблицы — от начала до конца.
```
Seq Scan on users  (cost=0.00..35.50 rows=2000 width=64)
```

## Когда выбирается

- Нет подходящего индекса
- Нужна большая часть таблицы (>5-10% строк)
- Таблица маленькая (несколько страниц)

## Почему не всегда плохо

Нужно 80% таблицы → Seq Scan быстрее (последовательное чтение дешевле random I/O).

## Стоимость
```
cost = (pages × seq_page_cost) + (rows × cpu_tuple_cost)
     = страницы × 1.0 + строки × 0.01
```

⚠️ Seq Scan на большой таблице с WHERE по индексированному полю → проверь индекс и статистику.
