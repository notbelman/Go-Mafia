**Exact** (влез в work_mem) — битовый массив по строкам:
```
страница 3: [1,0,0,1,0,0,0,0...]  ← знаем точно: строки 2, 4
страница 5: [0,0,1,0,0,0,1,0...]  ← знаем точно: строки 3, 7
```
Recheck проверяет только помеченные строки.

**Lossy** (не влез) — схлопывается до страниц:
```
[0,0,1,0,1,0,0...]  ← страницы 3,5 помечены, какие строки — неизвестно
```
Recheck проверяет **все** строки на странице.

**Диагностика:** ```Heap Blocks: exact=0 lossy=1200 <- (больше 0)```

**Решение:** `SET work_mem = '256MB';`
