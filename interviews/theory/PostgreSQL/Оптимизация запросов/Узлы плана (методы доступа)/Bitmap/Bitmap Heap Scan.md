Для средней селективности (5-20% строк).

Двухфазная операция:
```
Bitmap Heap Scan on orders              ← фаза 2: читаем страницы по порядку
  Recheck Cond: (amount > 1000)         ← перепроверяем строки на странице
  ->  Bitmap Index Scan on idx_amount   ← фаза 1: строим битовую карту
        Index Cond: (amount > 1000)
```

**Фаза 1 (Bitmap Index Scan):** проходим по индексу, строим битовую карту страниц и строк на ней.

**Фаза 2 (Bitmap Heap Scan):** читаем страницы последовательно по порядку номеров. Recheck Cond проверяет, какие строки реально подходят под условие.

**Выгода:** превращает random I/O в sequential I/O (Index Scan прыгает по heap на каждую строку хаотично, Bitmap читает страницы по порядку).
