Для каждой строки внешней таблицы ищем все совпадения во внутренней.

## Когда единственный вариант
- Неравенства в JOIN (`<`, `>`, `BETWEEN`) — Hash и Merge не умеют

## Когда выгоден (при `=`)
- Внешняя таблица маленькая (мало итераций)
- На внутренней есть индекс
- Есть LIMIT — можно остановиться рано

## Сложность
- O(N × M) — без индекса (катастрофа)
- O(N × log M) — с индексом
- O(N) — внутренняя возвращает 1 строку (unique index)

## Ограничения

- Без индекса на внутренней таблице — очень медленно
- Большая внешняя таблица — много итераций

## EXPLAIN
```
Nested Loop  (cost=0.29..850.00)
  ->  Seq Scan on users u              ← внешняя, 10 строк
        Filter: (status = 'vip')
  ->  Index Scan on orders o           ← внутренняя, выполнится 10 раз
        Index Cond: (user_id = u.id)
```

loops — сколько раз выполнился внутренний узел:
```
->  Index Scan on orders  (actual rows=5 loops=10)
                                        ↑
              реальное время = actual time × loops
```
