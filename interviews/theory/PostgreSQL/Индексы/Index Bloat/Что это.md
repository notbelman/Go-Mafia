Раздувание индекса - индекс занимает больше места, чем нужно для текущих данных.
### Почему возникает

DELETE и UPDATE в PostgreSQL не удаляют данные физически:

VACUUM чистит и heap, и индексы. Но физический размер файлов не уменьшает - место внутри становится свободным для переиспользования. Если новых вставок нет - bloat остаётся.

```
После 1M DELETE + VACUUM:
  Индекс: внутри свободно, файл всё ещё 2GB
  Новые INSERT переиспользуют место.
  Нет INSERT → файл так и останется 2GB.
```

### Как заметить

```sql
SELECT 
  pg_size_pretty(pg_relation_size('users')) AS table_size,
  pg_size_pretty(pg_relation_size('idx_users_email')) AS index_size;
```
