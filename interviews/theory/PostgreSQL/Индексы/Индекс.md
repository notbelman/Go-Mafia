Отдельная структура данных с ключами и указателями (TID) на строки в heap.

Аналогия: оглавление книги - "глава 5 → стр. 42" вместо перелистывания всех страниц.

## Где хранится

Отдельный файл на диске рядом с heap-файлом таблицы. Состоит из страниц по 8KB (как и heap):
```
base/16384/
├── 18204        <- heap (страницы данных)
├── 18204_fsm    <- free space map
└── 18210        <- индекс (страницы индекса)
```

## Структура записи
```
[ключ] → [TID (heap_page, offset)]
  70   →      (0, 4)
```

TID указывает: страница 0 в heap, 4-я строка.
