**Использовать:**

- Append-only таблицы (логи, события, метрики) - данные физически упорядочены
- Огромные таблицы (100M+ строк) с range-запросами (`>`, `<`, `BETWEEN`)
- Когда B-tree слишком большой (BRIN ~0.1% от таблицы vs 30% B-tree)

**Не использовать:**

- Данные часто UPDATE'ятся или вставляются в случайном порядке
- Нужен точечный поиск по `=`
- Таблица небольшая (B-tree будет эффективнее)

```sql
CREATE INDEX idx_logs_created ON logs USING BRIN(created_at);
```
