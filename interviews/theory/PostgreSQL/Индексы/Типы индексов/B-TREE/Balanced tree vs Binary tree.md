
| Binary Tree              | B-tree                    |
| ------------------------ | ------------------------- |
| 2 потомка                | 100-300 потомков          |
| Может быть несбалансир.  | Всегда сбалансировано     |
| 1 млн строк → 20 уровней | 1 млн строк → 3-4 уровня  |
| Для RAM                  | Для диска (page-oriented) |

## Почему B-tree для БД
- Узел = страница 8KB → меньше disk I/O
- Листья связаны списком → быстрые range scans
- Гарантированная высота → предсказуемый O(log n)

⚠️ "B" = "Balanced", не "Binary"
