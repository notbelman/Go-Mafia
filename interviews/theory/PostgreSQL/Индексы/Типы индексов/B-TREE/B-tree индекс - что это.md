## Назначение
- Поиск по равенству: `WHERE id = 123`
- Диапазонные запросы: `WHERE created_at > '2024-01-01'`
- Сортировка: `ORDER BY name` (включая DESC без пересоздания)
- Уникальность: `UNIQUE` / `PRIMARY KEY`

## Поддерживаемые операции
- `=`, `<`, `>`, `<=`, `>=`, `BETWEEN`, `IN`
- `IS NULL / IS NOT NULL`
- `LIKE 'prefix%'` - только с `varchar_pattern_ops` или collation "C"

## Когда неэффективен
- `LIKE '%suffix'`, `LIKE '%middle%'` - нужен GIN/GiST + pg_trgm
- `<>`, `!=`, `NOT IN` - не использует индекс
- Низкая селективность (пол, булевы) - планировщик выберет seq scan

## Ограничения
- Максимум ~2712 байт на ключ (1/3 страницы)
