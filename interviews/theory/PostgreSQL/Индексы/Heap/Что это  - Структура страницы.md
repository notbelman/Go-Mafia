- Heap - файл на диске, в котором хранится таблица. Разбит на страницы по 8 КБ.
- Строки лежат в порядке вставки. DELETE оставляет дыру. Поэтому id=7 может лежать раньше id=1. 
- Указатель - просто число (смещение в байтах). По этому смещению лежат данные строки.
```
Page 0 (8 КБ):
┌──────────────────────────────────────────────────────────────┐
│ Header                                                       │
├──────────────────────────────────────────────────────────────┤
│ Указатель 1: 8100                                            │
│ Указатель 2: 7950                                            │  ← растут вниз
│ Указатель 3: 7800                                            │
├──────────────────────────────────────────────────────────────┤
│                      свободное место                         │
├──────────────────────────────────────────────────────────────┤
│ [байт 7800] {id:12, email:'bob@ya.ru'}                       │
│ [байт 7950] {id:3,  email:'alice@gmail.com'}                 │  ← растут вверх
│ [байт 8100] {id:7,  email:'zack@mail.ru'}                    │
└──────────────────────────────────────────────────────────────┘
```
