
Это распределённая система из нескольких процессов, которая защищает хранилище от сбоев.
1.  **Мониторинг:** Sentinel постоянно проверяет доступность всех узлов Redis.
2.  **Failover (Восстановление):** Если ведущий узел падает, Sentinel выбирает нового мастера из подчинённых узлов.
3.  **Обнаружение сервиса:** Sentinel сообщает клиентам актуальный адрес текущего ведущего узла.
4.  **Кворум:** Это минимальное число голосов узлов Sentinel, необходимое для подтверждения недоступности мастера и начала процесса восстановления.
