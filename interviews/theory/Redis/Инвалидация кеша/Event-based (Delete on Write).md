При записи в БД — удаляем или обновляем ключ в кэше.
```go
// Обновили в БД → удаляем из кэша
func UpdateUser(id string, data User) error {
    err := db.UpdateUser(id, data)
    if err != nil {
        return err
    }
    redis.Del(ctx, "user:"+id) // следующее чтение подтянет свежие данные
    return nil
}
```

**Удалять или перезаписывать?**
```
Удалить (Del)        → проще, следующий read подтянет из БД (Cache-Aside)
Перезаписать (Set)   → быстрее для читателей, но сложнее (race condition)
```

Удалять безопаснее — нет гонки между двумя записями.

- ✅ Кэш актуален почти сразу
- ❌ Нужно не забыть удалить во всех местах где пишешь в БД
- ❌ Если забыл — stale данные, баг который сложно найти
