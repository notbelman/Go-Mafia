
| Стратегия            | Суть                                     | Когда                              |
| :------------------- | :--------------------------------------- | :--------------------------------- |
| Fallback на БД       | Redis недоступен → читаем напрямую из БД | Всегда как базовый вариант         |
| Circuit Breaker      | После N ошибок перестаём дёргать Redis   | Чтобы не тратить время на таймауты |
| Graceful Degradation | Сервис работает, но медленнее            | Кэш не критичен для бизнес-логики  |
| Fail Fast            | Сразу отдаём ошибку                      | Кэш критичен (сессии, rate limit)  |
## Мониторинг при падении Redis

Когда Redis лёг, нагрузка перекладывается на БД. Нужно видеть это:

- `redis_up` = 0 → алерт: Redis недоступен
- `pg_active_connections` растёт → БД забирает нагрузку кэша
- `http_request_duration_seconds` растёт → ответы медленнее без кэша
- `circuit_breaker_state` = open → Redis отключён автоматически
