Это компактное представление данных Redis на определённый момент времени.
*   **Как работает:** С заданными интервалами создается форк процесса, который записывает снимок всей базы в бинарный файл.
*   **Плюсы:** Максимальная скорость загрузки при старте; минимальное влияние на производительность (пишет дочерний процесс).
*   **Минусы:** Риск потери данных, записанных между моментами создания снепшотов.
