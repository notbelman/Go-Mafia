
Алгоритм обработки «промаха» кеша согласно источникам:
1.  **Обращение:** Приложение запрашивает данные у Redis.
2.  **Промах:** Если данных в Redis нет, приложение обращается к постоянному хранилищу (MySQL/Postgres).
3.  **Загрузка:** Данные, полученные из основной БД, записываются в Redis.
4.  **Результат:** Приложение использует полученные данные, а при следующем аналогичном запросе они уже будут взяты из быстрого кеша.
