После рестарта/деплоя кэш пустой → все запросы идут в БД → база перегружена.

**Решение 1: прогрев при старте** — загружаем горячие данные из БД в кэш до начала обработки трафика.
```go
func warmupCache() {
    // Загружаем самые популярные данные
    items, _ := db.GetTopItems(1000)
    for _, item := range items {
        redis.Set(ctx, "item:"+item.ID, marshal(item), 5*time.Minute)
    }
}

func main() {
    warmupCache()         // сначала прогрев
    startHTTPServer()     // потом трафик
}
```

**Решение 2: постепенная загрузка** — не прогреваем, но ограничиваем нагрузку на БД через singleflight + rate limiter, кэш заполняется органически.
