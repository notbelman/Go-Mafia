Что выведет этот код?
```go
func divide(a, b int) (int, bool) {
    if b == 0 { return 0, false }
    return a / b, true
}
func main() {
    result, ok := divide(10, 0)
    fmt.Println(result, ok)
}
```
?
`0 false` — флаг сигнализирует об ошибке, но не говорит о её причине. Это и есть главный недостаток флагового подхода.
