```
──────────────────────────────────────────────────
НАЧАЛО: WaitGroup пустой
──────────────────────────────────────────────────

counter: 0
waiters: 0

──────────────────────────────────────────────────
Запускаем 3 горутины
──────────────────────────────────────────────────

Main: wg.Add(1) → counter = 1
Main: go G1()

Main: wg.Add(1) → counter = 2
Main: go G2()

Main: wg.Add(1) → counter = 3
Main: go G3()

counter: 3
waiters: 0

──────────────────────────────────────────────────
Main вызывает Wait()
──────────────────────────────────────────────────

Main: wg.Wait()
  → counter != 0 → waiters++ → Semacquire(sema) 💤

counter: 3
waiters: 1
Main: спит на sema 💤

──────────────────────────────────────────────────
G1, G2 завершаются
──────────────────────────────────────────────────

G1: wg.Done() → Add(-1) → counter = 2 → != 0 → ничего
G2: wg.Done() → Add(-1) → counter = 1 → != 0 → ничего

counter: 1
waiters: 1
Main: спит 💤

──────────────────────────────────────────────────
G3 завершается — последняя!
──────────────────────────────────────────────────

G3: wg.Done() → Add(-1) → counter = 0
    → counter == 0 && waiters > 0
    → Semrelease(sema) × waiters раз → будим Main!

counter: 0
waiters: 0
Main: просыпается, продолжает работу

──────────────────────────────────────────────────
Несколько Wait() (редкий кейс)
──────────────────────────────────────────────────

Main1: wg.Wait() → waiters = 1 → спит 💤
Main2: wg.Wait() → waiters = 2 → спит 💤

G3: wg.Done() → counter = 0
    → Semrelease × 2 раза → будим обоих!
```
^wg-example-full

### Ключевое: когда происходит пробуждение

`Done()` будит ждущих только когда counter достигает **ровно 0**. Промежуточные `Done()` (counter = 2, 1) не делают ничего особенного. ^wg-wakeup-on-zero

### Несколько вызовов Wait()

Если несколько горутин вызвали `Wait()`, последний `Done()` (counter → 0) вызывает `Semrelease` ровно `waiters` раз — все ждущие пробуждаются одновременно. ^wg-multiple-waiters
