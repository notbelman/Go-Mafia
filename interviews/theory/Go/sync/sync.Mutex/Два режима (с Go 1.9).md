### Normal mode (по умолчанию)

- Ожидающие в очереди FIFO
- Разбуженный **конкурирует** с новыми горутинами за лок
- Новые имеют преимущество (уже на CPU, могут спиннить)
- Проигравший встаёт в **начало** очереди
- Лучше throughput

^normal-mode

### Starvation mode

**Включается:** горутина ждёт лок > 1ms ^starvation-trigger

- Лок передаётся **напрямую** первому в очереди (handoff)
- Новые горутины не спиннят, сразу в конец очереди
- Гарантия что никто не застрянет навечно
- Хуже throughput, лучше fairness

^starvation-mode

**Выключается:** waiter получил лок И: ^starvation-exit
- он последний в очереди, ИЛИ
- ждал < 1ms

### Почему нужны два режима: спиннинг vs засыпание

**Засыпание** = переключение контекста, работа с семафором, пробуждение — это дорого (~микросекунды). ^sleep-cost

**Спиннинг** = крутимся 120 циклов (~наносекунды). Если лок освободится быстро — сэкономили кучу времени. ^spin-cost

### Сравнение

|              | Normal                  | Starvation  |
| :----------- | :---------------------- | :---------- |
| Очередь      | FIFO, но с конкуренцией | Строго FIFO |
| Спиннинг     | Да                      | Нет         |
| Handoff      | Нет                     | Да          |
| Throughput   | Лучше                   | Хуже        |
| Fairness     | Хуже                    | Лучше       |
| Latency tail | Может быть большой      | Ограничен   |

^mode-comparison
