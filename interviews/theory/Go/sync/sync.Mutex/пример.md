          ↑              ↑

^example-normal-queue

```
──────────────────────────────────────────────────
G1 делает Unlock (Normal mode)
──────────────────────────────────────────────────

G1: "Unlock!" → будит G2
G2: просыпается, пытается CAS...

    В этот момент прилетает G5!
    G5: тоже пытается CAS (спиннит)
    
    G2 vs G5 — КТО БЫСТРЕЕ?
    
    G5 выигрывает (уже на CPU)
    G2 проигрывает → в НАЧАЛО очереди

Мьютекс: [LOCKED by G5]
Очередь: [G2] → [G3] → [G4]
          ↑
       G2 вернулся в начало
```
^example-normal-contention

──────────────────────────────────────────────────
G2 ждёт уже > 1ms — включается Starvation mode
──────────────────────────────────────────────────

Мьютекс: [LOCKED by G5, STARVING]
Очередь: [G2] → [G3] → [G4]
```
^example-starvation-trigger

```
──────────────────────────────────────────────────
G5 делает Unlock (Starvation mode)
──────────────────────────────────────────────────

G5: "Unlock!" → передаёт лок НАПРЯМУЮ G2 (handoff)

    G6 прилетает в этот момент
    G6: видит STARVING флаг → НЕ спиннит → сразу в конец очереди

Мьютекс: [LOCKED by G2, STARVING]
Очередь: [G3] → [G4] → [G6]
                        ↑
                    G6 в конец, без борьбы
```
^example-handoff

```
^example-starvation-stay

──────────────────────────────────────────────────

──────────────────────────────────────────────────

──────────────────────────────────────────────────

G6: "Я последний в очереди? ДА"
G6: "Выключаю starvation mode"

Мьютекс: [LOCKED by G6] ← флаг STARVING снят
Очередь: пусто
