- Семафор = счётчик + очередь ожидания. Acquire: счётчик >0 → уменьшить и пройти. Счётчик ==0 → заснуть
- Мьютекс = бинарный семафор (счётчик 0 или 1). Семафор — обобщение: до N потоков одновременно
- В Go: `golang.org/x/sync/semaphore` (взвешенный) или `chan struct{}` (простой)

---

## Операции

Классический семафор (Дейкстра, 1965):

```
P(sem) / Acquire / Wait:
    если счётчик > 0: уменьшить, пройти
    если счётчик == 0: заснуть в очереди

V(sem) / Release / Signal:
    увеличить счётчик
    если кто-то спит — разбудить одного
```

P и V — от голландских слов Proberen (проверить) и Verhogen (увеличить). ^semaphore-pv-origin

^semaphore-operations

## Реализация на Go

```go
type Semaphore struct {
    ch chan struct{}
}

func NewSemaphore(n int) *Semaphore {
    return &Semaphore{ch: make(chan struct{}, n)}
}

func (s *Semaphore) Acquire() {
    s.ch <- struct{}{}  // блокируется если буфер полон
}

func (s *Semaphore) Release() {
    <-s.ch
}
```

**Буферизированный канал** — по сути семафор: ёмкость канала = начальный счётчик. ^semaphore-buffered-chan

## Виды семафоров

**Бинарный (binary):** счётчик 0 или 1 = мьютекс. ^semaphore-binary

**Считающий (counting):** счётчик до N. Ограничивает параллелизм:

```go
// Максимум 10 одновременных запросов к БД
sem := NewSemaphore(10)

for _, query := range queries {
    sem.Acquire()
    go func(q string) {
        defer sem.Release()
        db.Exec(q)
    }(query)
}
```

^semaphore-counting

**Взвешенный (weighted):** `golang.org/x/sync/semaphore`. Acquire(n) забирает n единиц, Release(n) возвращает. Для ресурсов разного веса (например, лёгкие запросы = 1, тяжёлые = 5). ^semaphore-weighted

## Семафор vs Мьютекс

```
                Мьютекс              Семафор
Владелец       да (кто захватил,     нет (Release может
               тот отпускает)        вызвать другой поток)
Счётчик        0/1                   0..N
Рекурсия       возможна              не применимо
Назначение     защита ресурса        ограничение параллелизма
```

^semaphore-vs-mutex

Важное отличие: у мьютекса есть **владелец** — только он может Unlock. У семафора Release может вызвать **кто угодно**. Это и сила (сигнализация между потоками), и опасность (легко ошибиться). ^semaphore-no-owner

## В Go runtime

Внутри Go runtime семафоры (`runtime_Semacquire` / `runtime_Semrelease`) — основа `sync.Mutex`, `sync.WaitGroup`, `sync.RWMutex`. Это не пользовательский API, а внутренний механизм park/unpark. ^semaphore-go-runtime-internal
