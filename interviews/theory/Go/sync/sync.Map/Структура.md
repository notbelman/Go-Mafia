**Главная идея:** две map внутри. read — для быстрого чтения без лока, dirty — для записи под локом. ^struct-main-idea

```go
type Map struct {
    mu     Mutex
    read   atomic.Pointer[readOnly]  // lock-free доступ
    dirty  map[any]*entry            // под mu
    misses int                       // счётчик промахов
}

type readOnly struct {
    m       map[any]*entry
    amended bool  // true = в dirty есть ключи, которых нет в read
}

type entry struct {
    p atomic.Pointer[any]  // *value, nil, или expunged
}
```
^struct-definition

**Как связаны:**
```
sync.Map
    |
    +---> read ---> readOnly ---> map[key] ---> *entry ---> p ---> значение
    |                                              |
    |                                              | (один и тот же entry!)
    |                                              |
    +---> dirty ----------------> map[key] --------+
```
^struct-shared-entry

read и dirty содержат указатели на **одни и те же** entry. Изменил entry.p — изменилось везде. ^struct-shared-mutation
