```
──────────────────────────────────────────────────
НАЧАЛО: RWMutex свободен
──────────────────────────────────────────────────

readerCount: 0
readerWait:  0
w (внутренний Mutex): свободен
```
^example-initial-state

```
──────────────────────────────────────────────────
R1, R2, R3 хотят читать
──────────────────────────────────────────────────

R1: RLock() → readerCount.Add(1) = 1 → >= 0 → заходит
R2: RLock() → readerCount.Add(1) = 2 → >= 0 → заходит
R3: RLock() → readerCount.Add(1) = 3 → >= 0 → заходит

readerCount: 3
Все читают параллельно!
```
^example-readers-enter

```
──────────────────────────────────────────────────
W1 хочет писать (читатели ещё внутри)
──────────────────────────────────────────────────

W1: Lock()
  1. w.Lock() → захватил внутренний мьютекс
  2. readerCount.Add(-1_000_000_000) → 3 - 1млрд = -999_999_997
     (отрицательный = "писатель ждёт")
  3. r = -999_999_997 + 1млрд = 3 (реальное число читателей)
  4. readerWait.Add(3) = 3 → != 0 → Semacquire(writerSem) 💤

readerCount: -999_999_997 (отрицательный!)
readerWait:  3 (ждём 3 читателей)
W1: спит на writerSem 💤
```
^example-writer-waits

```
──────────────────────────────────────────────────
R4 хочет читать (пока W1 ждёт)
──────────────────────────────────────────────────

R4: RLock() → readerCount.Add(1) = -999_999_996
    < 0 → писатель есть → Semacquire(readerSem) 💤

readerCount: -999_999_996
R4: спит на readerSem 💤
```
^example-r4-blocks

```
──────────────────────────────────────────────────
R1, R2 заканчивают читать
──────────────────────────────────────────────────

R1: RUnlock()
  → readerCount.Add(-1) = -999_999_997
  → < 0 → slow path
  → readerWait.Add(-1) = 2 → != 0 → не будим

R2: RUnlock()
  → readerCount.Add(-1) = -999_999_998
  → < 0 → slow path
  → readerWait.Add(-1) = 1 → != 0 → не будим

readerWait: 1 (ждём ещё R3)
```
^example-r1r2-leave

```
──────────────────────────────────────────────────
R3 заканчивает — последний!
──────────────────────────────────────────────────

R3: RUnlock()
  → readerCount.Add(-1) = -999_999_999
  → < 0 → slow path
  → readerWait.Add(-1) = 0 → Semrelease(writerSem) → будим W1!

W1: просыпается, держит write lock
```
^example-r3-last

```
──────────────────────────────────────────────────
W1 пишет, потом заканчивает
──────────────────────────────────────────────────

W1: Unlock()
  1. readerCount.Add(+1млрд) = -999_999_999 + 1млрд = 1
     (r = 1 читатель ждёт — это R4)
  2. Semrelease(readerSem) × 1 раз → будим R4
  3. w.Unlock() → освобождаем внутренний мьютекс

readerCount: 1
R4: просыпается, читает
```
^example-writer-unlock

```
──────────────────────────────────────────────────
Всё свободно
──────────────────────────────────────────────────

R4: RUnlock() → readerCount.Add(-1) = 0 → >= 0 → выходит

readerCount: 0
readerWait:  0
```
