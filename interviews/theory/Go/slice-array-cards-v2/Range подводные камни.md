[[slice Flashcards - range]]
## Копирование выражения

Range копирует дескриптор (ptr, len, cap) **один раз** перед стартом цикла и итерирует по этой копии. ^range-copy-once

Поэтому `append` внутри `range` — НЕ бесконечный цикл: `len` зафиксирован. ^range-append-not-infinite

`for i := 0; i < len(s); i++` с `append` — бесконечный цикл, `len(s)` вычисляется каждый раз. ^range-vs-classic-loop

```go
s := []int{1, 2, 3}
for _, v := range s {
    s = append(s, v*10)  // НЕ бесконечный!
}
// s = [1 2 3 10 20 30] — ровно 3 итерации
```

## Value — копия

Value в range — всегда **копия** элемента. Модификация value не изменяет оригинальный slice или array. ^range-value-copy

```go
a := [3]int{1, 2, 3}
for _, v := range a {
    v += 50  // модифицируем копию, массив не изменится
}
```

## Go 1.22: новая переменная на каждой итерации

До Go 1.22: loop variable `v` переиспользуется — горутины в замыкании захватывают одну и ту же переменную, и все видят последнее значение. ^range-go122-before

Go 1.22+: на каждой итерации создаётся **новая переменная** — замыкания в горутинах работают корректно. ^range-go122-fix

## Два способа модифицировать элементы

По индексу — быстрее: нет дополнительного уровня косвенности. ^range-modify-index

Через `[]*T` — копируется указатель, но данные общие. Медленнее из-за лишних прыжков по памяти. ^range-modify-ptr

```go
// 1. По индексу (быстрее — нет лишних прыжков по памяти)
for i := range a {
    a[i] += 50
}

// 2. Срез указателей (копируется указатель, но указывает туда же)
ps := []*Account{{Balance: 100}, {Balance: 200}}
for _, p := range ps {
    p.Balance += 50
}
```

## Range по массиву — копирует ВЕСЬ массив

`range bigArr` копирует весь массив на стек/хип. Для большого массива — значительный overhead. ^range-array-copy-overhead

Решения: `range &arr` (range по указателю) или `range arr[:]` (range по срезу) — без копии. ^range-array-copy-fix

```go
bigArr := [1_000_000]int{...}
for _, v := range bigArr { ... }   // скопировал 8 МБ!
for _, v := range &bigArr { ... }  // указатель — без копии ✅
for _, v := range bigArr[:] { ... } // срез — без копии ✅
```

## Loop unrolling

Loop unrolling: шаг `i += 4`, 4 операции в теле — убираем 3 из 4 проверок условия и инкрементов. Только для горячих циклов. ^range-loop-unrolling

```go
for i := 0; i < len(s); i += 4 {
    s[i]   = process(s[i])
    s[i+1] = process(s[i+1])
    s[i+2] = process(s[i+2])
    s[i+3] = process(s[i+3])
}
```
