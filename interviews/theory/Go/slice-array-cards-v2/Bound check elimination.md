Go вставляет `if i < 0 || i >= len(s) { panic }` перед каждым доступом к элементу. ^bce-what-compiler-inserts

BCE (Go 1.7+) убирает лишние проверки. Флаг: `go build -gcflags="-d=ssa/check_bce"` ^bce-version-flag

- **константы с конца**: `s[3]; s[2]; s[1]; s[0]` → 1 check вместо 4
- **переменные через подсрез**: `sub := s[i:i+4]`, потом `sub[3]; sub[2]...` → 1 check
- **перед горячим циклом**: `_ = values[size-1]` → в цикле уже без checks
- **unsafe** — полный отказ от checks через арифметику указателей

[[slice Flashcards - bce]]
## Что вставляет компилятор

```go
// Вы пишете:
x := s[i]

// Компилятор генерирует:
if i < 0 || i >= len(s) { panic("index out of range") }
x := s[i]
```

Каждый доступ по индексу — потенциально лишняя пара инструкций в горячем коде. ^bce-overhead-per-access

## Оптимизация 1: обратный порядок констант

```go
// ❌ 4 bound check'а
_ = s[0]; _ = s[1]; _ = s[2]; _ = s[3]

// ✅ 1 bound check — если s[3] ок, то s[0..2] тоже
_ = s[3]; _ = s[2]; _ = s[1]; _ = s[0]
```

Если компилятор видит доступ к наибольшему индексу первым, он знает что меньшие индексы тоже безопасны — один check покрывает все. ^bce-opt-reverse-constants

## Оптимизация 2: подсрез для переменных

```go
// ❌ Компилятор не знает, что i неотрицательный — checks везде
_ = s[i+3]; _ = s[i+2]; _ = s[i+1]; _ = s[i]

// ✅ Один bound check на подсрезе
sub := s[i : i+4]
_ = sub[3]; _ = sub[2]; _ = sub[1]; _ = sub[0]
```

Подсрез `s[i:i+4]` — один bound check при создании. Дальнейшие обращения к `sub` с константными индексами уже без проверок (аналогично оптимизации 1). ^bce-opt-subslice

## Оптимизация 3: проверка перед горячим циклом

```go
func process(values []int, size int) {
    _ = values[size-1]  // один bound check здесь
    for i := 0; i < size; i++ {
        values[i] *= 2  // без bound check'ов
    }
}
```

Один фиктивный доступ к последнему элементу до цикла убеждает компилятор, что все индексы `0..size-1` безопасны. ^bce-opt-pre-check

## Оптимизация 4: unsafe

```go
p := unsafe.Pointer(&s[0])
for i := 0; i < len(s); i++ {
    elem := (*int)(unsafe.Add(p, uintptr(i)*unsafe.Sizeof(s[0])))
    *elem *= 2  // никаких checks, никакой защиты
}
```

`unsafe` — полный отказ от bound checks через арифметику указателей. Никакой защиты от выхода за границы. ^bce-opt-unsafe
