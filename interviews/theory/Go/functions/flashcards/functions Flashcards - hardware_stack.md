Что выведет этот код?
```go
func recurse(n int) {
    recurse(n + 1)
}

func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered:", r)
        }
    }()
    recurse(0)
}
```
?
Программа упадёт с `runtime: goroutine stack exceeds...` и не выведет "recovered". Stack overflow в Go нельзя перехватить через recover — это фатальная ошибка runtime.
