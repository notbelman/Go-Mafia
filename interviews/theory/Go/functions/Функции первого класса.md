- функции ведут себя как переменные: можно **присваивать, передавать, возвращать** ^first-class-ops
- **нельзя сравнивать** (как slice) и **нельзя взять адрес** `&fn` ^first-class-limits
- zero value любого функционального типа = **nil** ^func-zero-value
- встроенные функции (append, len, cap, make, copy...) **нельзя** использовать как значения ^builtins-not-values
- через `unsafe` взять адрес функции можно, но стандартный синтаксис — нет ^func-addr-unsafe

---

## Функция как значение

```go
// присвоить
var fn func(int) int
fn = func(x int) int { return x * 2 }

// передать в функцию
func apply(f func(int) int, x int) int { return f(x) }

// вернуть из функции
func multiplier(n int) func(int) int {
    return func(x int) int { return x * n }
}
```

## Нельзя сравнивать и брать адрес

```go
f1 := func() {}
f2 := func() {}
// f1 == f2         // ошибка компиляции
// f1 == nil        // ✅ можно только с nil
// _ = &f1          // нельзя взять адрес функции
```

## Zero value = nil

```go
var fn func(int) int
fmt.Println(fn == nil) // true
fn(5)                  // panic: nil function call
```

Семантически функция — указатель на первую инструкцию. Nil = никуда не указывает. ^func-nil-semantics

## Встроенные функции — не значения

```go
// f := append     // ошибка: cannot use append as value
// f := len        // ошибка: cannot use len as value
```

Встроенные функции и `init` нельзя использовать как значения — особенность языка. ^builtins-not-values-detail
