- функция = **адрес первой инструкции** её скомпилированного кода ^func-is-address
- параметры — переменные в объявлении; аргументы — значения при вызове ^params-vs-args
- аргументы вычисляются **слева направо** (в C++ порядок не определён) ^args-order
- сигнатура = типы входных параметров + типы возвращаемых значений (имя, тело, имена параметров — **не** часть сигнатуры) ^signature-def
- при передаче и возврате **всё копируется** (указатель, slice, map, interface — копия заголовка) ^copy-on-pass

---

## Функция = адрес

```go
func add(a, b int) int { return a + b }
// add → 0x4A3F10 (адрес первой инструкции)
```

Вызов функции = переход по этому адресу (инструкция CALL). ^func-call-instr

## Параметры vs аргументы

```go
func greet(name string) { ... }  // name — параметр (объявление)
greet("Alice")                    // "Alice" — аргумент (вызов)
```

## Порядок вычисления аргументов

```go
process(computeX(), computeY(), computeZ())
//        1️⃣            2️⃣            3️⃣
// слева направо — можно закладываться на порядок
```

## Сигнатура

```go
func add(a, b int) int            // сигнатура: (int, int) int
func sum(x, y int) int            // сигнатура: (int, int) int — та же!
// имена a/b, x/y и имя функции — не часть сигнатуры
```

## Всё копируется

```go
func modify(s []int) { s[0] = 99 }   // копия заголовка slice → тот же backing array
func replace(m map[string]int) { m["a"] = 1 } // копия указателя → тот же hmap
func bump(x int) { x++ }             // копия значения → оригинал не изменён
```

Возврат — тоже копия. ^copy-on-return

Нет RVO: объект создаётся внутри, потом копируется наружу. ^no-rvo
