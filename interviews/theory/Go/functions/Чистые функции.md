- чистая функция = **детерминированная** (один вход → всегда один выход) + **без побочных эффектов** ^pure-def
- побочные эффекты: модификация внешних переменных, I/O, рандом, глобальное состояние ^side-effects-list
- преимущества: проще читать, тестировать, параллелить (нет shared state) ^pure-benefits
- грязную функцию можно **очистить**: вынести зависимость в параметр ^impure-to-pure
- не нужно впадать в крайности — бизнес-логику и вычисления делать чистыми, I/O — грязное ^pure-pragmatics

---

## Грязная функция

```go
var counter int  // глобальная переменная

func dirtySum(a, b *int) int {
    counter++                    // модифицирует глобальное состояние
    *a = *a + *b                 // модифицирует внешнюю память
    fmt.Println(*a)              // побочный эффект (I/O)
    r := rand.Intn(10)           // недетерминированность
    secret := os.Getenv("KEY")   // зависимость от окружения
    return *a + r
}
```

## Чистая функция

```go
func pureSum(a, b int) int {
    return a + b
}
// ✅ Детерминированная: pureSum(3, 5) всегда = 8
// ✅ Нет побочных эффектов: ничего не меняет, не печатает, не читает
```

## Как очистить грязную

```go
// Грязная: зависит от rand
func dirty(min, max int) float64 {
    factor := rand.Float64()
    return float64(max-min) * factor
}

// Чистая: рандом вынесен в параметр
func clean(min, max int, factor float64) float64 {
    return float64(max-min) * factor
}
```

Приём: зависимость, которая делает функцию грязной, выносится в параметр — вызывающий код берёт ответственность за «грязь». ^extract-to-param

## Не впадать в крайности

```go
// Формально «грязная» из-за math.Pi — глобальная константа
func circleArea(r float64) float64 {
    return math.Pi * r * r
}
// Принимать Pi параметром ради «чистоты» — бессмысленно
```

Глобальные **константы** не делают функцию грязной на практике. ^constants-not-dirty

## Преимущества чистых функций

Проще разбирать (нет зависимостей от внешнего состояния), проще тестировать (не нужно мокать глобальные переменные), проще параллелить (нет shared state → нет гонок). ^pure-benefits-detail
