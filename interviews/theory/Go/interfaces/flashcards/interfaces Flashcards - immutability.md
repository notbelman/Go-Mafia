Почему этот код не компилируется и как это исправить?
```go
var w io.Writer = &bytes.Buffer{}
w.Write([]byte("hello"))
w.Reset()
```
?
`io.Writer` не имеет метода `Reset()`. Набор методов типа-интерфейса фиксирован. Нужен type assertion: `w.(*bytes.Buffer).Reset()`.
![[Иммутабельность интерфейсов#^iface-assert-to-mutate]]

Как через интерфейс мутировать объект, если нужный метод не входит в интерфейс?
?
![[Иммутабельность интерфейсов#^iface-mutation-via-assertion]]

Что выведет этот код?
```go
v := 42
var a any = v
v = 100
fmt.Println(a)
```
?
`42` — при присваивании значения в интерфейс создаётся **копия**. Дальнейшее изменение `v` не затрагивает копию в `a`.
![[Иммутабельность интерфейсов#^iface-copy-on-assign]]

Чем отличается поведение при присваивании в интерфейс значения vs указателя?
?
![[Иммутабельность интерфейсов#^iface-ptr-vs-value]]

Что выведет этот код?
```go
type Counter struct{ N int }

func inc(c any) {
    if cc, ok := c.(*Counter); ok {
        cc.N++
    }
}

x := &Counter{N: 0}
inc(x)
fmt.Println(x.N)
```
?
`1` — в интерфейс передаётся **указатель**, копируется сам указатель, а не объект. Мутация через type assertion видна снаружи.
