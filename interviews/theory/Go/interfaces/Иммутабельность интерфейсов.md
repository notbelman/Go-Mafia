- интерфейс как **тип** — иммутабельный: нельзя добавить/убрать методы в рантайме, набор фиксирован при компиляции ^iface-type-immutable
- **переменная** интерфейсного типа — мутабельная: можно менять динамический тип (переприсваивать) ^iface-var-mutable
- через type assertion можно достать конкретный тип и мутировать объект внутри ^iface-mutation-via-assertion
- при присваивании в интерфейс значение **копируется** → мутация снаружи не затрагивает копию ^iface-copy-on-assign

## Тип иммутабелен, переменная мутабельна

```go
var w io.Writer            // тип io.Writer — навсегда
w = os.Stdout              // динамический тип: *os.File
w = &bytes.Buffer{}        // динамический тип: *bytes.Buffer (изменился!)
// Набор методов (Write) — тот же. Реализация за ним — другая.
```

^iface-type-vs-var-example

## Мутация объекта внутри

```go
var w io.Writer = &bytes.Buffer{}  // w знает только про Write()
w.Write([]byte("hello"))           // ок — Write есть в io.Writer
w.Reset()  // ошибка! io.Writer не знает про Reset()

buf := w.(*bytes.Buffer)           // достаём *bytes.Buffer из интерфейса
buf.Reset()                        // ок — у *bytes.Buffer есть Reset()
```

^iface-assert-to-mutate

## Копирование при присваивании значения

```go
v := 42
var a any = v  // копия v
v = 100
fmt.Println(a) // 42 — копия не изменилась
```

При присваивании **указателя** — мутация видна через интерфейс (копируется указатель, не объект). ^iface-ptr-vs-value
