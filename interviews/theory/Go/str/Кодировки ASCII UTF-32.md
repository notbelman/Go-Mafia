- **ASCII** — 7 бит, 128 символов. Арифметика: `'W' - 'A'` = позиция в алфавите (массив `[26]int` вместо map) ^enc-ascii
- **кодовые страницы** — 8-й бит (+128 символов для конкретного языка, напр. кириллица) ^enc-codepages
- **Unicode** — 2 байта (65536 значений), проблемы: **×2 память** + **порядок байт** (BOM) ^enc-unicode-problems
- **UTF-8** — 1-4 байта, без BOM (маски), доминирует в интернете. Минус: **парсинг длины** каждого символа ^enc-utf8-tradeoff
- компромисс: память vs скорость обработки, серебряной пули нет ^enc-tradeoff

## ASCII

7 бит = 128 символов. 0–31 управляющие (`\n`, `\t`), 32–127 видимые. Старший бит не используется. ^enc-ascii-detail

Арифметика над символами — символ это число: ^enc-ascii-arithmetic

```go
var freq [26]int
for _, c := range word {
    freq[c-'a']++  // индекс = позиция в алфавите
}
// Быстрее чем map[rune]int
```

## Кодовые страницы

Расширение ASCII: 8-й бит = ещё 128 символов для конкретного языка. Первые 128 совпадают с ASCII. Проблема: 256 символов не хватает для азиатских языков. ^enc-codepages-detail

## Unicode и BOM

2 байта = 65536 значений. Проблемы: ^enc-unicode-detail

1. **×2 память** — каждый символ 2 байта даже для ASCII ^enc-unicode-memory
2. **Порядок байт** — big-endian (`0068`) или little-endian (`6800`)? ^enc-unicode-endian

Решение: **BOM** (Byte Order Mark) — 2 байта в начале строки указывают порядок. ^enc-bom

## UTF-8 / UTF-16 / UTF-32

| Кодировка | Размер символа | BOM   | Скорость обработки |
| :-------- | :------------- | :---- | :----------------- |
| UTF-8     | 1–4 байта      | нет   | медленная          |
| UTF-16    | 2 или 4 байта  | есть  | средняя            |
| UTF-32    | 4 байта        | есть  | быстрая            |

UTF-8 вместо BOM использует **битовые маски** — первый байт говорит длину символа. Минус: перед чтением каждого символа нужно распарсить маску → оверхед. ^enc-utf8-masks

**Go использует UTF-8** для строковых литералов. Java — UTF-16. UTF-32 — максимальный расход памяти, но мгновенный доступ по индексу. ^enc-lang-choice

UTF-32 позволяет доступ по индексу за O(1): смещение = `index * 4`. В UTF-8 нужно пройти все предыдущие символы, чтобы найти N-й. ^enc-utf32-index

Балун: "Редко мы встречаем серебряную пулю. Либо платим памятью и получаем быстрый процессинг, либо наоборот." ^enc-no-silver-bullet
