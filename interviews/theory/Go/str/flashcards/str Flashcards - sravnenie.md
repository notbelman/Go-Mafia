Что выведет этот код? Какая сложность каждого сравнения?
```go
b := make([]byte, 1<<20)
s1 := string(b)
s2 := string(b)
s3 := s1
fmt.Println(s1 == s2)  // A
fmt.Println(s1 == s3)  // B
```
?
Оба выведут `true`. A — O(n), 1 MB побайтово (разные ptr, два `string(b)` = две аллокации). B — O(1), `s3 := s1` копирует только header, ptr совпадает.
