- `len(s)` — количество **байт**, не символов. Для константы — **compile time** (подставляется число)
- подстрока `s[i:j]` — по **байтам**, может **разрезать** многобайтовый символ → мусор
- подстрока возвращает **string**, не slice — иначе можно было бы изменить immutable строку
- нельзя `&s[i]` — через указатель можно изменить строку
- `utf8.RuneCountInString(s)` — количество рун, но за **O(n)** (парсинг масок)

---

## len() = байты

```go
s := "hello世界"
len(s)                        // 11 (5 ASCII + 3 + 3)
utf8.RuneCountInString(s)     // 7 символов — за O(n)!
```

`len(s)` возвращает количество **байт**, а не символов. ^len-bytes

Для константной строки `len()` вычисляется на этапе компиляции — компилятор подставляет число, функция не вызывается. ^len-const-compiletime

`utf8.RuneCountInString(s)` — единственный способ узнать количество символов, но работает за O(n) — обходит всю строку для парсинга UTF-8 масок. ^len-rune-count-on

## Подстрока — по байтам, не символам

```go
s := "привет"       // кириллица = 2 байта на символ
s2 := s[0:2]        // "п" — первые 2 байта = одна буква ✅
s3 := s[0:3]        // мусор — разрезали букву 'р' пополам ❌
```

Срез `s[i:j]` работает по индексам байт, а не рун. Если срезать посередине многобайтового символа — получим невалидный UTF-8. ^substr-bytes

## Почему подстрока возвращает string, не slice

```go
s := "hello"
sub := s[1:4]  // возвращает string "ell", не []byte
```

Если бы вернулся `[]byte`, можно было бы через него изменить оригинальную строку — нарушение иммутабельности. ^substr-returns-string

## Нельзя взять адрес байта

```go
s := "hello"
p := &s[0]  // ❌ compile error
```

Имея указатель, можно записать новое значение → изменить строку. Go запрещает. ^no-addr-of-byte

Обход через unsafe:
```go
s := "hello"
sub := s[2:]                          // "llo"
ptr := unsafe.StringData(sub)         // адрес первого байта подстроки
fmt.Println(*ptr)                     // 108 ('l')
```
^no-addr-unsafe-workaround

## Bound checks

```go
const s = "hello"
_ = s[10]     // константа → ошибка компиляции (len известен)

i := 10
_ = s[i]      // переменная → panic в runtime
```

Для константной строки индекс проверяется на этапе компиляции. Для переменной — panic в runtime. Bound check elimination работает для строк так же, как для slice и массивов. ^bound-checks
