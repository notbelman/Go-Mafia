Строки в Go нельзя изменить после создания. Любая "модификация" создаёт новую строку. ^imm-def

```go
s := "hello"
s[0] = 'H'  // ошибка компиляции: cannot assign to s[0]

s = "Hello"  // ок — это новая строка, не изменение старой
```

**Почему иммутабельность:**

1. **Безопасный sharing** — несколько переменных указывают на одни данные, никто не сломает другому ^imm-reason-sharing
2. **Concurrency** — можно читать из горутин без блокировок ^imm-reason-concurrency
3. **Map keys** — строки можно использовать как ключи, потому что они не изменятся ^imm-reason-map-keys
4. **Compiler optimizations** — компилятор знает что данные не изменятся ^imm-reason-compiler

**Цена иммутабельности:** ^imm-cost

```go
s := ""
for i := 0; i < 10000; i++ {
    s += "a"  // каждый раз новая аллокация + копирование
}
// O(n²) по памяти и времени
```

Каждая конкатенация `+=` создаёт новую строку, копируя все предыдущие данные. 10 000 итераций = O(n²) аллокаций. ^imm-cost-quadratic

Решение — `strings.Builder` или `[]byte` для построения строк. ^imm-solution
