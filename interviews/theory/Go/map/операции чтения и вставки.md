[[map Flashcards - operations]]
**Чтение `v := m[key]` → `runtime.mapaccess1`:**
1. `h == nil || h.count == 0` → вернуть zero value (безопасно)
2. Проверить `flags & hashWriting` → если кто-то пишет → **fatal error** (не panic)
3. `hash = hasher(key, hash0)`
4. `bucket = hash & (2^B - 1)` → номер бакета
5. Если идёт эвакуация и этот бакет ещё не переехал (`< nevacuate`) → читаем из `oldbuckets`
6. `tophash = hash >> 56` (старшие 8 бит) → быстрый фильтр
7. Проходим 8 слотов: tophash совпал → сравниваем ключ → совпал → возвращаем value
8. Не нашли → идём по `overflow` → повторяем шаги 6-7
9. Цепочка кончилась → zero value ^op-read-steps

Чтение из nil map безопасно — вернёт zero value. ^op-nil-read-safe

**Вставка `m[key] = value` → `runtime.mapassign`:**
1. `h == nil` → **panic** ("assignment to entry in nil map")
2. `flags & hashWriting != 0` → **fatal error** ("concurrent map writes")
3. `hash = hasher(key, hash0)`
4. Ставим бит `hashWriting` в flags (после hasher, т.к. hasher может паниковать)
5. `buckets == nil` → аллоцируем первый бакет (lazy init)
6. Если идёт resize → `evacuate()` бакет, в который попадает ключ
7. Находим бакет по `hash & mask`
8. Ищем ключ по цепочке (tophash → полное сравнение)
9. Нашли → перезаписываем value
10. Не нашли → запоминаем первый пустой слот по пути
11. Пустой слот есть → вставляем туда (записываем tophash, key, value)
12. Пустого слота нет → создаём overflow бакет → вставляем
13. `count++`
14. Проверяем: load factor > 6.5 **или** overflow бакетов >= 2^B → `hashGrow()` (resize)
15. Снимаем бит `hashWriting` ^op-write-steps

**Удаление `delete(m, key)` → `runtime.mapdelete`:**
1. `h == nil || h.count == 0` → ничего не делаем (безопасно)
2. `flags & hashWriting` → **fatal error**
3. Ставим бит `hashWriting`
4. Если идёт resize → `evacuate()` соответствующий бакет
5. Находим бакет, ищем ключ (tophash → полное сравнение)
6. Нашли → зануляем key и value, ставим `tophash = emptyOne` (или `emptyRest` если все следующие тоже пустые)
7. `count--`
8. Если `count == 0` → **сбрасываем hash0** (новый seed)
9. Снимаем бит `hashWriting`
10. **Бакет НЕ освобождается** — память не возвращается ^op-delete-no-free
