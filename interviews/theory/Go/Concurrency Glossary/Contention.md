- **Contention** — конкуренция за общий ресурс. Больше горутин борются за один мьютекс/атомик → **ниже** пропускная способность ^cnt-def
- Три вида: **lock** (ждут мьютекс), **CAS** (крутят CAS впустую), **cache** (MESI invalidation на одну кэш-линию) ^cnt-types
- Если добавление ядер **не ускоряет** программу — скорее всего contention ^cnt-symptom

---

## Как снизить

| Способ | Что делает |
|:--|:--|
| **Шардирование** | 1 мьютекс → N мьютексов |
| **Мелкогранулярные локи** | лок на запись, не на таблицу |
| **Lock-free** | убрать мьютексы → атомики |
| **Padding** | разнести переменные по кэш-линиям |
| **Уменьшить КС** | меньше кода под локом |
^cnt-reduce

## Связь с законом Амдала

Contention = последовательная часть программы. Закон Амдала: `S = 1 / ((1-P) + P/N)`. Чем больше contention → тем меньше P → добавление ядер не поможет. ^cnt-amdahl

## Как обнаружить

```bash
go test -bench . -count 5   # если больше ядер ≠ быстрее → contention
go tool pprof -contentiondelay  # профиль contention
```
^cnt-detect
