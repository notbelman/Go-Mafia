Что выведет этот код?
```go
runtime.GOMAXPROCS(1)
i := 0
go func() {
    i = 42
}()
fmt.Println(i)
```
?
`0` — инструкция `go` не запускает горутину немедленно. При GOMAXPROCS=1 горутина не получит CPU до первой точки переключения. fmt.Println выполнится раньше.
