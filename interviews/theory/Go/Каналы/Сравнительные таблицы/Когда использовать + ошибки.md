
| Тип                    | Основное применение                                          |
| :--------------------- | :----------------------------------------------------------- |
| **Nil**                | Динамическое отключение веток в `select`                     |
| **Небуферизированный** | Гарантированная доставка, сигналы (`chan struct{}`), рандеву |
| **Буферизированный**   | Развязка producer/consumer, пулы воркеров, сглаживание пиков |

| Ошибка | Тип канала | Результат |
|:-------|:-----------|:----------|
| Запись в закрытый | Любой | panic |
| Повторный close | Любой | panic |
| Close nil | Nil | panic |
| Чтение из nil вне select | Nil | Горутина зависает навсегда |
| Забыть проверить `ok` после close | Закрытый | Бесконечный цикл с zero values |
