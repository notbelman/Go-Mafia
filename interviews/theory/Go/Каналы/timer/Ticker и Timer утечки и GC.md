- До Go 1.23: Ticker без Stop() = утечка горутины. Timer GC собирал сам после срабатывания
- С Go 1.23: Stop не обязателен ни для Ticker, ни для Timer — финализаторы чистят
- Reset до 1.23 не сбрасывал буфер канала — старый тик читался мгновенно. С 1.23 сбрасывает

---

## Проблема до Go 1.23

Внутри Ticker — горутина которая sleep + пишет в канал. Если никто не вызвал Stop():

```go
// утечка горутины до Go 1.23!
func bad() {
    ticker := time.NewTicker(1 * time.Second)
    // забыли defer ticker.Stop()
    <-ticker.C  // прочитали один тик
    return       // ticker.C горутина продолжает жить и писать
}
```

Горутина Ticker'а крутится вечно → **goroutine leak**. GC не может собрать — горутина активна. ^leak-ticker-pre123

Timer после срабатывания — горутина завершалась сама → GC собирал без проблем. ^leak-timer-pre123

## Go 1.23 — финализаторы

С Go 1.23 Stop **не обязателен** для GC: когда Ticker/Timer больше не referenced, GC добирается до него. ^gc123-stop-not-required

Скорее всего через **finalizers** — функция вызывается перед сборкой объекта. Документация теперь явно говорит: Stop не обязателен. ^gc123-finalizers

Но Stop всё ещё **хорошая практика** — финализаторы не гарантируют *когда* сработают. ^gc123-stop-good-practice

## Reset и буфер — изменение в Go 1.23

```go
ticker := time.NewTicker(1 * time.Second)
time.Sleep(2 * time.Second)  // тик уже в канале
ticker.Reset(3 * time.Second)

// До Go 1.23:
<-ticker.C  // мгновенно! старый тик всё ещё в буфере

// С Go 1.23:
<-ticker.C  // ждёт 3 секунды — Reset сбросил буфер
```

**До 1.23**: Reset менял интервал, но не трогал канал. Если тик уже в буфере — прочитается мгновенно. ^reset-pre123

**С 1.23**: Reset сбрасывает буферизированное событие. Следующее чтение ждёт новый интервал. ^reset-post123

## Резюме изменений Go 1.23

```
                        До 1.23              С 1.23
Ticker без Stop()       утечка горутины      GC соберёт (финализатор)
Timer без Stop()        GC соберёт           GC соберёт
Reset чистит буфер      нет                  да
Stop обязателен         да (Ticker)          нет (но хорошая практика)
```
