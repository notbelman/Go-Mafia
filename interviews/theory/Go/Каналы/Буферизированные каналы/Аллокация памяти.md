Для небольших элементов `hchan` и `buf` выделяются **одним непрерывным блоком**:

```
┌─────────────────────────────────────────┐
│  hchan struct  │  buf (ring buffer)     │
│  (96 bytes)    │  (n × elemsize bytes)  │
└─────────────────────────────────────────┘
         Один блок в куче (heap)
```

^alloc-single-block

`hchan` занимает фиксированные **96 bytes**. ^alloc-hchan-size

Размер буфера в байтах: `n × elemsize`, где `n` — ёмкость канала, `elemsize` — размер одного элемента. ^alloc-buf-size

**Выгода единого блока**: улучшение cache locality, меньше фрагментация, проще для GC. ^alloc-benefit
