### Send: буфер полон, никто не ждёт

Горутина-отправитель засыпает в `sendq` и ждёт receiver. ^send3-desc

```
ДО:
  буфер: [A, B, C]
  qcount: 3 (полон)
  recvq: пусто

G1: ch <- D

  lock()
  создаём sudog (elem = &D)
  встаём в sendq
  unlock()
  gopark()   → G1: running → waiting 💤

  ... G1 спит в sendq ...

G2: x := <-ch

  lock()
  x = buf[recvx]         → x = A
  buf[sendx] = G1.elem   → buf[0] = D (Handoff)
  unlock()
  goready(G1)            → G1 в runqueue

ПОСЛЕ:
  буфер: [D, B, C]
  sendq: пусто
  
  G1: проснулся, его D в буфере ✓
  G2: x = A ✓
```

^send3-steps

**sudog** создаётся с `elem = &D` — указатель на данные которые G1 хочет отправить. ^send3-sudog

Пробуждение G1 происходит через **Handoff**: receiver одновременно читает из буфера и кладёт данные G1 на освободившееся место. ^send3-handoff
