### Recv: буфер не пуст, никто не ждёт

Обычное чтение из буфера. Самый простой и частый путь. ^recv1-desc

```
ДО:
  буфер: [A, B, _]
  recvx: 0
  qcount: 2
  sendq: пусто

G1: x := <-ch
  lock()
  x = buf[recvx]   → x = buf[0] → x = A
  recvx++          → recvx = 1
  qcount--         → qcount = 1
  unlock()

ПОСЛЕ:
  буфер: [_, B, _]
  recvx: 1
  qcount: 1
  x = A ✓
```

^recv1-steps

Операции под мьютексом: читаем `buf[recvx]`, инкрементируем `recvx`, декрементируем `qcount`. ^recv1-mutex-ops
