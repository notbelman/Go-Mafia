Для `select` с веткой `default` рантайм проверяет состояние **атомарно без мьютекса**:

```go
// Псевдокод быстрой проверки
if atomic.Load(&c.qcount) == 0 {  // пусто — сразу default
    return  
}
if atomic.Load(&c.qcount) == c.dataqsiz {  // полон — сразу default
    return
}
```

Это lock-free fast path: вместо захвата мьютекса рантайм делает атомарное чтение `qcount` и немедленно уходит в ветку `default`, если канал пуст или полон. Мьютекс захватывается только если fast path не сработал и нужна реальная операция. ^lfp-mechanism

Преимущество: отправитель или получатель не блокируется даже на мьютекс при non-blocking check. ^lfp-benefit
