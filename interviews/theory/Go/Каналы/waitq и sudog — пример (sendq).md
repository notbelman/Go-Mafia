```
──────────────────────────────────────────────────
НАЧАЛО: пустой небуферизированный канал
──────────────────────────────────────────────────

ch := make(chan int)

hchan:
  sendq: пусто
  recvq: пусто

──────────────────────────────────────────────────
G1 хочет отправить, но никто не читает
──────────────────────────────────────────────────

G1: ch <- 10

lock()
некому отдать → создаём sudog1 {
    g:    G1
    elem: &10
    c:    ch
}
встаём в sendq
unlock()
gopark()   → G1 спит 💤

hchan:
  sendq: [sudog1]
  recvq: пусто

──────────────────────────────────────────────────
G2 тоже хочет отправить
──────────────────────────────────────────────────

G2: ch <- 20

lock()
некому отдать → создаём sudog2
встаём в sendq
unlock()
gopark()   → G2 спит 💤

hchan:
  sendq: [sudog1] → [sudog2]
             ↓          ↓
           G1,10      G2,20

G1: спит 💤
G2: спит 💤

──────────────────────────────────────────────────
G3 хочет ПОЛУЧИТЬ
──────────────────────────────────────────────────

G3: x := <-ch

lock()
sendq не пустой → достаём sudog1 (FIFO)
x = sudog1.elem   → x = 10 (Direct Copy из стека G1)
unlock()
goready(G1)   → G1 в runqueue

hchan:
  sendq: [sudog2]
             ↓
           G2,20
  recvq: пусто

G1: проснулся ✓
G2: спит 💤
G3: x = 10 ✓
```
^sendq-example-full

**Ключевые моменты примера:**

При наличии ждущего sender в sendq — receiver копирует данные **напрямую из стека sender** (Direct Copy), минуя буфер канала. Это оптимизация для небуферизированных каналов. ^sendq-direct-copy

Очередь sendq работает по принципу **FIFO** — первый заблокировавшийся sender первым и разблокируется. ^sendq-fifo
