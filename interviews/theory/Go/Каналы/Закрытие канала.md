Операция `close(ch)` переводит канал в особое состояние, сигнализирующее об **окончании передачи данных**. Это основной механизм для корректного завершения горутин и broadcast-уведомлений. ^close-overview

## Внутреннее устройство (`closechan`)

Когда вызывается `close(ch)`, runtime выполняет:

1. `ch == nil?` → **panic**: "close of nil channel" ^close-nil-panic
2. `lock()`
3. `ch` уже закрыт? → `unlock()` → **panic**: "close of closed channel" ^close-already-closed
4. `c.closed = 1` ^close-set-flag
5. Все из `recvq` → добавляем в `glist` (получат zero value + `ok=false`) ^close-recvq
6. Все из `sendq` → добавляем в `glist` (получат panic при пробуждении) ^close-sendq
7. `unlock()`
8. `goready()` для всех из `glist` → все просыпаются ^close-goready-all

Горутины из `sendq` получают panic не сразу — они просыпаются и panic происходит когда пытаются продолжить send. ^close-sendq-deferred-panic

> Канал закрывается **только для записи**. Читать можно — получишь zero value. Писать — всегда panic. ^close-read-write-rule

## Broadcast через close

Закрытие канала разблокирует **всех** ждущих читателей — каждый получает zero value + ok=false. Это единственный способ broadcast через каналы. ^close-broadcast

```go
done := make(chan struct{})
// 100 горутин ждут: <-done
close(done)  // все 100 разблокируются одновременно
```

**Отличие от sync.Cond:** close можно вызвать только один раз (повторный = паника). sync.Cond.Broadcast — многократно. ^close-vs-synccond

## Чтение после close буферизированного

```go
ch := make(chan int, 2)
ch <- 10
ch <- 20
close(ch)
// <-ch → 10, true   ← данные из буфера, ok=true!
// <-ch → 20, true   ← ещё данные
// <-ch → 0, false   ← буфер пуст, теперь false
```

Закрытие не уничтожает данные в буфере. Сначала дочитываются все значения (с ok=true), только потом zero value. ^close-buffered-read

## Скользкий момент: заблокированные писатели

```go
ch := make(chan int)  // небуферизированный
go func() {
    ch <- 42         // G попадает в sendq, ждёт читателя
}()
time.Sleep(500 * time.Millisecond)
close(ch)            // будим G из sendq → G пытается дописать → ПАНИКА
```

При close все горутины из sendq просыпаются. Просыпаясь, они обнаруживают закрытый канал и паникуют. Если закрываете канал — убедитесь, что все писатели уже дописали. ^close-blocked-writers
