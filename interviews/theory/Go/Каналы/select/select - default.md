Наличие `default` делает весь блок `select` **неблокирующим**. ^select-default-nonblocking

Если данные недоступны ни в одном канале прямо сейчас, `select` не вызывает `gopark`, а немедленно выполняет код в `default`. ^select-default-no-gopark

**Оптимизация**: Для неблокирующих операций (с `default`) рантайм может использовать быстрые атомарные проверки состояния канала без захвата мьютекса. ^select-default-atomic
