
| Сценарий                            | Результат                                        |
| :---------------------------------- | :----------------------------------------------- |
| **Один канал готов**                | Выполняется этот `case`                          |
| **Несколько каналов готовы**        | Выбирается один **случайно**                     |
| **Ничего не готово (нет default)**  | Горутина блокируется до готовности любого канала |
| **Ничего не готово (есть default)** | Немедленно выполняется `default`                 |
| **Только nil-каналы (нет default)** | **Deadlock**                                     |
| **Пустой select {}**                | **Deadlock** (блокировка навсегда)               |
