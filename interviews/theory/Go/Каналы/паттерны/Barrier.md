- Barrier — примитив синхронизации: все горутины ждут друг друга перед переходом на следующий этап
- Два канала (before/after) + счётчик + мьютекс: последняя пришедшая горутина разблокирует остальных
- Редко нужен на практике, но незаменим для стадийной обработки

---

## Идея

N горутин работают этапами. Каждая должна закончить текущий этап прежде чем любая перейдёт к следующему. ^barrier-idea

```
Этап 1: [G1 работает] [G2 работает] [G3 работает]
         ─────────── barrier ───────────
Этап 2: [G1 работает] [G2 работает] [G3 работает]
         ─────────── barrier ───────────
Этап 3: ...
```

## Использование

```go
b := NewBarrier(3)

for i := 0; i < 3; i++ {
    go func() {
        for round := 0; round < 3; round++ {
            b.Before()       // ждём, пока все закончат предыдущий этап
            bootstrap()      // этап 1
            b.After()        // ждём, пока все закончат этап 1
            work()           // этап 2
        }
    }()
}
```

^barrier-usage

## Реализация

```go
type Barrier struct {
    mu      sync.Mutex
    count   int
    size    int
    before  chan struct{}
    after   chan struct{}
}

func NewBarrier(n int) *Barrier {
    return &Barrier{
        size:   n,
        before: make(chan struct{}, n),
        after:  make(chan struct{}, n),
    }
}
```

^barrier-struct

**Before()**: каждая горутина инкрементирует count. Последняя (count == size) пишет N раз в before-канал — разблокирует всех. ^barrier-before

**After()**: каждая горутина декрементирует count. Последняя (count == 0) пишет N раз в after-канал — разблокирует всех. ^barrier-after

Ключ: **последняя пришедшая** горутина отпускает остальных записью в буферизированный канал. ^barrier-key

## Почему каналы буферизированные

`before` и `after` создаются с буфером `n`. Это позволяет последней горутине записать N значений без блокировки — каждая горутина затем прочитает своё значение. ^barrier-buf

## Когда нужен

- Параллельные вычисления с зависимостями между этапами
- Симуляции (все агенты завершили шаг → переходим)
- Тестирование (синхронизировать старт N горутин) ^barrier-when
