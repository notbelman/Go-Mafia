^hchan-fields-table

**Детали по ключевым полям:**

`qcount` и `dataqsiz` вместе описывают заполненность буфера: `qcount == dataqsiz` означает буфер полон. ^hchan-qcount-dataqsiz

`closed` имеет тип `uint32` (а не `bool`) — это позволяет использовать атомарные операции (`atomic.LoadUint32`) для чтения флага без захвата мьютекса. ^hchan-closed-uint32

`sendx` и `recvx` реализуют кольцевой буфер: при достижении конца массива индекс обнуляется. ^hchan-ring-buffer

`elemtype` хранит `*_type` — рефлексивное описание типа, используемое рантаймом при копировании данных через `memmove`. ^hchan-elemtype
