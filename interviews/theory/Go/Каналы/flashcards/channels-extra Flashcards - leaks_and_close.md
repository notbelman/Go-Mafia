Что выведет этот код?
```go
func main() {
    ch := make(chan int)
    go func() {
        for v := range ch {
            fmt.Println(v)
        }
        fmt.Println("done")
    }()
    ch <- 1
    ch <- 2
    close(ch)
    time.Sleep(10 * time.Millisecond)
}
```
?
`1`, `2`, `done` — range печатает все значения, после close range завершается и печатает "done". Если убрать `close(ch)` — "done" никогда не появится, горутина утечёт.
![[Утечки горутин и правила закрытия#^leak-reader-pattern]]

Что выведет этот код?
```go
func fastest() string {
    ch := make(chan string)
    for i := 0; i < 3; i++ {
        go func(i int) {
            ch <- fmt.Sprintf("result-%d", i)
        }(i)
    }
    return <-ch
}
func main() {
    fmt.Println(fastest())
}
```
?
Одну строку вида `result-0`, `result-1` или `result-2` — недетерминировано. Но 2 горутины навсегда заблокированы на записи в небуферизированный канал. Утечка.
