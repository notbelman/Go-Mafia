ШАГ 3: mcache стартует ПУСТЫМ
═══════════════════════════════════════════════════════════════

Допустим GOMAXPROCS=2, значит 2 процессора: P0 и P1.
Каждый P получает свой mcache.
При старте mcache пустой — все слоты указывают на пустышку (emptymspan).

P0 mcache:                          P1 mcache:
┌──────────────────────┐            ┌──────────────────────┐
│ класс 1  (8B)  → ∅   │            │ класс 1  (8B)  → ∅   │
│ класс 2  (16B) → ∅   │            │ класс 2  (16B) → ∅   │
│ класс 3  (24B) → ∅   │            │ класс 3  (24B) → ∅   │
│ ...                  │            │ ...                  │
│ класс 67 (32KB)→ ∅   │            │ класс 67 (32KB)→ ∅   │
└──────────────────────┘            └──────────────────────┘

∅ = пустышка (emptymspan), нет свободных блоков.
Спаны создаются ЛЕНИВО — только когда реально попросят.
Спан — это просто кусок памяти (одна или несколько страниц), нарезанный на блоки одного класса.

═══════════════════════════════════════════════════════════════
ШАГ 4: Горутина на P0 первый раз просит 20 байт
═══════════════════════════════════════════════════════════════

4.1  Округляем 20 → ближайший класс = 3 (24B)

4.2  mcache P0 смотрит слот класса 3 → там ∅ (пустышка)
     Нет спана! Надо получить.

4.3  mcache P0 идёт в mcentral класса 3 (лок!)
     mcentral тоже пуст → идёт в mheap

4.4  mheap берёт стр1 из арены
     → создаёт спан: нарезает стр1 на блоки по 24B
     → отдаёт спан в mcentral → mcentral отдаёт в mcache P0

4.5  Теперь mcache P0 выглядит так:

     P0 mcache:
     ┌───────────────────────────────────────────────┐
     │ класс 1  (8B)  → ∅                            │
     │ класс 2  (16B) → ∅                            │
     │ класс 3  (24B) → спан из стр1:                │
     │                   [24B][24B][24B]...[24B]     │
     │                    ↑                          │
     │                    берём этот блок            │
     │ класс 4  (32B) → ∅                            │
     │ ...                                           │
     └───────────────────────────────────────────────┘

4.6  Горутина получила блок 24B. Готово. Без локов больше не будет
     пока этот спан не заполнится.
