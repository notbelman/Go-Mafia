- frame создаётся при вызове функции, исчезает при return ^frame-lifecycle
- переменные внутри frame живут **только пока функция выполняется** ^frame-vars-lifetime
- return копирует значение в frame вызывающей функции ^frame-return-copy

---

[[memory Flashcards - stack_example]]

```go
func main() {
    x := 10
    y := add(x, 5)  // вызов создает новый frame
}                   // frame main исчезает

func add(a, b int) int {
    sum := a + b    // sum живет только пока add выполняется
    return sum
}                   // frame add исчезает, sum больше нет
```

^a669ee

```
Во время вызова add():

          stack
+-------------------+
| frame main        |
|   x = 10          |
|   y = ?           |
+-------------------+
| frame add         |  <-- текущий
|   a = 10          |
|   b = 5           |
|   sum = 15        |
+-------------------+

После return из add():

+-------------------+
| frame main        |  <-- текущий  
|   x = 10          |
|   y = 15          |
+-------------------+
                       frame add исчез
```

Frame создается при вызове, исчезает при return. Переменные внутри frame живут только пока функция выполняется. ^frame-summary
