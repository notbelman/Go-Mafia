[[memory Flashcards - stack_growth_direction]]

В классической модели процесса (C, C++):
```
Высокие адреса
┌─────────────┐
│    Стек ↓   │  растёт вниз (от высоких к низким)
│             │
│    ...      │
│             │
│    Куча ↑   │  растёт вверх (от низких к высоким)
├─────────────┤
│  Data/BSS   │
├─────────────┤
│    Code     │
└─────────────┘
Низкие адреса
```
^classic-memory-layout

В Go это менее релевантно: стек горутины — обычный объект на куче. При росте не расширяется на месте, а копируется в новый блок памяти × 2. Направление роста значения не имеет. ^go-goroutine-stack-object
