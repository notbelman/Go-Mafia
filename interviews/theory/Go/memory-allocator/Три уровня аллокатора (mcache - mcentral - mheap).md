- **mcache** — per-P, без локов. Большинство аллокаций здесь ^alloc-mcache-def

- **mcentral** — по одному на каждый size class (67 штук), с локами ^alloc-mcentral-def

- **mheap** — один глобальный, раздаёт страницы из арен ^alloc-mheap-def

---

[[memory Flashcards - allocator_levels]]

**Зачем три уровня:**

Если все горутины лезут за памятью в одно место → contention (все ждут один лок). Решение — иерархия: сначала быстро, потом медленнее. ^alloc-why-hierarchy

**Почему mcache на P, а не на M (поток):**

TCMalloc делал кэш per-thread. Go улучшил: привязал к P. Когда M блокируется на syscall, P с mcache переходит к другому M → память не простаивает. ^alloc-p-not-m
