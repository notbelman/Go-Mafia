- куча = область памяти для данных, которые **не могут жить на стеке**
- общая для всех горутин (в отличие от стека — у каждой горутины свой)

[[memory Flashcards - heap]]

Куча — область памяти для данных, которые не могут жить на стеке. ^heap-definition

Куча общая для всех горутин, в отличие от стека — у каждой горутины свой. ^heap-shared

**Почему медленнее стека:**

Сложный поиск свободного блока (не просто сдвиг указателя). ^heap-slow-search

Нужна синхронизация: куча общая → локи. ^heap-slow-locks

Нужен GC для освобождения: стек освобождается при return, куча — нет. ^heap-slow-gc
