- Go просит у ОС память большими кусками — **арены по 64MB** ^heap-arena-size

- арена нарезается на **страницы по 8KB** ^heap-page-size

- страницы объединяются в **спаны (mspan)** ^heap-span-def

- каждый спан обслуживает **один класс размеров** ^heap-span-one-class

---

[[memory Flashcards - heap_organization]]

**Почему арены, а не маленькие куски:**

Каждый запрос к ОС = syscall = дорого. Лучше попросить 64MB один раз, чем 1KB тысячу раз. ^heap-why-arenas

**Цепочка:**

``` 
Go запрашивает у ОС арену (64MB на Linux) 
	→ арена нарезается на страницы (8KB каждая) 
		→ страницы объединяются в спаны (mspan) 
			→ каждый спан обслуживает один size class 
```
^heap-chain

**Спан (mspan)** — ключевое понятие:

```
Спан для класса 8B (1 страница = 8KB):
[8B][8B][8B][8B][8B]...[8B]  — 1024 блока по 8 байт

Спан для класса 24B (1 страница = 8KB):
[24B][24B][24B]...[24B]  — 341 блок по 24 байт

Спан для класса 32KB (4 страницы = 32KB):
[32KB]  — 1 блок
```
^heap-span-examples

Спан = группа страниц, нарезанная на одинаковые блоки. Размер блока = класс размеров. ^heap-span-summary
