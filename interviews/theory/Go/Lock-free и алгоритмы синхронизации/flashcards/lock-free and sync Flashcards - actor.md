Что выведет этот код?
```go
inbox := make(chan int, 3)
inbox <- 1
inbox <- 2
inbox <- 3

go func() {
    for v := range inbox {
        fmt.Println(v)
    }
}()

time.Sleep(10 * time.Millisecond)
close(inbox)
time.Sleep(10 * time.Millisecond)
```
?
`1 2 3` — буферизированный канал = inbox актора. Горутина вычитывает по одному FIFO. После close(inbox) range завершается. Это базовая модель актора в Go.
