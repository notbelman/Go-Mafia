Что выведет этот код?
```go
type Point struct{ X, Y int }
p1 := Point{X: 10, Y: 20}
p2 := p1
p2.X = 99
fmt.Println(p1.X, p2.X)
```
?
`10 99` — `p2 := p1` делает побитовую копию всех полей. Изменение `p2.X` не затрагивает `p1`, это независимые значения.
![[Структуры_основы#^struct-copy-shallow]]

Что копируется при присвоении структуры, содержащей slice или map?
?
![[Структуры_основы#^struct-copy-shallow]]

Что выведет этот код?
```go
type S struct{ Data []int }
a := S{Data: []int{1, 2, 3}}
b := a
b.Data[0] = 99
fmt.Println(a.Data[0])
```
?
`99` — побитовое копирование структуры копирует заголовок slice (указатель + len + cap), но не данные. `a.Data` и `b.Data` указывают на один и тот же underlying array.
