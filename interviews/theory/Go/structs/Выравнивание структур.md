- **требуемое выравнивание** структуры = размер **максимального поля** (после распаковки до примитивов) ^align-rule-max
- порядок полей влияет на размер структуры (padding заполняется **нулями**, не мусором) ^align-padding-zeros
- компилятор Go **никогда не меняет** порядок полей ^align-compiler-no-reorder
- массивы: выравнивание = выравнивание типа элемента (`[123]byte` → выравнивание 1) ^align-array-rule
- вложенные структуры распаковываются до примитивов для определения выравнивания ^align-nested-unpack

## Порядок полей → разный размер

```go
type Data1 struct {
    A bool    // 1 байт
    B int32   // 4 байта
    C bool    // 1 байт
}
// Выравнивание = 4 (максимальное поле = int32)
// Layout: [A][pad][pad][pad] [B B B B] [C][pad][pad][pad]
// Размер: 12 байт

type Data2 struct {
    B int32   // 4 байта
    A bool    // 1 байт
    C bool    // 1 байт
}
// Layout: [B B B B] [A][C][pad][pad]
// Размер: 8 байт
```

Те же поля, но Data2 на 4 байта меньше — булы рядом, один padding. ^align-field-order-example

## Почему padding в конце?

Структура выровнена на N байт → её размер **кратен N**. Даже если последнее поле — bool (1 байт), до кратности N добьётся padding. Это нужно для корректной работы в массивах/срезах: каждый элемент должен начинаться по выровненному адресу. ^align-trailing-padding

## Массивы: выравнивание = тип элемента

```go
type X struct {
    A bool           // 1 байт
    B [123]byte      // выравнивание = 1 (элемент = byte)
    C bool           // 1 байт
}
// Выравнивание структуры = 1 байт!
// Размер = 125 байт (без padding)

type Y struct {
    A bool
    B [123]int16     // выравнивание = 2 (элемент = int16)
    C bool
}
// Выравнивание структуры = 2 байта
```

^align-array-example

## Вложенные структуры → распаковка

```go
type Inner struct {
    Ptr unsafe.Pointer  // 8 байт
    Size int            // 8 байт
}

type Outer struct {
    Flag bool    // 1 байт
    Data Inner   // распаковываем: Ptr(8) + Size(8) → максимум = 8
}
// Выравнивание Outer = 8 байт (не 16!)
// string тоже = {Ptr, Size} → выравнивание 8
```

^align-nested-example

## 32-бит машина

На 32-бит: int64 выровнен на **4 байта** (машинное слово), не на 8. Зачем тратить padding, если процессор всё равно читает по 4 байта? ^align-32bit
