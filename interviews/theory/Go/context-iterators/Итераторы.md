## Типы итераторов

```go
// iter.Seq[V] — одно значение (как range по slice values)
type Seq[V any]    func(yield func(V) bool)

// iter.Seq2[K,V] — два значения (как range по map: key, value)
type Seq2[K, V any] func(yield func(K, V) bool)
```

Это просто type definitions. Базовый тип — функция, принимающая yield callback. ^iter-types-def

`iter.Seq[V]` принимает yield с одним значением — аналог range по slice values. ^iter-seq-one

`iter.Seq2[K,V]` принимает yield с двумя значениями — аналог range по map (ключ + значение). ^iter-seq2-two

## Простой итератор

```go
func RangeN(n int) iter.Seq[int] {
    return func(yield func(int) bool) {
        for i := 0; i < n; i++ {
            if !yield(i) {  // передаём значение в range
                return      // false = break в range
            }
        }
    }
}

// Использование:
for v := range RangeN(5) {
    fmt.Println(v)  // 0, 1, 2, 3, 4
}
```

Итератор — функция, возвращающая функцию (замыкание), принимающую yield. При yield(i) = false нужно сразу вернуться. ^iter-simple-pattern

## Почему yield возвращает bool

```go
for v := range RangeN(1000) {
    if v == 3 {
        break  // range говорит итератору: "хватит" → yield вернёт false
    }
}
```

`break` внутри range сигнализирует итератору через false-возврат yield — это механизм досрочного завершения. ^iter-yield-bool-break

Если не проверить результат yield:

```go
func Bad(yield func(int) bool) {
    for i := 0; i < 10; i++ {
        yield(i)  // НЕ проверяем результат!
    }
}

for v := range Bad {
    if v == 3 {
        break  // ПАНИКА: range function continued after loop body exit
    }
}
```

Runtime Go ловит это и паникует с сообщением `range function continued after loop body exit` — защита от бесконечного цикла. ^iter-panic-message

## Iter.Seq2 — два значения

```go
func Enumerate[T any](s []T) iter.Seq2[int, T] {
    return func(yield func(int, T) bool) {
        for i, v := range s {
            if !yield(i, v) { return }
        }
    }
}

for i, name := range Enumerate([]string{"a", "b", "c"}) {
    fmt.Printf("%d: %s\n", i, name)
}
```

`iter.Seq2` используется когда нужно вернуть два значения — например, индекс и элемент. ^iter-seq2-example

## Замыкания для параметризации

Итератор возвращает функцию → параметры через замыкание. Отсюда паттерн «функция возвращает функцию»: ^iter-closure-pattern

```go
func Backward[T any](s []T) iter.Seq[T] {
    return func(yield func(T) bool) {
        for i := len(s) - 1; i >= 0; i-- {
            if !yield(s[i]) { return }
        }
    }
}
```

Параметры (срез `s`) захватываются замыканием — итератор становится параметризованным без изменения сигнатуры yield. ^iter-closure-capture

## Под капотом: корутины

Итераторы работают поверх stackless coroutines. ^iter-coroutine-stackless

yield — точка переключения: вызвали yield → выполнился код внутри range → вернулись обратно в итератор. ^iter-yield-switch-point

Конечный автомат, стек не нужен. В будущих версиях Go корутины могут стать доступны напрямую. ^iter-fsm-future
