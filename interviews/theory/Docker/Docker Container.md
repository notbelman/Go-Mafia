**Docker Container (Контейнер)** — это запущенный и работающий экземпляр образа (Image). Если образ — это пассивный шаблон или «архив» с файлами, то контейнер — это активный процесс, который изолирован от основной операционной системы и других контейнеров.

**Ключевые особенности:**

- **Изоляция**: Контейнер работает внутри собственного программного пространства (ящика), имея свою независимую **mini-OS** (обычно урезанный Linux), что гарантирует отсутствие конфликтов с хостом или другими приложениями.
- **Эффективность**: В отличие от виртуальных машин (VM), контейнеры не требуют полной гостевой ОС. Они весят десятки мегабайт и запускаются почти мгновенно (за секунды).
- **Контроль ресурсов**: При запуске можно четко ограничить, сколько ресурсов процессора (CPU) и оперативной памяти (RAM) может использовать конкретный контейнер.

```
# Запуск контейнера на основе образа
# (флаг -p пробрасывает порт хоста на порт контейнера)
docker run -p 8088:8088 my-backend-app

# Посмотреть список всех запущенных контейнеров
docker ps

# Остановить работающий контейнер
docker stop <container_id_или_name>
```
