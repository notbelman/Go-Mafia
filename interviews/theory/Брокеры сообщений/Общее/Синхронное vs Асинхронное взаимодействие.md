## Зачем асинхронность

Синхронные цепочки (HTTP/REST) → задержка внизу каскадно блокирует всех выше → исчерпание потоков → падение ("эффект домино").

Асинхронность изолирует: потребитель тормозит → сообщения копятся в очереди, отправитель не страдает.

## Сравнение

| Характеристика  | HTTP/REST (синхронно)     | Брокер (асинхронно)            |
| --------------- | ------------------------- | ------------------------------ |
| Связность       | Тесная: знает адрес и API | Слабая: знает только брокера   |
| Доступность     | Оба online одновременно   | Получатель может быть offline  |
| Блокировка      | Поток занят, ждёт ответа  | Свободен сразу                 |
| Надёжность      | Риск потери при сбое      | Брокер сохраняет на диск       |
| Результат       | Немедленный               | Eventual consistency           |
| Отладка         | Проще                     | Сложнее, нужен мониторинг      |
| Масштабирование | Плохо под нагрузкой       | Высокая пропускная способность |
| Идемпотентность | Не требуется              | Обязательна (дубли)            |
