Маршрутизаторы в RabbitMQ. Publishers никогда не отправляют messages напрямую в queues - они направляют их в exchange, который на основе правил решает куда передать данные.

## Direct (Прямой):
Использует точное соответствие. Message попадает в queue только если **routing key**, указанный producer, **идентичен ключу** при привязке queue к exchange.

## Fanout (Разветвитель):
Работает по принципу широковещания. Игнорирует routing keys и **копирует message во все queues**, которые к нему привязаны. Стандартная модель для **Pub-Sub** паттерна.

## Topic (Тематический):
Самый гибкий тип. Маршрутизация на основе частичного совпадения ключей с wildcards:
- `*` заменяет ровно одно слово
- `#` заменяет ноль или более слов
Пример: `ERROR.#` соберёт все ошибки из любой подсистемы.

## Headers (Заголовочный):
Редкий тип. Игнорирует текстовый routing key и анализирует **атрибуты заголовков** message для принятия решения о доставке.
