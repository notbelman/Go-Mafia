
Архитектура, где всё приложение — один деплоймент-юнит: собирается, тестируется и выкатывается как единый артефакт.

Единый артефакт — один билд, один файл на выходе (jar/exe/docker image).
Нельзя задеплоить только модуль оплаты, только всё целиком.

Вызовы между модулями — прямой вызов метода в памяти.
Нет сети между компонентами.

Один стек — один язык, один фреймворк, общие зависимости.

Общая БД — все модули ходят в одну базу.
