
*   **Фрагментация данных:** У каждого сервиса своя база. Прямые SQL Join-ы между таблицами разных сервисов невозможны. Данные приходится собирать «как пазл» на уровне бизнес-логики приложения 
*   **Отсутствие распределенных транзакций:** Классические ACID-транзакции работают только внутри одной БД. Нельзя одной транзакцией обновить данные в нескольких сервисах
