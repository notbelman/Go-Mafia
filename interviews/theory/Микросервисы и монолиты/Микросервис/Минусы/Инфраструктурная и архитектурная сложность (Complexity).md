*   **Увеличение точек управления:** Вместо одного приложения и одной БД приходится администрировать десятки или сотни сервисов, каждый из которых может иметь свой стек, конфигурацию и базу данных
*   **Инфраструктурный «налог»:** Требуется внедрение «джентльменского набора» DevOps: контейнеризация (Docker), оркестрация (Kubernetes), CI/CD пайплайны, Service Discovery и API Gateway для маршрутизации запросов
