Closure в Rust - это анонимная структура, которую компилятор генерирует автоматически, с полями для захваченных переменных и реализацией одного из `Fn`-трейтов.

## Зачем

Closure нужны чтобы создавать функции "на лету" с доступом к окружающему контексту. В отличие от обычных функций, closure может использовать переменные из scope, где была определена.

## Под капотом

Когда пишешь:
```rust
let x = 10;
let y = 20;
let add = |z| x + y + z;
```

Компилятор генерирует примерно такое:
```rust
struct __AnonymousClosure<'a> {
    x: &'a i32,  // захвачено по ссылке
    y: &'a i32,  // захвачено по ссылке
}

impl<'a> Fn<(i32,)> for __AnonymousClosure<'a> {
    type Output = i32;
    
    extern "rust-call" fn call(&self, (z,): (i32,)) -> i32 {
        *self.x + *self.y + z
    }
}
```

**Что происходит:**

1. Компилятор анализирует тело closure и определяет какие переменные используются
2. Создаёт анонимную структуру с полями под каждую захваченную переменную
3. Тип захвата (ссылка / mut ссылка / значение) выбирается минимально необходимый для операций в теле
4. Реализует нужный `Fn`-трейт в зависимости от того, как используются захваченные данные

**Размер closure:**
```rust
let x = 10i32;
let y = [0u8; 1000];

let c1 = || x;           // размер = size_of::<&i32>() = 8 байт (указатель)
let c2 = || y.len();     // размер = size_of::<&[u8; 1000]>() = 8 байт
let c3 = move || y;      // размер = size_of::<[u8; 1000]>() = 1000 байт
```

Closure без захвата имеет нулевой размер (ZST - Zero Sized Type):
```rust
let c = || 42;
assert_eq!(std::mem::size_of_val(&c), 0);
```

## Ключевые детали

**Каждая closure имеет уникальный анонимный тип:**
```rust
let a = |x| x + 1;
let b = |x| x + 1;
// typeof(a) != typeof(b), даже если тело идентично
```

Это значит нельзя написать:
```rust
let mut c = |x| x + 1;
c = |x| x + 2;  // ошибка: разные типы
```

**Почему уникальный тип:**
- Позволяет компилятору инлайнить вызовы (мономорфизация)
- Каждая closure может захватывать разные переменные = разная структура
- Zero-cost abstraction: нет vtable, нет heap allocation

**Сравнение с function pointer:**
```rust
// Function pointer - фиксированный размер, один тип для сигнатуры
let f: fn(i32) -> i32 = |x| x + 1;  // работает только если нет захвата

// Closure с захватом нельзя привести к fn pointer
let y = 10;
let f: fn(i32) -> i32 = |x| x + y;  // ошибка!
```

## Ограничения / Когда не использовать

- Нельзя явно указать тип closure (он анонимный) - только через generics или trait objects
- Closure с захватом нельзя хранить в `static` (лайфтаймы)
- Большие захваченные данные с `move` раздувают размер closure

## Примеры

**Проверка что генерирует компилятор:**
```rust
fn main() {
    let x = 5;
    let closure = |y| x + y;
    
    println!("size: {}", std::mem::size_of_val(&closure));  // 8 (один &i32)
    println!("result: {}", closure(10));  // 15
}
```

**Эквивалент на структуре (для понимания):**
```rust
struct MyClosure<'a> {
    x: &'a i32,
}

impl<'a> MyClosure<'a> {
    fn call(&self, y: i32) -> i32 {
        *self.x + y
    }
}

fn main() {
    let x = 5;
    let closure = MyClosure { x: &x };
    println!("{}", closure.call(10));  // 15
}
```

**Когда closure становится не-ZST:**
```rust
let a = 1;
let b = 2;
let c = 3;

let closure = || a + b + c;
// Структура: { a: &i32, b: &i32, c: &i32 }
// Размер: 24 байта (3 указателя по 8)
```
