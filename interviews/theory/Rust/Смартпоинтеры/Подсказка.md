```
Box<T>         → данные в куче (база)
    ↓
Rc<T>          → несколько владельцев, однопоточный
    ↓
Arc<T>         → несколько владельцев, многопоточный
    ↓
Cell<T>        → interior mutability, Copy типы
    ↓
RefCell<T>     → interior mutability, любые типы, runtime проверки
    ↓
Weak<T>        → слабая ссылка для Rc/Arc, ломает циклы
    ↓
Cow<T>         → clone on write, оптимизация аллокаций
    ↓
Mutex<T>       → эксклюзивный доступ, многопоточный
    ↓
RwLock<T>      → много читателей / один писатель
    ↓
tokio::Mutex   → async версия
    ↓
tokio::RwLock  → async версия
    ↓
parking_lot    → быстрые замены std
```

Типичные комбинации:

```rust
Rc<RefCell<T>>      → несколько владельцев + мутабельность (однопоточный)
Arc<Mutex<T>>       → несколько владельцев + мутабельность (многопоточный)
Arc<RwLock<T>>      → то же, но read >> write
```
