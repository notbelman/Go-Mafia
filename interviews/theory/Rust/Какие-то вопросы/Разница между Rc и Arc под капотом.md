## Rc

- Обычный счётчик: `count += 1`
- Не потокобезопасен
- Быстрее

## Arc

- Атомарный счётчик: `AtomicUsize`
- Потокобезопасен
- Дороже из-за атомарных операций

## Почему Rc нельзя в многопоточке

Data race на счётчике:
```
Поток 1: читает count = 1
Поток 2: читает count = 1
Поток 1: пишет count = 2
Поток 2: пишет count = 2  // должно быть 3
```

Rc не реализует `Send` → компилятор не даст передать в другой поток.
