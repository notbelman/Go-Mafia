## Array [T; N]
- Фиксированный размер в compile time
- На стеке
- Размер - часть типа: [i32; 3] ≠ [i32; 5]
## Vec<T>
- Динамический размер
- Данные в куче
- Может расти: push, pop, resize
- Под капотом: ptr + len + capacity
## Slice [T]
- Вью на непрерывную последовательность
- Всегда за ссылкой: &[T], &mut [T]
- DST - размер неизвестен в compile time
- Можно получить из array и Vec
## Пример
```rust
let arr: [i32; 3] = [1, 2, 3];
let vec: Vec<i32> = vec![1, 2, 3];
let slice: &[i32] = &arr[..];
let slice2: &[i32] = &vec[1..];
```
