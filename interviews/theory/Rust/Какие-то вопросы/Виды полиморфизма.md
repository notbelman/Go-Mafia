## Ad-hoc (перегрузка)

Разные реализации для разных типов через трейты:
```rust
impl Add for i32 { ... }
impl Add for f64 { ... }
```

## Параметрический (generics, static dispatch)

Один код для любых типов, resolved в compile time:
```rust
fn draw_generic<T: Drawable>(shape: &T) {
    shape.draw();
}
```

## Subtype (trait objects, dynamic dispatch)

Разные типы за одним интерфейсом, resolved в runtime:
```rust
let shapes: Vec<Box<dyn Drawable>> = vec![
    Box::new(Rectangle::new(10.0, 5.0)),
    Box::new(Circle::new(3.0)),
];
```

## Enum-based

Все варианты известны, match вместо vtable:
```rust
enum Shape {
    Rectangle { width: f64, height: f64 },
    Circle { radius: f64 },
}

impl Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Rectangle { width, height } => width * height,
            Shape::Circle { radius } => PI * radius * radius,
        }
    }
}
```

## Closure / Function pointer

Поведение через функции:
```rust
fn apply<F: Fn(i32, i32) -> i32>(x: i32, y: i32, op: F) -> i32 {
    op(x, y)
}

apply(5, 3, |a, b| a + b);
```
