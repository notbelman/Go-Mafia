
Выносит синхронную блокирующую операцию в отдельный пул потоков, чтобы не блокировать async runtime.

### Зачем

Worker threads крутят async задачи. Если там вызвать что-то блокирующее (std::fs, тяжёлые вычисления, синхронный HTTP), worker встанет - другие таски на нём не выполняются.

`spawn_blocking` переносит блокирующий код на отдельный поток из blocking pool.

### Blocking pool

- Потоки создаются по требованию (не при старте)
- Лимит ~512 потоков
- Один поток = одна блокирующая задача
- Умирают после 10 секунд простоя

### Когда использовать

- Работа с файловой системой через std::fs
- CPU-intensive вычисления
- Синхронные библиотеки без async версии
- Любой код который блокирует поток
