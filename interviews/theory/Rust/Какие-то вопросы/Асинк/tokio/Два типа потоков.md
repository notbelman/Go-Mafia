**Worker threads (core threads)**
- Количество = ядрам CPU (по умолчанию)
- Создаются при старте runtime, число не меняется
- Крутят async задачи
- Один worker может выполнять тысячи задач конкурентно

**Blocking threads**
- Создаются по требованию при вызове spawn_blocking
- Лимит ~512 потоков
- Один поток = одна блокирующая задача
- Умирают после 10 секунд простоя
