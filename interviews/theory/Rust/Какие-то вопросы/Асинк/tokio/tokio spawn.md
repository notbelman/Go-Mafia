Создаёт новую **асинхронную задачу** (task) и запускает её на том же async runtime.

### Суть

- Таска выполняется **конкурентно** с другими тасками
- Работает на тех же потоках executor'а (не создаёт новый поток)
- Возвращает `JoinHandle<T>` для получения результата

### Когда использовать

- Хочешь запустить что-то параллельно и не ждать сразу результат
- Fire-and-forget задачи (логирование, отправка метрик)
- Обработка нескольких запросов одновременно

### spawn vs spawn_blocking

| | tokio::spawn | tokio::spawn_blocking |
|-|--------------|----------------------|
| Для чего | async код | синхронный блокирующий код |
| Где выполняется | async runtime потоки | отдельный пул потоков |
| Блокирует executor | да, если внутри sync код | нет |
