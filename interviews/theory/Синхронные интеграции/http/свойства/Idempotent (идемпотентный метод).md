N одинаковых запросов дают тот же результат, что и 1 запрос.

## Под капотом

| Метод   | Idempotent | Почему                                           |
|---------|------------|--------------------------------------------------|
| GET     | Да         | Читает одно и то же                              |
| HEAD    | Да         | Читает одни и те же метаданные                   |
| OPTIONS | Да         | Возвращает одни и те же доступные методы         |
| PUT     | Да         | Заменяет ресурс на одно и то же                  |
| DELETE  | Да         | 1-й раз удалит, остальные - ресурса уже нет      |
| POST    | Нет        | Каждый раз создает НОВЫЙ ресурс                  |
| PATCH   | Нет        | Зависит от реализации, по спеке не гарантируется |
