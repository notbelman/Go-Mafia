Метод не меняет состояние сервера. Read-only операция.
Браузеры, кеши и прокси могут смело вызывать safe методы без риска что-то сломать или изменить. Можно делать prefetch, предзагрузку.
## Под капотом

| Метод   | Safe | Почему                          |
| ------- | ---- | ------------------------------- |
| GET     | Да   | Только читает данные            |
| HEAD    | Да   | Только читает метаданные        |
| OPTIONS | Да   | Только читает доступные методы  |
| TRACE   | Да   | Только диагностика, эхо запроса |
| POST    | Нет  | Создает ресурс, меняет БД       |
| PUT     | Нет  | Заменяет ресурс, меняет БД      |
| PATCH   | Нет  | Изменяет ресурс, меняет БД      |
| DELETE  | Нет  | Удаляет ресурс, меняет БД       |
