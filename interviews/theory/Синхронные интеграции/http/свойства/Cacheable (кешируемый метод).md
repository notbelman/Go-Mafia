Ответ метода можно сохранить и переиспользовать без повторного запроса к серверу.

## Под капотом

| Метод   | Cacheable | Почему                                              |
|---------|-----------|-----------------------------------------------------|
| GET     | Да        | Safe + idempotent, результат стабильный             |
| HEAD    | Да        | Safe + idempotent, метаданные стабильны             |
| POST    | Теор. да  | Можно по спеке, но никто не делает на практике      |
| PUT     | Нет       | Меняет состояние, кеш станет невалидным             |
| PATCH   | Нет       | Меняет состояние, кеш станет невалидным             |
| DELETE  | Нет       | Меняет состояние, кеш станет невалидным             |
| OPTIONS | Нет       | Редко кешируется, хотя технически можно             |
| TRACE   | Нет       | Диагностический, смысла кешировать нет              |
