Заменяет ресурс ЦЕЛИКОМ. Клиент знает ID.

```
PUT /users/123
{"name": "Ivan", "email": "new@example.com", "role": "admin"}
```

-> Заменит ВСЁ. Если не передал поле - оно удалится/обнулится

Идемпотентен: N запросов = 1 запрос, результат тот же.

## Upsert семантика
Если /users/123 не существует -> создаст его (201 Created)
Если существует -> заменит (200 OK или 204 No Content)
