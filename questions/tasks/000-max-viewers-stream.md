## Условие

Посчитать максимальное количество пользователей, одновременно смотревших игровой стрим.

Каждый пользователь подключался к стриму в момент времени `t_in` и отключался в момент времени `t_out` - время измеряется в секундах (от 0 до 10^9). У каждого пользователя это время своё.

Дан массив (неупорядоченный) из пар `(t_in, t_out)` - длина массива от 0 до 10^6.

Требуется вывести число - максимальное количество пользователей, которые одновременно смотрели стрим.

## Примеры

```
[] -> 0
[(1, 5), (5, 10)] -> 1
[(1, 5), (0, 1), (4, 5)] -> 2
[(1, 10), (5, 6), (2, 3), (7, 8)] -> 2
[(1, 2), (1, 10), (4, 9), (8, 15), (5, 6), (8, 16)] -> 4
```

## Решение

```rust
fn max_viewers(intervals: Vec<(i64, i64)>) -> i32 {
    if intervals.is_empty() {
        return 0;
    }
    
    // Создаём события: +1 при входе, -1 при выходе
    let mut events: Vec<(i64, i32)> = Vec::with_capacity(intervals.len() * 2);
    
    for (t_in, t_out) in intervals {
        events.push((t_in, 1));   // вход
        events.push((t_out, -1)); // выход
    }
    
    // Сортируем по времени, при равенстве - выходы раньше входов
    // (чтобы [(1,5), (5,10)] давало 1, а не 2)
    events.sort_by(|a, b| {
        if a.0 != b.0 {
            a.0.cmp(&b.0)
        } else {
            a.1.cmp(&b.1) // -1 < 1, выходы первыми
        }
    });
    
    let mut current = 0;
    let mut max_count = 0;
    
    for (_, delta) in events {
        current += delta;
        max_count = max_count.max(current);
    }
    
    max_count
}
```

## Сложность

- Время: O(n log n) - сортировка событий
- Память: O(n) - хранение событий

## Шаг 1

```
i = 0, j = 0
starts[0] = 0
ends[0] = 1
```

Сравниваем: 0 < 1
Потому что 0 случилось **раньше по времени** чем 1.

Ты идёшь по временной шкале слева направо. Меньшее число = более ранний момент = обрабатываешь первым.

Событие в момент 0 случилось раньше. Это приход (из starts). Значит кто-то пришёл.

```
count = 0 + 1 = 1
max_count = 1
i = 1 (двигаем, потому что взяли из starts)
```
