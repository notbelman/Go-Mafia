## Условие
Дана строка, содержащая символы-скобки `(`, `{`, `[`, `)`, `}`, `]`.
Необходимо определить, является ли последовательность скобок корректной.

**Примеры:**
- Input: `(( { [ ] } { } ))` → Output: `true`
- Input: `( { } ) [ ]` → Output: `false`

## Решение

```go
func isValid(s string) bool {
	// стек для хранения открывающих скобок
	// используем slice как стек: append = push, s[:len-1] = pop
	stack := []rune{}

	// маппинг: закрывающая → соответствующая открывающая
	// ключ — то что встречаем, значение — то что ожидаем на вершине стека
	pair := map[rune]rune{
		')': '(',
		'}': '{',
		']': '[',
	}

	for _, char := range s {
		if char == '(' || char == '{' || char == '[' {
			// открывающая скобка — кладём в стек, будем ждать её закрывающую пару
			stack = append(stack, char)
		} else if len(stack) > 0 && stack[len(stack)-1] == pair[char] {
			// закрывающая скобка И на вершине стека лежит её пара
			// pair[char] — ищем какая открывающая должна соответствовать этой закрывающей
			// stack[len(stack)-1] — смотрим вершину стека (последний элемент)
			// если совпали — снимаем вершину стека (pop)
			stack = stack[:len(stack)-1]
		} else {
			// два случая попадания сюда:
			// 1. стек пуст, а пришла закрывающая — нечего закрывать → невалидно
			// 2. вершина стека не совпадает с парой — неправильный порядок → невалидно
			// пример: "({)" — на вершине '(' а пришла ')' при ожидании '}'
			return false
		}
	}

	// если стек пуст — все открывающие нашли свою пару
	// если не пуст — остались незакрытые скобки, например "(("
	return len(stack) == 0
}
```

**Сложность:**
- Временная: O(n)
- Пространственная: O(n)
